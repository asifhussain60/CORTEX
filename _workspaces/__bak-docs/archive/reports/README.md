# Analysis Reports

Auto-expired analysis and investigation outputs.

**Lifetime:** 30 days
**Auto-delete:** Yes (after expiry)
**Archive:** Move to documentation/ if results are needed long-term

Files in this folder are temporary analysis outputs, investigation results,
and exploratory reports. They expire after 30 days automatically.

```yaml
created_at: 2026-01-26T15:30:00Z

category: analysis

---
```
