Semantic Chunking Engine

CORTEX chunks text by semantic boundaries (paragraphs, logical sections, code blocks) rather than arbitrary character limits. This preserves context and improves retrieval accuracy.

Implementation Highlights

  • AST-aware chunking for code files
  • Paragraph and section detection for docs
  • Overlap strategy: 10% overlap between chunks
  • Size limits: 200-800 tokens per chunk

Example: Semantic Chunking in Action

# Example: Semantic chunking in action
from cortex.brain.context.semantic_chunker import SemanticChunker

chunker = SemanticChunker(
    chunk_size_range=(200, 800),
    overlap_pct=0.1,
    boundary_types=["paragraph", "code_block", "function"]
)

chunks = chunker.chunk_document(large_document)
# Result: 25 chunks with clean semantic boundaries
# vs 40 chunks with arbitrary splitting
