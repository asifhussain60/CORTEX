🧠 LENS Analyzers

4 Specialized Code Intelligence Crawlers

📊 Analyzer Data Flow

Interactive visualization showing how data flows through CORTEX LENS analyzers

1. AST Analyzer

Purpose: Extract code structure, functions, classes, imports

Languages: Python, JavaScript, TypeScript, Java, C#, Go (6+)

Capabilities

Function/method signatures with parameters and return types
Class hierarchies and inheritance
Import/dependency graphs
Variable declarations and scope analysis
Decorator/annotation extraction
Nested structure parsing
cortex_ast_analyze(file_path, language)

2. Git History Analyzer

Purpose: Extract commit history, blame, author patterns

Context Window: 24 hours (configurable)

Capabilities

Recent commits affecting file (last 24h default)
Git blame line-by-line authorship
Author contribution patterns
Commit frequency and change velocity
File modification hotspots
Branch and merge analysis
cortex_git_history(file_path, repo_path, hours=24)

3. Comment Extractor

Purpose: Extract TODOs, FIXMEs, intent hints from comments

Capabilities

TODO/FIXME/HACK/NOTE pattern detection
Docstring extraction (Google, NumPy, Sphinx styles)
Inline comment analysis
Intent signals from developer notes
Technical debt markers
Priority and severity classification
cortex_extract_comments(file_path)

4. Security Threat Analyzer

Purpose: Detect CWE vulnerabilities in code

Coverage: 6 CWE patterns

Detected Patterns

CWE-94: Code Injection
CWE-95: Unsafe Deserialization
CWE-78: Command Injection
