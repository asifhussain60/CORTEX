🎯 cortex_process_request

Main Request Processing Tool

Overview

cortex_process_request is the primary MCP tool for routing user requests through CORTEX's orchestrator pipeline. It handles intent classification, DoR validation, orchestrator routing, and evidence bundle generation.

Function Signature


cortex_process_request(
    request: str,
    context: Optional[Dict[str, Any]] = None,
    mode: str = "production"
) -> Dict[str, Any]

Parameters

Parameter Type Description
request string User's natural language request (e.g., "implement login feature with TDD")
context dict (optional) Additional context (file paths, repo info, constraints)
mode string Execution mode: "production", "development", "test"

Returns


{
    "status": "success" | "error",
    "intent": "IMPLEMENT" | "FIX" | "REFACTOR" | "ANALYZE" | "TEST",
    "orchestrator": "TDDOrchestrator" | "RefactoringOrchestrator" | ...,
    "dor_validation": {
        "passed": true,
        "requirements": [...],
        "missing": [...]
    },
    "execution_result": {
        "files_modified": [...],
        "tests_run": 15,
        "tests_passed": 15,
        "coverage": 95.2
    },
    "evidence_bundle_path": "cortex_brain/state/evidence/bundle_abc123.zip",
    "audit_trail": [...]
}

Workflow

  1. Intent Classification: IntentRouter analyzes request → classifies as IMPLEMENT/FIX/REFACTOR/etc.
  2. LENS Analysis: If needed, triggers LENS analyzers for context
  3. DoR Validation: LENSSynthesis generates Definition of Ready → awaits approval
  4. Orchestrator Routing: MasterOrchestrator selects appropriate orchestrator
  5. Execution: Orchestrator executes with governance enforcement
  6. Evidence Bundle: TodoManager generates evidence bundle with audit trail

Example Usage


# Simple request
result = cortex_process_request(
    request="Implement user authentication with JWT tokens"
)

# With context
result = cortex_process_request(
    request="/refactor extract authentication logic into service",
    context={
        "file_path": "api/auth.py",
        "target_pattern": "service_layer"
    }
)

# Development mode (relaxed governance)
result = cortex_process_request(
    request="/test generate unit tests for UserService",
    mode="development"
)

Error Handling

Returns structured errors with remediation guidance:


{
    "status": "error",
    "error_type": "GOVERNANCE_VIOLATION",
    "rule_id": "CORE-008",
    "message": "Tests must exist before implementation (TDD)",
    "remediation": "Run: cortex_process_request('/test generate tests for UserService')"
}
