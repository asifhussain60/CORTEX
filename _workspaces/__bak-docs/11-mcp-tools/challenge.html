⚔️ cortex_challenge

Security Gates & Threat Blocking (Phase 8.3)

Overview

cortex_challenge enforces hard security gates that prevent critical vulnerabilities from progressing. When LENS detects CWE threats, ChallengeEngine blocks execution until explicit override approval is provided.

Function Signature


cortex_challenge(
    threat_id: str,
    action: str = "EVALUATE",
    override_reason: Optional[str] = None
) -> Dict[str, Any]

Parameters

Parameter Type Description
threat_id string Threat identifier from LENS security analysis
action string "EVALUATE" (default), "OVERRIDE", "BLOCK", "REMEDIATE"
override_reason string (optional) Justification for override (required if action=OVERRIDE)

Actions

  • EVALUATE: Check threat severity and get recommendations
  • OVERRIDE: Explicitly approve proceeding despite threat (requires justification)
  • BLOCK: Permanently block this threat pattern
  • REMEDIATE: Get automated fix suggestions

Returns


{
    "status": "blocked" | "approved" | "remediated",
    "threat_id": "THREAT-abc123",
    "cwe": "CWE-89",
    "severity": "CRITICAL",
    "recommendation": {
        "action": "Use parameterized queries",
        "code_example": "cursor.execute('SELECT * FROM users WHERE id = ?', (user_id,))",
        "references": [
            "OWASP Top 10: A03 Injection",
            "CWE-89: SQL Injection"
        ]
    },
    "override_granted": false,
    "override_reason": null,
    "audit_logged": true
}

Example Usage


# Step 1: LENS detects SQL injection
lens_result = cortex_lens_analyze("api/users.py", include_security=True)
threat_id = lens_result['security_analysis']['threats'][0]['id']

# Step 2: Evaluate threat
challenge_result = cortex_challenge(
    threat_id=threat_id,
    action="EVALUATE"
)
# Returns: status="blocked", recommendation with fix

# Step 3a: Apply automated remediation
remediation = cortex_challenge(
    threat_id=threat_id,
    action="REMEDIATE"
)
# Returns: code patches to fix vulnerability

# Step 3b: OR override with justification (NOT RECOMMENDED)
override = cortex_challenge(
    threat_id=threat_id,
    action="OVERRIDE",
    override_reason="Legacy code, scheduled for refactor in Sprint 23"
)
# Returns: override_granted=true, audit_logged=true

Security Gates (Phase 8.3)

ChallengeEngine enforces these severity-based gates:

Severity CWE Patterns Default Action
CRITICAL CWE-94 (Code Injection), CWE-89 (SQL Injection), CWE-78 (Command Injection) BLOCK (requires override)
HIGH CWE-95 (Deserialization), CWE-327 (Weak Crypto) WARN + Recommendation
MEDIUM CWE-22 (Path Traversal) RECOMMENDATION
