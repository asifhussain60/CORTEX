🧭 Epic Plan Viewer

Interactive HTML View Generator for CORTEX Plans

Overview

The Epic Plan Viewer transforms YAML epic plans into beautiful, interactive HTML visualizations with phase tracking, dependency graphs, and progress monitoring.

Features

  • Phase Visualization: Multi-phase epic plans with progress bars
  • Dependency Graphs: D3.js visualizations of task dependencies
  • DoR/DoD Validation: Color-coded Definition of Ready/Done status
  • Evidence Tracking: Link to evidence bundles for completed phases
  • Glassmorphism Design: Modern glass-style UI matching CORTEX theme

Usage


from cortex.toolkit.plan_viewer import generate_plan_view

# Generate HTML from YAML epic plan
generate_plan_view(
    plan_path="epic-plans/user-auth-epic.yaml",
    output_path="docs/plans/user-auth.html"
)

# Result: Interactive HTML page with:
# - Phase timeline
# - Task breakdown with complexity scores
# - Dependency visualization
# - Progress tracking

Generated View Components

📊 Phase Timeline

Horizontal timeline showing epic phases with completion status

🎯 Task Cards

Interactive cards for each task with DoR/DoD checklists

🔗 Dependency Graph

D3.js force-directed graph showing task relationships

📈 Progress Metrics

Real-time completion percentage and velocity tracking
