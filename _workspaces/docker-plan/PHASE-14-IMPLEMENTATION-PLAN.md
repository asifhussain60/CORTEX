## 📐 Architecture: Phase 14 V2

### Simplified 2-Tier Structure

```
cortex-lens/                    # Root dashboard folder
├─ index.html                   # Entry point (redirects to data/cortex/index.html)
├─ static/                      # Bundled assets
│   ├─ css/
│   │   ├─ dashboard.css        # Base styles
│   │   └─ glassmorphism.css    # Glass effect styling
│   ├─ js/
│   │   ├─ tabs.js              # Simple tab switching (vanilla JS)
│   │   └─ d3-viz.js            # D3.js visualization wrappers
│   ├─ vendor/
│   │   └─ d3.v7.min.js         # D3.js bundled locally (250KB)
│   └─ assets/
│       └─ cortex-logo.png      # CORTEX logo
└─ data/
    └─ cortex/                  # CORTEX repository dashboard
        ├─ index.html           # Main 6-tab dashboard
        ├─ overview.json        # Business language data
        ├─ dependencies.json    # Import/call graph data
        ├─ classes.json         # Entity model data
        ├─ timeline.json        # Git history data
        ├─ impact.json          # Change impact data
        └─ orchestrators.json   # CORTEX-specific orchestrator graph
```

**Design Principles:**
1. ✅ **No build step** — Open `index.html` directly in browser
2. ✅ **Offline-first** — Works at `file:///` URLs
3. ✅ **No CDN** — All assets bundled locally
4. ✅ **Vanilla JS** — No framework dependencies (Alpine.js removed)
5. ✅ **Static JSON** — Pre-generated data files
6. ✅ **D3.js only** — No Mermaid (failed rendering)

## 🗂️ 6-Tab Dashboard Structure

### Tab 1: 📦 Repository Overview
**Purpose:** Business-language summary of CORTEX

**Content:**
- "CORTEX is a [description]" (BusinessLanguageGenerator)
- Key capabilities (orchestrators, LENS, governance)
- Technology stack (Python 3.9+, pytest, yaml)
- Architecture pattern (4-tier brain, 27 orchestrators)
- File statistics (LOC, file count, test coverage)

**Data Source:** `overview.json` (generated by `BusinessLanguageGenerator`)

---

### Tab 2: 🕸️ Dependency Graph
**Purpose:** Visualize module import relationships

**Content:**
- D3.js force-directed graph
- Nodes = Python modules (cortex/*, cortex_brain/*, tests/*)
- Edges = import statements
- Color coding: core (blue), brain (green), tests (gray)
- Interactive hover (show module docstring)

**Data Source:** `dependencies.json` (generated by AST analyzer)

**Implementation Reference:**
- `cortex/brain/analysis/ast_analyzer.py` (existing)
- `cortex/visualization/renderers/d3_import_graph_renderer.py` (NEW)

---

### Tab 3: 📊 Orchestrator Constellation
**Purpose:** CORTEX-specific orchestrator relationships

**Content:**
- 27 orchestrators as nodes
- Edges = invocation relationships (who calls whom)
- Size = number of methods
- Color = category (core, domain, support)
- Wiring status indicator (wired/unwired)

**Data Source:** `orchestrators.json` (generated from wiring.yaml + AST)

**Implementation:**
- Parse `cortex/wiring/specifications/wiring.yaml`
- Analyze orchestrator method calls via AST
- Generate D3.js network graph

---

### Tab 4: ⏰ Git Timeline
**Purpose:** Commit history visualization

**Content:**
- D3.js timeline (last 90 days)
- Y-axis = LOC changed
- X-axis = date
- Color = author
- Hover = commit message

**Data Source:** `timeline.json` (generated by GitHistoryAnalyzer)

**Implementation Reference:**
- `cortex/brain/analysis/git_history_analyzer.py` (existing)
- D3.js timeline renderer (NEW)

---

### Tab 5: 💥 Impact Analysis
**Purpose:** Change propagation visualization

**Content:**
- Heatmap of file change frequency
- "Blast radius" of changes (which files change together)
- Hotspot detection (files changed >10 times in 30 days)

**Data Source:** `impact.json` (generated by GitHistoryAnalyzer + AST)

---

### Tab 6: 🧠 Brain Architecture
**Purpose:** CORTEX 4-tier brain visualization

**Content:**
- Tier 0: Governance rules (CORE-* rules)
- Tier 1: Audit & control (audit trail)
- Tier 2: Templates & hallucination prevention
- Tier 3: Knowledge (35 YAML files)
- Connections between tiers

**Data Source:** `brain.json` (generated from cortex_brain/ structure)
