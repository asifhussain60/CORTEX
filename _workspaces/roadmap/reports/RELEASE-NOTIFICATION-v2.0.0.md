## 🔄 Migration Guide

### For Existing Systems
No breaking changes. Existing code continues to work with automatic enhancement:
1. MasterOrchestrator picks up new enforcement rules
2. ConversationProtocol automatically gains multi-turn support
3. Governance validation happens transparently

### For New Development
Use the new orchestrator patterns:
```python
# Start with MasterOrchestrator
from cortex.orchestrators.core.master_orchestrator import MasterOrchestrator
master = MasterOrchestrator.instance()

# Or wrap for multi-turn conversations
from cortex.core.orchestrator.conversation_protocol import ConversationProtocol
protocol = ConversationProtocol(master)

# Always verify AC-PERMANENT-FIX status
from cortex.tools.total_recall_agent import TotalRecallAgent
agent = TotalRecallAgent()
agent.check_ac_permanent_fixes()
```
