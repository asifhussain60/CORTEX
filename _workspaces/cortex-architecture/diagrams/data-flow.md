## Cache Data Flow

```
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                            CACHE DATA FLOW                                               │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                          │
│  Request ──► Check L1 ──► Check L2 ──► Check L3 ──► Compute ──► Store ──► Return       │
│                │             │             │           │           │                     │
│                │             │             │           │           │                     │
│                ▼             ▼             ▼           │           ▼                     │
│           ┌────────┐    ┌────────┐    ┌────────┐      │      ┌────────┐                │
│           │  HIT   │    │  HIT   │    │  HIT   │      │      │ Cache  │                │
│           │ Return │    │ Return │    │ Return │      │      │ Entry  │                │
│           └────────┘    └────────┘    └────────┘      │      └────────┘                │
│                                                        │           │                     │
│                                                        │           ▼                     │
│  L1: Process Memory ◄──────────────────────────────────┴───── Populate                  │
│  L2: Redis ◄────────────────────────────────────────────────── Populate                  │
│  L3: Git Registry ◄─────────────────────────────────────────── (Persistent)             │
│                                                                                          │
│  ┌──────────────────────────────────────────────────────────────────────────────────┐  │
│  │  Cache Entry Structure                                                            │  │
│  │                                                                                   │  │
│  │  key: "lens:src/auth/service.py:abc123"                                          │  │
│  │  value: {                                                                         │  │
│  │    "data": {...},                          ← Actual cached data                  │  │
│  │    "checksum": "sha256:...",               ← Source file checksum               │  │
│  │    "created_at": "2026-02-10T14:30:00Z",   ← Creation timestamp                 │  │
│  │    "ttl": 300,                             ← Time to live (seconds)             │  │
```
