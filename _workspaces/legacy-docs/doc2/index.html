What is CORTEX?

CORTEX is an MCP-first enterprise orchestration system that transforms Copilot into a governed, auditable execution engine. 23 wired orchestrators enforce standards via a GitBackedRegistry that routes every request through MasterOrchestrator → TodoManager pipeline with full traceability.

The 4-tier governance (Tier 0 SKULL → Tier 3 Learned) provides hash‑chain audit, state management, 7‑state lifecycle, and Evidence Bundles proving completion. TDD‑Master enforces RED → GREEN → REFACTOR with gates that block untested code.

All functionality exposed via 15+ MCP tools including cortex_process_request, cortex_lens_analyze, and cortex_challenge— enabling SaaS-grade orchestration with Prometheus observability and health endpoints.
