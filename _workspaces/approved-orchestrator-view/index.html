CORTEX Orchestrators

23 production orchestrators providing intelligent workflow automation, TDD enforcement, and domain-specific operations. All orchestrators are MCP-exposed for SaaS integration and governed by the 4-Tier Brain system.

23 Orchestrators 6 Core 6 Domain 11 Support MCP-First

Executive Summary

CORTEX orchestrators are the execution engine of the system. They coordinate complex multi-phase workflows, enforce governance rules, and provide intelligent automation through the MCP server interface. Each orchestrator is wired via GitBackedRegistry for hot-reload configuration and audit trail.

Key Orchestration Principles

  • MCP-First Architecture: All orchestrators exposed via MCP tools for SaaS integration
  • TDD Enforcement: TDDOrchestrator gates all code with RED→GREEN→REFACTOR
  • Governance Integration: 4-Tier Brain validation on every operation
  • Audit Trail: Every orchestrator action logged with hash-chain integrity
  • Hot-Reload Wiring: GitBackedRegistry enables runtime configuration updates
