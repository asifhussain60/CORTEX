## Architecture Highlights

### State Machine
```
User Request
    ↓
[Classify]
    ↓
[PENDING] ← User sees markdown
    │
    ├─→ approve() → [APPROVED] → Execute ✅
    ├─→ reject()  → [REJECTED] → Blocked ❌
    └─→ modify()  → [MODIFIED] → Re-classify
```

### Multi-Turn Support
```
Turn 1: Classify + Get Reflection
Turn 2: Approve (or Modify)
Turn 3: Different Request (state persists)
Turn 4: Reference previous approval
```

### Complete Audit Trail
```
Classification: 2026-01-24T14:23:15.123Z | Intent: FIX | Confidence: 0.92
Approval:       2026-01-24T14:23:18.456Z | Decision: APPROVED
Execution:      2026-01-24T14:23:19.789Z | Status: Success | Files: 3
```
