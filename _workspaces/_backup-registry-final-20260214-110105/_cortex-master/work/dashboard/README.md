## 🚀 Quick Start

### **IMPORTANT:** Must use HTTP server (not file://)

The dashboard loads data dynamically from `data/plan-summary.json` using the Fetch API, which requires an HTTP server due to browser CORS restrictions.

### **Option 1: Python HTTP Server (Recommended)**

```bash
cd /Users/asifhussain/PROJECTS/CORTEX/cortex-registry/_cortex-master/dashboard
python3 -m http.server 8893
```

Then open: **http://localhost:8893/index.html**

### **Option 2: One-Line Launch**

```bash
(cd /Users/asifhussain/PROJECTS/CORTEX/cortex-registry/_cortex-master/dashboard && python3 -m http.server 8893 > /dev/null 2>&1 &) && sleep 1 && open http://localhost:8893/index.html
```

### **❌ Will NOT Work:**
- Opening `index.html` directly via `file://` protocol
- Double-clicking the HTML file
- Drag-and-drop to browser

These methods trigger CORS errors and the dashboard will show all zeros.

## 🔍 Troubleshooting

### **Dashboard Shows All Zeros**
**Cause:** Opened via `file://` protocol (CORS blocked fetch)  
**Fix:** Use HTTP server (see Quick Start above)

### **JSON Not Loading**
**Cause:** Server not running or wrong directory  
**Fix:** 
```bash
cd cortex-registry/_cortex-master/dashboard
python3 -m http.server 8893
```

### **Check Browser Console**
Open DevTools (F12) → Console tab

**✅ Success message:**
```
✅ Dashboard data loaded from plan-summary.json
📊 Active phases: 1
📊 Completed phases: 19
📊 Progress: 95%
```

**❌ Error message:**
```
❌ Failed to load dashboard data: TypeError: Failed to fetch
```
→ Use HTTP server, not file:// protocol

```python
from cortex.registry import regenerate_dashboard
result = regenerate_dashboard('cortex-registry/_cortex-master')
```

**Trigger conditions:**
- Variance > 10%: Silent regeneration
- Variance > 20%: Silent sync (no user notification)
- Manual: Anytime via MCP tools or Python API

## 📝 Architecture

```
index.yaml (source)
    ↓
cortex_master_dashboard_generator.py
    ↓
data/plan-summary.json (generated)
    ↓
index.html (loads via fetch)
    ↓
Dashboard UI (dynamic)
```

**Key Functions:**
- `loadDashboardData()`: Async JSON loader with error handling
- `transformDashboardData()`: Maps JSON → UI format
- `initializeOverview()`: Renders progress rings and stats
- `initializeEvolution()`: Renders era timeline and cards
