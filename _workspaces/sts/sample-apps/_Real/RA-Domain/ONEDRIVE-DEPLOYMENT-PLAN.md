## 🛠️ Troubleshooting

### Issue: "OneDrive folder not found"
**Solution:** Ensure OneDrive is syncing. Check OneDrive icon in system tray.

### Issue: "HTML file opens as plain text"
**Solution:** Right-click → Open with → Choose browser (Chrome/Edge)

### Issue: "Styles not loading"
**Solution:** Verify folder structure. `css/main.css` must be in `css/` subdirectory.

### Issue: "Can't share folder"
**Solution:** Check OneDrive sharing settings. May require admin permissions.
