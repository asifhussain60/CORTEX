7-Stage Feature Delivery Pipeline

CORTEX is the conductor of adlc-copilot's existing pipeline, not a replacement. The 7 stages are owned by adlc-copilot; CORTEX enforces gates at key handoffs. CORTEX fires at stages 1, 3, 4, and 6—the 4 real decision points. Stages 0, 2, 5, and 7 are owned entirely by adlc-copilot or the developer.

Key Insight

CORTEX enforces decision gates at the critical handoff points: readiness before work begins, code review before merge, security before production, and final go/no-go before deployment. Between gates, adlc-copilot owns the execution.

4 Gate Skills

Each gate enforces discipline at a critical juncture. Gates fire automatically when conditions are met and either unlock the next stage or block with specific guidance.

gate-readiness

✓ Pass: Issues approval

3-Layer Testing Strategy

A pragmatic testing pyramid replacing the overengineered test-everything approach. Each layer validates a specific concern with bounded scope and time commitment.

What Was Removed

This strategy eliminated overengineered overhead:

  • Surface parity tests across 5 IDEs
  • Integration tests for every orchestrator
  • Certification testing suite (costly, low signal)

Instead, each layer targets a single critical concern: tool availability, routing logic, and self-consistency. Tests run in seconds to minutes, not hours.
