What is v3.2.0?

Consolidated Sharp Knife — an independent, comprehensive review of the live Foundations.Cortex repository state, followed by corrected planning and architecture simplification.

The Reality Check

The v3.1 plan claimed 275 orchestrators and 8 phases, but an independent audit of the live repo revealed the truth:

  • 381 orchestrators actually exist (not 275)
  • 74 MCP tool files defined
  • 19 skills in the original manifest, unified to 137 total
  • 1,428 test files covering live behavior

The v3.1 plan also proposed overengineered features (Release Evidence Mesh, SHA-256 plugin signing) that didn't match real repo needs. v3.2.0 is the corrected, simplified, executable plan based on what actually exists and what stakeholders genuinely require.

Three-Repo Ecosystem

CORTEX v3.2.0 operates within a broader ecosystem of three repositories that have distinct but complementary roles:

Foundations.Cortex

The CORTEX engine and governance framework. Contains:

  • 381 orchestrators (the coordination layer)
  • 74 MCP tool files (Python-based stateful engine)
  • 19 core skills unified to 137 total
  • Gate and phase management
  • ADR and decision traceability

adlc-copilot

Feature delivery workflow. Contains 7 agents and 26+ skills focused on the ADLC pipeline. CORTEX delegates delivery TO this repo — it does not reinvent feature workflows. CORTEX is the conductor, adlc-copilot is the implementor.

purple-platform-copilot

Domain expertise library with 78+ skills across 9 domains. Serves as a knowledge source that CORTEX consumes when domain expertise is needed.

Key Decisions Made

Based on an independent GitHub Copilot AI recommendation and stakeholder review, the following decisions were made for v3.2.0:

What We Agreed With

  • 3-wave incremental deprecation: Retire old skills gradually, not with a big-bang archive cutover
  • Agent + Engine complement: Conversational agents (Claude in browser) handle user interaction; Python MCP handles stateful engine logic
  • Reduce gate skills 7 → 4: Keep only real decision points (compliance, traceability, performance, quality)
  • Reduce DoD 76 → 40: Focus on checks that meaningfully impact delivery quality

What We Disagreed With or Removed

  • Release Evidence Mesh (ADR-V3-014 WITHDRAWN): Proposed 8-layer certification for markdown files — overengineered. Real evidence is in git history and test files.
  • Plugin Governance with SHA-256 signing (ADR-V3-013 WITHDRAWN): Premature cryptographic overhead. Not required for v3.2 scope.
  • Surface parity testing (5 IDEs): Out of scope. CORTEX orchestrates, agents render — parity is agent problem, not CORTEX.
  • gate-compliance and gate-traceability skills: Redundant. SKULL hook + CORE plugin + git hooks already cover this.
