### 🧠 Token Synthesis Pseudocode Summary

**Architecture:**
```
User Request → Minimal Header (250 tokens)
                    ↓
         GitHub Copilot (semantic search on-demand)
                    ↓
         [If execution needed] → CORTEX MCP Gateway
                    ↓
         IncrementalContextLoader (load 1-3 relevant files)
                    ↓
         TokenDistillationEngine (compress 80-99%)
                    ↓
         ContextCacheLayer (LRU + TTL)
                    ↓
         ContextSynthesisGateway (budget enforcement)
                    ↓
         Distilled Context → Back to Copilot (≤20K tokens)
```

**Key Algorithms:**

1. **Incremental Loading:**
   - Embed query → Semantic search (cosine similarity)
   - Filter by relevance (≥ 0.8 threshold)
   - Check cache (avoid re-loading)
   - Load top-K (max 3 results)
   - Distill → Cache → Return

2. **Type-Specific Distillation:**
   - **Agent files:** Extract title + version + purpose + capabilities (3 lines)
   - **YAML files:** Remove comments, keep critical keys only
   - **Source code:** AST parsing → Extract signatures + docstrings
   - **Documentation:** Extract headings + first sentence per section

3. **Cache Strategy:**
   - LRU eviction (least recently used)
   - TTL expiration (10 minutes default)
   - Content-hash + mtime keys (prevent stale entries)
   - Hit rate tracking (target ≥ 70%)

4. **Budget Enforcement:**
   - Initial budget: 500 tokens (header + mode logic)
   - Incremental budget: 19,500 tokens (on-demand loading)
   - Emergency trim: Remove lowest-relevance context if exceeded
   - Session tracking: Cumulative tokens across turns
