```
┌─────────────────────────────────────────┐
│         Presentation Layer              │

├─────────────────────────────────────────┤
│         Application Layer               │

├─────────────────────────────────────────┤

├─────────────────────────────────────────┤
│         Infrastructure Layer            │
│  (Data Loading, Cache, Storage, D3)     │
└─────────────────────────────────────────┘
```

**Key Design Patterns:**
- **State Management:** Immutable state with versioning (prevent races)
- **Error Boundaries:** Per-component try-catch with fallback UI
- **Lazy Loading:** Tab-based rendering (only active tab)
- **Dependency Injection:** Adapter pattern for D3, storage
- **Observer Pattern:** Event bus for cross-component communication
- **Strategy Pattern:** Pluggable visualizations
