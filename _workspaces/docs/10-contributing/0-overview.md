## Quick Checklist

Before submitting a pull request:

- [ ] Read Code of Conduct
- [ ] Set up development environment
- [ ] Write failing tests first (TDD)
- [ ] Make tests pass with implementation
- [ ] Follow documentation style
- [ ] Update related docs
- [ ] Verify all tests pass
- [ ] Submit PR with clear description

---

## Key Principles

1. **Test-Driven Development:** Write tests before code
2. **Documentation First:** Document before coding
3. **Single Source of Truth:** One implementation location
4. **Tier Governance:** Respect tier precedence (tier0 immutable)
5. **Production Ready:** All code production-grade
