## Orchestrator Tutorials

   - Time: 30 minutes
   - Learn: State management, sequential steps, error handling

3. **[Error Handling & Resilience](orchestrator-tutorials/3-error-handling.md)**
   - Time: 45 minutes
   - Learn: Circuit breakers, retries, compensation

4. **[Knowledge Integration](orchestrator-tutorials/4-knowledge-integration.md)**
   - Time: 60 minutes
   - Learn: Domain Brain, knowledge queries, tier rules
