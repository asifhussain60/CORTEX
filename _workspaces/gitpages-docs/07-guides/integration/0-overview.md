# Integration Guide

Integrate CORTEX with external systems, build custom orchestrators, and extend functionality.

## Integration Patterns

### REST API Integration
Connect to CORTEX via REST endpoints for orchestrator execution, domain management, and governance queries.

### MCP Protocol Integration
Use Model Context Protocol for AI-native integrations and tool discovery.

### Custom Orchestrators
Build domain-specific orchestrators that leverage CORTEX's governance and resilience patterns.

### Domain Knowledge Integration
Ingest and manage domain knowledge through the Domain Brain interface.

## Key Topics

- **API Integration**: REST endpoints, authentication, response handling
- **Custom Orchestrator Development**: Building orchestrators that follow CORTEX patterns
- **Domain Knowledge Management**: Knowledge ingestion, conflict resolution
- **Monitoring & Observability**: Integration with monitoring systems
