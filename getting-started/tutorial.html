Lesson 1: Setup and First Commands

Step 1: Installation

▼

Clone the repository:

git clone https://github.com/asifhussain60/CORTEX.git
cd CORTEX

Install dependencies:

pip install -r requirements.txt

Configure paths:

Edit cortex.config.json with your machine-specific paths:

{
  "workspace_root": "/path/to/CORTEX",
  "brain_root": "/path/to/CORTEX/cortex-brain",
  "user_repo_root": "/path/to/your/project"
}

Step 2: Your First Command

▼

Open GitHub Copilot Chat in VS Code and say:

help

Expected response: CORTEX command reference with available operations

Try these commands:

  • healthcheck - Check system health
  • introduce yourself - Learn about CORTEX
  • help planning - Planning System commands

Lesson 2: Four-Tier Brain

Understanding the Brain Architecture

▼

CORTEX uses a 4-tier brain for intelligent memory management:

  • Tier 0: Governance (SKULL rules)
  • Tier 1: Working memory (70-conversation FIFO)
  • Tier 2: Knowledge graph (patterns and relationships)
  • Tier 3: Development context (metrics and hotspots)

Lesson 3: Planning System

Creating Your First Plan

▼

Command:

plan user authentication

What happens:

  1. CORTEX analyzes complexity (HIGH/MEDIUM/LOW)
  2. Creates multi-phase plan with TDD integration
  3. Defines DoR/DoD requirements
  4. Generates acceptance criteria
  5. Saves plan manifest to YAML

Execute autonomously:

execute all phases autonomously

Lesson 4: TDD Mastery

RED-GREEN-REFACTOR Workflow

▼

Start TDD workflow:

start tdd email validation

The cycle:

  • RED: Write failing tests (CORTEX validates they fail)
  • GREEN: Implement minimal code (CORTEX checks coverage ≥80%)
  • REFACTOR: Clean code (CORTEX scores quality 0-10)

Git checkpoints: Automatic commits at each phase for safe rollback

Learn more about TDD Mastery →

Lesson 5: ADO Operations

Azure DevOps Integration

▼

Generate ADO work item:

plan ado story user authentication

Output includes:

  • Story title and description
  • Acceptance criteria
  • TDD requirements (RED-GREEN-REFACTOR)
  • Tasks with effort estimates
  • Definition of Ready (DoR)
  • Definition of Done (DoD)

Generate completion summary:

generate ado summary for story 12345

Lesson 6: System Maintenance

7-Phase Maintenance Workflow

▼

Run full maintenance:

system maintenance

Phases executed:

  1. Pre-Healthcheck: Baseline system health
  2. Alignment: Auto-fix common issues
  3. Cleanup: Remove obsolete files
  4. Optimization: Performance tuning
  5. Vacuum: Compact databases
  6. Prompt Refresh: Regenerate documentation
  7. Post-Healthcheck: Validate improvements

Duration: Typically < 5 minutes
