## 🎯 Strategic Context

### Problem Statement

CORTEX currently lacks:
1. **Visual Plan Monitoring** - No real-time view of plan execution progress
2. **Repository Intelligence UI** - AST/code analysis results trapped in JSON
3. **Unified Admin Experience** - Scattered tools across different interfaces
4. **Effectiveness Tracking** - No visibility into plan time estimates vs. actuals

### Dual-Purpose Solution

**CORTEX-LENS serves TWO distinct but complementary goals:**

#### Goal 1: Repository Intelligence (Existing)
- **Purpose:** Reverse-engineer repositories into knowledge bases
- **Users:** Developers understanding unfamiliar codebases
- **Input:** AST scanning, dependency analysis, code metrics
- **Output:** Visual code maps, dependency graphs, architecture diagrams

#### Goal 2: Admin Monitoring (New)
- **Purpose:** Track CORTEX plan execution and effectiveness
- **Users:** Users monitoring active planning orchestrator sessions
- **Input:** Plan metadata, phase progress, acceptance criteria status
- **Output:** Progress dashboards, AC validation reports, time tracking

### Why Merge Them?

**Synergistic Intelligence:**
- Plan phases reference specific files → Link to AST view
- Acceptance criteria map to tests → Show coverage heatmaps
- Time estimates vs. actuals → Identify high-churn code areas
- Knowledge Library queries → Display historical patterns

**Architectural Benefits:**
- Single HTML/CSS/JS codebase (40% dev time savings)
- Unified Glass design system
- Shared navigation and search infrastructure
- One deployment pipeline

**User Mental Model:**
> "CORTEX-LENS is where I **see** what CORTEX knows and does"

### Phase 2: Plan Metadata System (2 Days)

**Goal:** Standardize plan format and enable machine-readable tracking

**Tasks:**
1. ✅ **Define `.cortex-metadata.json` Schema**
   ```json
   {
     "$schema": "http://json-schema.org/draft-07/schema#",
     "type": "object",
     "required": ["plan_id", "title", "status", "phases", "acceptance_criteria"],
     "properties": {
       "plan_id": {"type": "string"},
       "title": {"type": "string"},
       "status": {"enum": ["NOT_STARTED", "IN_PROGRESS", "COMPLETED", "BLOCKED"]},
       "created": {"type": "string", "format": "date-time"},
       "updated": {"type": "string", "format": "date-time"},
       "phases": {
         "type": "array",
         "items": {
           "type": "object",
           "required": ["id", "name", "status", "progress"],
           "properties": {
             "id": {"type": "string"},
             "name": {"type": "string"},
             "status": {"enum": ["NOT_STARTED", "IN_PROGRESS", "COMPLETED"]},
             "progress": {"type": "number", "minimum": 0, "maximum": 100},
             "started": {"type": "string", "format": "date-time"},
             "completed": {"type": "string", "format": "date-time"},
             "tasks": {"type": "array"}
           }
         }
       },
       "acceptance_criteria": {
         "type": "array",
         "items": {
           "type": "object",
           "required": ["id", "description", "status"],
           "properties": {
             "id": {"type": "string"},
             "description": {"type": "string"},
             "status": {"enum": ["PENDING", "IN_PROGRESS", "VALIDATED", "FAILED"]},
             "validated_at": {"type": "string", "format": "date-time"},
             "test_files": {"type": "array", "items": {"type": "string"}}
           }
         }
       },
       "linked_files": {"type": "array", "items": {"type": "string"}},
       "estimated_hours": {"type": "number"},
       "actual_hours": {"type": "number"}

   }
   ```

## 🚧 Risks & Mitigations

| Risk | Impact | Probability | Mitigation |
|------|--------|-------------|------------|
| **Glass design tokens incompatible with HTML** | HIGH | MEDIUM | Convert YAML to CSS custom properties early (Phase 0) |
| **Plan metadata generation breaks existing plans** | HIGH | LOW | Metadata is additive (sidecar files), doesn't modify PLAN.md |
| **Repository Lens AST data incomplete** | MEDIUM | MEDIUM | Graceful degradation (show "AST not available") |
| **Performance degrades with 100+ plans** | MEDIUM | MEDIUM | Pagination, virtualized lists, local storage caching |
| **Cross-linking breaks if file paths change** | LOW | MEDIUM | Store relative paths, validate on load |
