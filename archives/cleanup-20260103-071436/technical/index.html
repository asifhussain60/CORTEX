Architecture

4-Tier Brain

CORTEX uses a hierarchical 4-tier brain architecture for memory management and knowledge organization:

Tier 0

Governance: Core rules, templates, system-wide policies

Tier 1

Working Memory: Active conversations, current context

Tier 2

Knowledge Graph: Relationships, patterns, insights

Tier 3

Dev Context: Project-specific knowledge

Execution Agent

Code implementation, testing, and tactical operations

API Reference

📋 Planning System

plan [task description]

Creates a strategic plan with 4 subfolders: Design, Implementation, Testing, Documentation

🔴 TDD Mastery

tdd [feature description]

Starts TDD workflow: RED (failing test) → GREEN (minimal implementation) → REFACTOR (clean code)

🔧 Maintenance

system maintenance

Runs 6-phase health check: Diagnostics, Cleanup, Optimization, Validation, Documentation, Reporting

🎯 Strategic Agent

Handles architecture design, requirement analysis, and high-level planning decisions

⚡ Execution Agent

Executes code implementation, runs tests, and performs tactical development operations

Workflows

📋 Planning Workflow

  1. Analyze user request and break down into components
  2. Create planning structure with 4 subfolders
  3. Generate Design, Implementation, Testing, Documentation plans
  4. Present structured plan for user approval
  5. Execute plan phase by phase with checkpoints

🔴 TDD Cycle

RED: Write failing test that defines desired behavior

GREEN: Write minimal code to make test pass

REFACTOR: Clean up code while keeping tests green

🔧 Maintenance

  1. Phase 1 - Diagnostics: Analyze system health metrics
  2. Phase 2 - Cleanup: Remove obsolete files and artifacts
  3. Phase 3 - Optimization: Improve performance and efficiency
  4. Phase 4 - Validation: Run tests and verify integrity
  5. Phase 5 - Documentation: Update docs and comments
  6. Phase 6 - Reporting: Generate health report

Guides

🚀 Quick Start

  1. Say "help" in Copilot Chat to see all operations
  2. Use "plan [task]" for complex multi-step work
  3. Use "tdd [feature]" for test-driven development
  4. Use "system maintenance" for health checks

🤝 Copilot Integration

CORTEX integrates with GitHub Copilot through .github/copilot-instructions.md and .github/prompts/ directory. All intent routing is defined in CORTEX.prompt.md.

🌐 Deployment

  1. Documentation server: ./scripts/launch_docs.sh
  2. Access at: http://localhost:8000
  3. Publish docs: See cortex-brain/publish-config.yaml

🔍 Troubleshooting

  • Check cortex-brain/brain-protection-rules.yaml for SKULL rules
  • Review cortex-brain/lessons-learned.yaml for common issues
  • Run system maintenance for automated diagnostics
  • Check logs in logs/ directory
