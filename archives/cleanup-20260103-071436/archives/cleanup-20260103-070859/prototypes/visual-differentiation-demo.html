Improvements Based on NN/g Research

  • 3-D Visual Cues (NN/g Tested): Clickable tiles elevated with multi-layer shadows, display tiles recessed with inset shadows
  • Border Differentiation: 2px colored border on clickable (stronger affordance), 1px muted on display
  • Gradient Direction: Light-to-dark on clickable (raised), dark-to-light on display (sunken)
  • Cursor Signaling: Pointer cursor on clickable (universal web convention since 1990s)
  • Hover Lift Animation: Clickable rises further on hover (reinforces interactivity)
  • Chevron Arrow: Always visible at 70% opacity (motion on hover = interaction cue)
  • Icon Brightness: Clickable icons brighter (80% opacity display vs 100% clickable)
  • Consistent Treatment: All clickable elements share identical visual language
li>INSTANT Recognition: Clickable tiles appear raised/elevated, display tiles appear recessed/embedded
  • Depth Perception: Outset shadow on clickable (pressable button), inset shadow on display (sunken panel)
  • Border Accent: Subtle cyan tint on clickable borders signals interactivity
  • Cursor Change: Pointer on clickable, default on display tiles
  • Press Feedback: Clickable tiles push down on active state (tactile feel)
  • Chevron Indicator: Always-visible chevron on clickable tiles (brightens on hover)
  • Glass Reflection: Display tiles have slow 8s shine animation for visual interest
