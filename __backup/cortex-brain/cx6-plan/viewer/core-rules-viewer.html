Recovery: Implement governance compliance checklist
🟡 CRITICAL Violations
Consequence: Audit alert, operation proceeds with warning
Examples: Hardcoded paths, missing TDD tests
Recovery: Implement corrective actions, log audit entry
🟢 HIGH Violations
Consequence: Audit log entry, operation proceeds
Examples: Missing documentation, incomplete tests
Recovery: Asynchronous correction, tracked for later

Outcome: Prevents false positives reaching production
