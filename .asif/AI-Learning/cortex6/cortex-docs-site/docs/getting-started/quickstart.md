## Prereqs

- Node 20+ (for this docs site)
- npm or pnpm

## Run the docs site

```bash
npm install
npm run start
```

## Deploy to GitHub Pages

1. Update `docusaurus.config.js`:
   - `url`
   - `baseUrl`
   - `organizationName`
   - `projectName`

2. Push to `main`.

3. In GitHub repo settings → Pages → Source: **GitHub Actions**.
