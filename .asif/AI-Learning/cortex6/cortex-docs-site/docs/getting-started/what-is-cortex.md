---
title: What is CORTEX?
---

CORTEX is an orchestration framework for AI‑assisted development. It takes a user request (e.g., *“plan OAuth2 for patient portal”*)
and turns it into **governed, ordered work**:

1. **Merge governance** from four sources into one unified instruction set.
2. **Route intent** to the right workflow orchestrator.
3. **Generate TODOs** as a DAG (Directed Acyclic Graph) with dependencies.
4. **Execute safely** with audit logging, checkpoints, rollback, and resource limits.

CORTEX is designed so “smart” never becomes “reckless”.
