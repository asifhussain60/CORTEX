---
title: The 4 Governance Categories
---

## Category 1 — CORTEX Tier 0 (Core Brain Protection)

Immutable universal rules (e.g., TDD enforcement, planning isolation, audit logging, git isolation, incremental execution).  
Override is **not allowed** except in the specific “business compliance wins” case.

## Category 2 — Business Tier 0 (Company Governance)

Company policies and compliance (HIPAA/PCI/SOX/GDPR).  
Can override CORTEX **only** for compliance-related conflicts.

## Category 3 — Company Best Practices (Engineering Standards)

Coding conventions, architecture preferences, testing standards, documentation standards.  
May tighten defaults but must not contradict core governance.

## Category 4 — Knowledge Best Practices (Learned Intelligence)

Learned patterns and lessons learned. Advisory only; lowest priority.
