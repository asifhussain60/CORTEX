---
title: Merge Algorithm
---

The merge algorithm transforms 4 sources into one Unified Instruction Set.

### Steps

1. Load sources (Tier 0 + optional repo governance + knowledge patterns)
2. Categorize rules (COMPLIANCE, SECURITY, ENGINEERING, ADVISORY)
3. Detect conflicts (override / extension / advice)
4. Resolve conflicts
5. Generate the unified set
6. Validate (no circular deps, enforcement present, no contradictions)
