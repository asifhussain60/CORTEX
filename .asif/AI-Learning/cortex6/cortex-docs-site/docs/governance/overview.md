---
title: Governance Overview
---

CORTEX governance is how the system stays honest.

A user request loads governance rules from four sources, merges them, validates the result, and outputs a **Unified Instruction Set** that drives orchestrators and TODO generation.

The goal is not “more rules.” The goal is **actionable intelligence**:

- what TODOs to create
- what constraints to enforce
- what order to execute tasks
- which patterns to apply
