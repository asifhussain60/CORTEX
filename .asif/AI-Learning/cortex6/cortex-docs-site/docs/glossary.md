title: Glossary
---

- **DAG**: Directed Acyclic Graph — dependency graph that never loops.
- **MCP**: Model Context Protocol — here used as JSON‑RPC 2.0 server + clients for standardized calls.
- **Tier 0**: immutable core governance rules.
- **Unified Instruction Set**: merged governance output that drives orchestration and TODO generation.
- **Planning Isolation**: planning creates structure; no implementation in planning.
