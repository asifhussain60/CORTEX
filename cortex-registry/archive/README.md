# Archive Directory

This directory contains historical files from the CORTEX Registry that have been superseded by newer implementations.

## Structure

### `old-docs/`
Documentation files from previous registry organization attempts:
- `DIRECTORY-STRUCTURE-FINAL.md` - Early registry structure proposal
- `STRUCTURE-CORRECTED.md` - Corrected structure documentation

### `old-html/`
Previous HTML implementations that have been replaced:
- `index-old-knowledge-hub.html` - Original static knowledge hub (replaced by YAML Reader)
- `index.html.backup` - Backup of index.html during YAML Reader development

## Current Active Files

The active registry now uses:
- `.yaml-reader/` - Modern offline YAML Reader SPA (Phase 104)
- `manifest.yaml` - Registry metadata and configuration
- `master-index.yaml` - Registry master index
- `launch-yaml-reader.sh` - Quick launcher for YAML Reader

## Phase 104 Context

These files were archived as part of **Phase 104: Registry Intelligence Consolidation**, which replaced the static knowledge hub with a dynamic, offline-capable YAML exploration tool.

## Restoration

If you need to restore any of these files, they are preserved as-is in their respective subdirectories.
