## 🎯 Key Separation Principles

### 1️⃣ `` - CORTEX Internal

| Folder | Purpose | Example |
|--------|---------|---------|
| `core/governance/` | CORTEX CORE rules (CORE-001 to CORE-056) | `core-rules.yaml` |
| `phases/planned/` | Future CORTEX phases | `phase-103-registry-intelligence-consolidation.yaml` |
| `knowledge/` | CORTEX internal KB (orchestrator specs) | `config/orchestrator_specs.json` |
| `baselines/` | CORTEX development baselines | `pre-phase38-baseline-*.json` |

**Consumer:** `cortex-architect.prompt.md` + CORTEX agents

### 2️⃣ `planning/` - User Production Work

| Folder | Purpose | Example |
|--------|---------|---------|
| `phases/` | User repo phases (NOT phase-*.yaml) | `api-v2-migration.yaml` |
| `workflows/` | User workflow templates | `cicd-pipeline.yaml` |
| `templates/` | User planning templates | `feature-template.yaml` |

**Consumer:** Users planning work for their GitHub repos

### 3️⃣ `knowledge-base/` - Onboarded Repo KB

**Generated by:** `cortex_onboard_repository_v3` tool (LENS extraction)  
**Purpose:** Store LENS-analyzed knowledge from user production repos
