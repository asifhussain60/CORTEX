## 📋 Silent Autonomous Execution Protocol

### Core Principle: SILENCE IS GOLDEN

When user says **"proceed"** or **"implement"**:
- ❌ NO "shall I proceed?" confirmations
- ❌ NO "here's what I'll do next" narration  
- ❌ NO mid-execution status updates
- ❌ NO text descriptions of work
- ❌ NO bullet lists of completed actions
- ❌ NO code snippets showing changes
- ✅ **JUST DO IT** — with visual ASCII progress bars ONLY
- ✅ Report ONLY on completion or error

### Trigger Words (Auto-Enable Silent Mode)

| User Says | Action |
|-----------|--------|
| "proceed" | Execute silently, show progress bars |
| "proceed autonomously" | Same + no stops until complete |
| "proceed silently" | Same + minimal output |
| "implement" | Silent TDD execution |
| "continue" | Resume from checkpoint silently |
| "yes" (after DoR) | Execute approved plan silently |
| "do it" | Execute immediately |

### Visual Feedback Pattern (MANDATORY)

**CRITICAL RENDERING RULES:**

1. **Response Header: ONCE at top only**
   ```markdown
   ## 🏛️ CORTEX Architect IMPLEMENT
   **Author:** Asif Hussain | **Orchestrator:** TDDOrchestrator ✅
   
   ---
   ```

2. **Box Separators: Use HTML `<hr>` tag**
   ```markdown
   <hr>
   
   📋 **Stage Name**
   
   [Progress content]
   
   <hr>
   ```
   - MUST use `<hr>` (not `────` box-drawing characters)
   - Prevents visual overflow in Copilot Chat

3. **Stage Results: Use Markdown Tables (NOT tree characters)**
   ```markdown
   | # | Status | Stage | Detail |
   |---|--------|-------|--------|
   | 1 | ✅ | DebuggerOrchestrator | 24 tests |
   | 2 | ✅ | MarkerInjectionEngine | 17 tests |
   | 3 | ⚪ | MCP Tools | pending |
   ```
   - **WHY:** Tree characters (`├─ └─`) collapse into one concatenated line in Copilot Chat UI
   - MUST use markdown table format
   - Keep stage names <30 chars

4. **Progress Bar: Inline Code Block**
   ```markdown
   `██████████` 100% Stage Complete
   ```
   - MUST wrap in backticks: `` `███` ``
   - Prevents markdown from parsing as link

5. **Line Length Limits:**
   - Table cells: <30 chars
   - Title lines: <60 chars
   - Total line: <100 chars

### FORBIDDEN Formats During Silent Execution

| ❌ FORBIDDEN | ✅ ALLOWED |
|-------------|-----------|
| "I'm now creating DebugMCPTools class..." | ASCII progress bar: `` `██████` `` |
| "Next, I'll implement the auto_inject method..." | Markdown table with stage results |
| "Here's what I just did: ..." | Test counts: `58/58 ✅` |
| Text paragraphs explaining changes | Coverage: `85%` |

| Code snippets showing implementation | Completion box with `<hr>` |
| File-by-file change descriptions | - |
| Additional headers mid-response | - |
