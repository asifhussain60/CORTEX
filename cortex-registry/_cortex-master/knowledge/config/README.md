# Configuration

System configuration files for CORTEX.

## Contents

- `master-plan.yaml` - Overall system planning
- `execution-queue-config.yaml` - Task execution settings
- `orchestrator_specs.json` - Orchestrator specifications
- `mcp-tool-audit-matrix.yaml` - MCP tool tracking
- `workflows-index.yaml` - Workflow definitions

## Usage

Modify these files to adjust system behavior. Always validate YAML syntax before committing.
