### Request 3: MCP Registry Dual-Registry Issue

**User Request:**
> "I restarted vscode. Fix the cortex MCP all work should be done only via mcp"

**Actions Taken:**

- ✅ Updated MCP server to call bridge at startup

- ✅ All 7 existing tests passing
