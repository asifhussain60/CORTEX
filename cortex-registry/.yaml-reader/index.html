CORTEX Registry YAML Reader

A fully offline YAML viewer designed for the file:// protocol. Load, explore, and visualize YAML files with zero HTTP dependencies.

💡 Pro Tips:
• Drag & drop multiple YAML files anywhere
• Press / to search within content
• Press Esc to clear search
• Files are never uploaded - all processing is local
⚠️ Browser Limitations:
Under file:// protocol, clipboard access requires user interaction. Some features may prompt for permissions on first use.
