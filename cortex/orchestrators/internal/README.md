# CortexDocsOrchestrator - Internal Documentation Generator

**Status:** ✅ COMPLETE | **Tests:** 19/19 PASSING | **Mode:** Internal Only (NOT MCP-Exposed)

---

## 🎯 Purpose

`CortexDocsOrchestrator` is an **internal CORTEX tooling orchestrator** dedicated to generating and maintaining HTML documentation for the CORTEX repository (`docs/` folder).

**Key Distinction:**
- ❌ **NOT for production MCP** — Not exposed to external repositories
- ✅ **CORTEX-internal only** — Maintains `docs/index.html` and subfolder indexes
- ✅ **Approved design system** — Dark blue glassmorphism theme from existing `docs/index.html`

---

## 🏗️ Architecture

### Separation from Production

| Orchestrator | Purpose | MCP Exposed | Scope |
|--------------|---------|-------------|-------|
| **CortexDocsOrchestrator** | CORTEX `docs/` HTML generation | ❌ NO | Internal tooling |
| **DocumentationOrchestrator** | Markdown docs for any repo | ✅ YES | Production MCP tool |

**Why Separate?**
1. **Clear Boundary** — Internal tooling ≠ production features
2. **ARCH-007 Compliance** — Production stays MCP-first; internal can use direct imports
3. **Maintenance Isolation** — CORTEX docs changes don't affect production
4. **CORE-035 Preservation** — Single canonical purpose per orchestrator

## 🔧 Usage

### 1. Extract Templates

```python
from cortex.orchestrators.internal import get_cortex_docs_orchestrator

orchestrator = get_cortex_docs_orchestrator()

# Extract Jinja2 templates from docs/index.html
result = orchestrator.execute("extract_template")

if result.is_ok():
    print(f"Templates created: {result.value['templates_created']}")
```

### 2. Generate Main Index

```python
# Generate docs/index.html
result = orchestrator.execute("generate_main")

if result.is_ok():
    print(f"Generated: {result.value}")
```

### 3. Generate Subfolder Indexes

```python
# Generate index.html for all subfolders
result = orchestrator.execute("generate_subfolders")

if result.is_ok():
    for file in result.value:
        print(f"Generated: {file}")
```

### 4. Generate All

```python
# Extract templates + generate all HTML files
result = orchestrator.execute("generate_all")

if result.is_ok():
    report = result.value
    print(f"Generated {len(report.generated_files)} files")
    print(f"Total size: {report.total_size_bytes // 1024} KB")
    print(f"Time: {report.generation_time_seconds:.2f}s")
```

### 5. Validate HTML

```python
# Validate generated HTML
result = orchestrator.execute("validate")

if result.is_ok():
    validation = result.value
    if validation["valid"]:
        print("✅ All HTML valid")
    else:
        print(f"⚠️ Issues found: {validation['issues']}")
```
