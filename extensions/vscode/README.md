## 🔧 Troubleshooting

### Command Not Found
**Problem:** "CORTEX commands not appearing in Command Palette"

**Solution:**
1. Verify extension is installed: Extensions panel → Search "CORTEX"
2. Reload VS Code: `Developer: Reload Window`
3. Check output channel: `View → Output → CORTEX`

### Python Execution Errors
**Problem:** "Python executable not found" or "CORTEX script execution failed"

**Solution:**
1. Open Configuration UI
2. Click "Auto-Detect" or manually enter Python path
3. Test with: `python3 --version` in terminal
4. Ensure Python 3.8+ is installed
5. Click "Validate" to verify configuration

### CORTEX Not Detected
**Problem:** "CORTEX installation not detected"

**Solution:**
1. Verify CORTEX is cloned/installed locally
2. Open Configuration UI
3. Manually set CORTEX path (e.g., `/Users/you/PROJECTS/CORTEX`)
4. Check for these markers:
   - `cortex-brain/` directory exists
   - `manifests/` directory exists
   - `src/` directory exists
5. Click "Validate" to verify

### Dashboard Empty or Stale
**Problem:** "Dashboard shows no data or outdated information"

**Solution:**
1. Check `cortex.autoRefreshDashboard` setting (should be `true`)
2. Click "Refresh" button in dashboard
3. Verify CORTEX brain directories exist:
   - `cortex-brain/tier0/`
   - `cortex-brain/tier1/`
   - `cortex-brain/tier2/`
   - `cortex-brain/tier3/`
4. Check output channel for errors

### Copilot Integration Not Working
**Problem:** "Natural language commands not recognized"

**Solution:**
1. Verify GitHub Copilot extension is installed
2. Check `cortex.enableCopilotIntegration` setting (should be `true`)
3. Use prefix: `@cortex` in Copilot Chat
4. Check confidence threshold (0.7 minimum)
5. Try more explicit commands: "create a plan" vs "make plan"

### Command Execution Hangs
**Problem:** "Command starts but never completes"

**Solution:**
1. Check Python process in Activity Monitor/Task Manager
2. Verify Python script paths are correct
3. Check for infinite loops in CORTEX orchestrators
4. Increase timeout (default 30s) in code if needed
5. Check output channel for error messages

## 🏗️ Architecture

### Extension Structure
```
extensions/vscode/
├── src/
│   ├── extension.ts              # Entry point, activation
│   ├── commands/
│   │   └── index.ts              # Command registration (11 commands)
│   └── utils/
│       ├── outputChannel.ts      # Logging (singleton)
│       ├── pythonExecutor.ts     # Python subprocess execution
│       ├── workspaceDetector.ts  # CORTEX installation detection
│       ├── dashboardProvider.ts  # Webview dashboard
│       ├── copilotIntegration.ts # Natural language parsing
│       └── configurationProvider.ts # Settings UI
├── package.json                  # Extension manifest
├── tsconfig.json                 # TypeScript configuration
└── README.md                     # This file
```

### Key Components

**PythonExecutor:**
- Spawns Python subprocesses for CORTEX operations
- 30-second timeout protection
- Stdout/stderr streaming to output channel
- Path validation and configuration

**WorkspaceDetector:**
- Multi-source CORTEX path resolution
- Workspace type classification (CORTEX repo vs user)
- Validation of installation markers
- Configuration integration

**DashboardProvider:**
- Webview panel management
- Brain health metrics (tier0-3)
- Recent operations list (last 10)
- Planning folder browser
- Quick action buttons

**CopilotIntegration:**
- 40+ intent regex patterns
- Confidence scoring (0.7-0.9 thresholds)
- Context provider for Copilot Chat
- File system watcher for brain state

**ConfigurationProvider:**
- Settings webview UI
- Auto-detection of Python/CORTEX paths
- Validation with error/warning messages
- Save/load/reset functionality
