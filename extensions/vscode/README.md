# CORTEX - AI Development Intelligence

Transform GitHub Copilot into a strategic development partner with long-term memory, TDD mastery, and autonomous orchestration.

## ✨ Features

### 🎯 Strategic Planning
- **Smart Planning System**: Create comprehensive 4-folder planning structures (strategy, tasks, tracking, research)
- **Multi-Repo Support**: Seamlessly work across multiple repositories with intelligent context switching
- **Adaptive Templates**: Automatically selects appropriate planning templates based on project type

### 🧪 TDD Mastery
- **RED → GREEN → REFACTOR**: Automated TDD workflow with SKULL enforcement
- **Test-First Development**: CORTEX ensures tests fail before implementation (prevents cheating)
- **Continuous Validation**: Auto-runs tests after every code change

### 🛠️ Development Orchestrators
- **System Maintenance**: 6-phase health check (dependencies, logs, brain cleanup, performance, security)
- **Code Sanitization**: 5-phase cleanup (remove secrets, generic placeholders, standard formatting)
- **Refinement Engine**: 7-phase improvement (architecture, performance, security, documentation)
- **ADO Integration**: Azure DevOps planning workflows (epics, features, stories, tasks)

### 🧠 4-Tier Brain Architecture
- **Tier 0**: Governance (SKULL rules, templates, manifests)
- **Tier 1**: Working memory (active plans, conversations, tracking)
- **Tier 2**: Knowledge graph (lessons learned, best practices)
- **Tier 3**: Development context (workspace relationships, user dictionaries)

### 💬 GitHub Copilot Enhancement
- **@cortex Chat Participant**: Use `@cortex` in Copilot Chat for intelligent routing
- **Context-Aware Responses**: CORTEX injects brain data into Copilot conversations
- **Command Suggestions**: Auto-completes CORTEX operations in chat

### 📊 Visual Dashboard
- **Brain Health Metrics**: Token usage, active plans, knowledge graph size
- **Recent Activity**: Last 10 operations with timestamps
- **Quick Actions**: One-click access to help, onboarding, maintenance

## 🚀 Quick Start

### Prerequisites
- VS Code 1.85.0 or higher
- GitHub Copilot extension
- Python 3.8+

### Installation
1. Install from VS Code Marketplace (search "CORTEX")
2. Run `CORTEX: Interactive Onboarding` from Command Palette
3. Configure Python path in settings (auto-detected if in PATH)

### First Steps
1. Open your project in VS Code
2. Press `Ctrl+Shift+P` → `CORTEX: Show Help`
3. Try `@cortex` in Copilot Chat: "plan a REST API feature"
4. Use `CORTEX: Create Planning Folder` for structured planning

## 📦 Commands

| Command | Description | Shortcut |
|---------|-------------|----------|
| `CORTEX: Show Help` | Open comprehensive help guide | - |
| `CORTEX: Create Planning Folder` | Generate 4-folder planning structure | - |
| `CORTEX: Start TDD Workflow` | Begin RED → GREEN → REFACTOR cycle | - |
| `CORTEX: Run System Maintenance` | Execute 6-phase health check | - |
| `CORTEX: Sanitize Code` | Remove secrets, apply generic placeholders | - |
| `CORTEX: Run Refinement` | Improve architecture, performance, security | - |
| `CORTEX: Interactive Onboarding` | Step-by-step setup wizard | - |
| `CORTEX: ADO Planning` | Azure DevOps work item creation | - |
| `CORTEX: Show Dashboard` | View brain metrics and quick actions | - |

## ⚙️ Configuration

```json
{
  "cortex.pythonPath": "",  // Auto-detected if empty
  "cortex.cortexPath": "",  // Auto-detected if empty
  "cortex.enableCopilotIntegration": true,
  "cortex.autoRefreshDashboard": true
}
```

## 🛡️ SKULL Protection

CORTEX enforces 3 brain protection rules:
1. **TDD_ENFORCEMENT**: Tests must fail before implementation
2. **HOLISTIC_DISCOVERY**: Search before create (prevent duplication)
3. **GIT_ISOLATION**: CORTEX code never commits to user repos

## 🌐 Multi-Repo Usage

### Method 1: Reference in Chat
```
@cortex "Using workspace at D:\PROJECTS\my-api, create planning folder for authentication feature"
```

### Method 2: Multi-Folder Workspace
1. File → Add Folder to Workspace
2. Add all repos (CORTEX + your projects)
3. CORTEX auto-detects context from active file
