GOVERNANCE ENFORCEMENT
───────────────────────────────────────────────────────────────────────────────

Every implementation MUST comply with:

CORE-008: TDD (Tests Before Code)
  ✓ Review test expectations before implementation
  ✓ Understand what tests expect the code to do
  ✓ Implement to match test expectations exactly

CORE-011: Type Hints (100% Coverage)
  ✓ Every function parameter typed
  ✓ Every return type specified
  ✓ No use of generic Any type
  ✓ Example:
      def process_data(input: List[str], mode: OperationMode) -> Result[Dict]:
          """Process data according to operation mode."""

CORE-012: Google Docstrings
  ✓ All public APIs documented
  ✓ Format with Args, Returns, Raises sections
  ✓ Example:
      """Process conversation turn.
      
      Args:
          turn: The conversation turn to process.
          context: Current conversation context.
      
      Returns:
          Result containing processed turn or error.
      
      Raises:
          ValueError: If turn data is invalid.
      """

CORE-013: Specific Exception Handling
  ✓ NO bare except:
  ✓ NO except Exception:
  ✓ ONLY: except (SpecificError1, SpecificError2):

CORE-026: Git Checkpoints
  ✓ Before phase: git commit -m "checkpoint: before phase-X"
  ✓ After phase:  git commit -m "complete: phase-X"
