THE SYSTEM ORGANIZES FILES BY:

1. FILE TYPE (Destination Mapping):
   - Executive docs → docs/executive/
   - Phase docs → docs/phases/
   - Review docs → docs/reviews/
   - Status docs → docs/
   - Reports → reports/
   - Scripts → scripts/
   - Config → config/

2. NAMING CONVENTION (kebab-case, ≤20 chars):
   - All lowercase
   - No spaces
   - No adjectives/pronouns (old, new, fixed, enhanced, etc.)
   - Use abbreviations (verify, impl, exec, arch)
   - Example: EXECUTIVE-BRIEF-FOR-DECISION.md → executive-brief.md

3. CLEANUP (Automatic Deletion):
   - Backup files: *.bak, *.backup, *-old*, *-new*
   - Temp files: *.tmp, *.temp, *-temp*
   - Python cache: *.pyc, __pycache__/

================================================================================
                            MCP INTEGRATION
================================================================================

Three MCP tools are exposed:

1. vacuum_analyze(repo_root, output_dir=None)
   - Run analysis and generate reports
   - Returns: Analysis report dictionary
   
2. vacuum_execute(repo_root, migration_plan, dry_run=True, auto_approve=False)
   - Execute migration with safety guarantees
   - Returns: Execution report dictionary
   
3. vacuum_verify(repo_root)
   - Verify repository compliance
   - Returns: Compliance report dictionary

Register with MCP:
   from src.mcp.tools import register_vacuum_tools
   registry.register_tool(register_vacuum_tools)
