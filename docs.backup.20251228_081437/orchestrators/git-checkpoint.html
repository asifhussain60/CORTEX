Git Checkpoint Orchestrator

Production Ready

The Git Checkpoint Orchestrator is your safety net—it automatically creates git checkpoints at key workflow milestones, enabling instant rollback if something goes wrong. With smart retention policies (30 days max, 50 checkpoints), trigger-based automation (before/after implementation, TDD phases, plan completion), and safety checks for uncommitted changes, you'll never lose work or get stuck in an unrecoverable state.

🗄️ Retention Policy

Rule Value Description
Max Age 30 days Auto-delete checkpoints older than 30 days
Max Count 50 Keep maximum 50 checkpoints per repository
Grace Period 3 days Minimum retention before any cleanup
Named Checkpoints Preserved User-named checkpoints never auto-deleted
Tagged Checkpoints Preserved Checkpoints with custom tags never deleted
Cleanup Interval 24 hours Automatic cleanup runs daily

📋 Example Checkpoint Metadata

YAML 
checkpoint:
  name: "tdd-green-20251227-151234"
  type: "tdd_green"
  timestamp: "2025-12-27T15:12:34Z"
  
  metadata:
    commit_hash: "a1b2c3d4e5f6"
    branch_name: "feature/oauth-integration"
    user_message: "Implementing OAuth token refresh"
    cortex_operation: "tdd"
    
  files_modified:
    - "src/auth/oauth_handler.py"
    - "tests/test_oauth.py"
    
  diff_stats:
    insertions: 45
    deletions: 12
    files_changed: 2
    
  storage:
    location: "git-tags"
    annotation: true
    pushed_to_remote: false
    
  rollback_command: "git reset --hard tdd-green-20251227-151234"
  
  retention:
    age_days: 3
    preserve: false
    cleanup_eligible: false
