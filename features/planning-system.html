What is the Planning System?

The Planning System is CORTEX's intelligent feature planning orchestrator that transforms user requests into structured, test-driven implementation plans. It automatically classifies complexity, discovers existing plans to avoid duplication, and generates tier-appropriate documentation—all while enforcing TDD principles from the start.

🎯 Core Capability: Converts feature requests into structured plans with automatic complexity detection (4 tiers: INSTANT→LIGHTWEIGHT→DOCUMENTED→COMPLEX), TDD integration, and zero overhead for simple tasks.

The system operates through 4 core phases:

  1. Phase 1 - Classification & Analysis: Automatically classifies operations into one of 4 tiers based on complexity dimensions (component count, dependencies, external integrations)
  2. Phase 2 - Pre-Planning Discovery: Searches for existing/recent plans to prevent duplication and unnecessary work
  3. Phase 3 - Tiered Execution: Executes tier-appropriate planning workflow (INSTANT=no artifacts, LIGHTWEIGHT=inline notes, DOCUMENTED=full folder, COMPLEX=multi-phase with gates)
  4. Phase 3.5 - TDD Integration: Automatically integrates RED→GREEN→REFACTOR workflow for Tier 2+ operations
  5. Phase 4 - Validation & Storage: Validates plan completeness and stores in cortex-brain/documents/planning/ with structured folder hierarchy

Key Benefits

⚡ Zero Overhead for Simple Tasks

Tier 1 operations (simple queries, file reads) execute immediately with no planning artifacts. The system knows when planning overhead isn't justified.

🎯 Automatic Complexity Detection

No need to manually decide planning depth. The system analyzes component count, dependencies, external integrations, and security concerns to classify operations automatically.

🧪 TDD-First Workflow

Test cases are generated and validated (RED state) before implementation begins for Tier 2+ operations. No more retrofitting tests after code is written.

🔍 Smart Duplication Prevention

Pre-planning discovery checks cortex-brain for existing or recent plans before creating new ones, preventing redundant work and promoting plan reuse.

📁 Structured Storage

Plans stored in cortex-brain with consistent 4-subfolder structure (context/, reports/, tracking/, artifacts/) for easy retrieval and knowledge management.

📊 Scalable Planning

From 30-second instant operations to multi-hour complex features with phase gates—the same system handles all complexity levels with appropriate planning depth.

Example: OAuth2 Authentication Feature

User Request: "Create a user authentication system with OAuth2"

System Response:

  1. Phase 1 (Classification): Detects Tier 4: COMPLEX — multiple components, external OAuth2 provider integration, security concerns, 20+ implementation steps
  2. Phase 2 (Discovery): Searches cortex-brain/documents/planning/ for existing OAuth2 plans, finds none, proceeds with new plan creation
  3. Phase 3 (Execution): Creates full planning folder at cortex-brain/documents/planning/active/oauth-authentication/ with 4 subfolders, generates master plan with implementation phases, architecture documentation, and risk assessment
  4. Phase 3.5 (TDD): Generates comprehensive test suite (test_oauth_config, test_token_exchange, test_refresh_flow, test_user_session) and validates RED state before implementation
  5. Phase 4 (Validation): Validates all required plan components present, stores validated plan in cortex-brain, updates knowledge graph with new OAuth2 planning pattern

Result: Complete implementation plan with architecture diagrams, phased delivery schedule, test coverage targets, and security considerations—ready for Execution Orchestrator to implement autonomously.
