# CortexLabs FinTrack — Refactored (CORTEX Manifest)

## Overview

This is the **CORTEX-refactored** version of BadMonolith, demonstrating the application of 8 workflow templates to resolve 25 intentional code smells.

## Smell Resolution Summary

| Original Files | Refactored Structure | Smells Resolved |
|----------------|---------------------|-----------------|
| 591-line `Program.cs` | 50-line `Program.cs` + Controllers + Services | SMELL-3, 4, 17 |
| 2 circular-dep services | DI-wired interface-based services | SMELL-5 |
| SQL string concatenation | EF Core parameterized queries | SMELL-1 |
| Hardcoded secrets | Environment config placeholders | SMELL-2 |
| 466-line `app.ts` | Modular services + main.ts | SMELL-21, 23, 24 |
| Inline `<style>` | Extracted `styles.css` | SMELL-21 |
| `any` types | Strict TypeScript | SMELL-22 |
| Duplicate validation | `ValidationService` (both ends) | SMELL-10 |

## Workflow Templates Applied

1. **csharp-refactor-workflow.yaml** — SOLID decomposition
2. **csharp-security-workflow.yaml** — SQL injection, secrets
3. **typescript-refactor-workflow.yaml** — strict mode
4. **css-zero-inline-workflow.yaml** — CSS extraction
5. **duplicate-validation.yaml** — consolidated validation

## Running

```bash
# Backend
cd backend && dotnet run

# Frontend  
cd frontend && npm install && npm run dev
```

## Verification

```bash
# Backend tests
cd backend/Tests && dotnet test

# TypeScript type check
cd frontend && npx tsc --noEmit
```
