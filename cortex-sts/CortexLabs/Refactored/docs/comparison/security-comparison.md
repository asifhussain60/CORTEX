## SQL Injection — Before vs After

### Before (4 injection points)

```mermaid
sequenceDiagram
    participant Attacker
    participant API as BadMonolith API
    participant DB as SQLite

    Attacker->>API: GET /api/users/search?username=' OR '1'='1
    Note over API: cmd.CommandText = $"SELECT * FROM Users<br/>WHERE user_name = '{username}'"
    API->>DB: SELECT * FROM Users WHERE user_name = '' OR '1'='1'
    DB-->>API: ALL ROWS RETURNED
    API-->>Attacker: 200 OK — all user data including password_hash

    Note over Attacker,DB: 🔴 CRITICAL — Full database dump via URL parameter
```

### After (0 injection points)

```mermaid
sequenceDiagram
    participant Client
    participant API as Refactored API
    participant Repo as UserRepository
    participant DB as SQLite

    Client->>API: GET /api/v1/users?page=1&pageSize=20
    API->>Repo: GetAllAsync(page, pageSize)
    Note over Repo: cmd.Parameters.AddWithValue("@Limit", pageSize)<br/>cmd.Parameters.AddWithValue("@Offset", offset)
    Repo->>DB: SELECT ... FROM Users LIMIT @Limit OFFSET @Offset
    DB-->>Repo: Paginated rows (no password_hash)
    Repo-->>API: IReadOnlyList<User>
    API-->>Client: 200 OK — UserDto (password excluded)

    Note over Client,DB: 🟢 SAFE — Parameterized queries + DTO projection
```

## Security Scorecard

| Category | Before | After | Severity |
|----------|--------|-------|----------|
| SQL Injection | 4 endpoints vulnerable | 0 — all parameterized | 🔴 P0 → 🟢 Fixed |
| Password Storage | Plaintext in DB | SHA256 + random salt | 🔴 P0 → 🟢 Fixed |
| Password Exposure | Returned in GET /api/users | Excluded from UserDto | 🔴 P0 → 🟢 Fixed |
| Secrets in Config | JWT key, SMTP, API keys hardcoded | Placeholder + env vars | 🔴 P0 → 🟢 Fixed |
| Error Disclosure | `ex.ToString()` to client | ProblemDetails (prod: generic) | 🔴 P0 → 🟢 Fixed |
| CORS Policy | `AllowAnyOrigin()` | `WithOrigins(config[])` | 🟡 P1 → 🟢 Fixed |
| CSP Headers | None | `<meta http-equiv="CSP">` | 🟡 P1 → 🟢 Fixed |
| Input Validation | None (accepts any garbage) | DataAnnotations + EmailValidator | 🟡 P1 → 🟢 Fixed |
| API Versioning | `/api/users` | `/api/v1/users` | 🟡 P2 → 🟢 Fixed |
