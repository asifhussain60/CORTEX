Quick Start (3 Commands)

Get CORTEX running in under 5 minutes with these 3 simple commands. No complex configuration needed - CORTEX works out of the box with GitHub Copilot.

Installation Commands 
# 1. Clone the repository
git clone https://github.com/your-org/CORTEX.git
cd CORTEX

# 2. Install dependencies
pip install -r requirements.txt

# 3. Start CORTEX
python -m cortex
✅ That's it! CORTEX is now running and integrated with GitHub Copilot.

Detailed Installation Steps

1

Clone Repository

Clone the CORTEX repository to your local machine:

git clone https://github.com/your-org/CORTEX.git

This creates a CORTEX/ directory with all source files.

2

Navigate to Directory

Change into the CORTEX directory:

cd CORTEX
3

Install Dependencies

Install required Python packages:

pip install -r requirements.txt

This installs all core dependencies. Optional dependencies in optional-requirements.txt .

4

Verify Installation

Check that CORTEX installed correctly:

python -m cortex --version

Should output: CORTEX 4.0.0

5

Open in VS Code

Open the CORTEX directory in VS Code:

code .

VS Code will automatically detect .github/copilot-instructions.md

Configuration (Optional)

CORTEX works with zero configuration, but you can customize behavior via cortex.config.json :

cortex.config.json 
{
  "brain": {
    "tier0_enabled": true,
    "knowledge_graph_path": "cortex-brain/tier2/knowledge-graph.yaml"
  },
  "orchestrators": {
    "planning": {
      "autonomous": true,
      "output_path": "cortex-brain/documents/planning/"
    },
    "tdd": {
      "enforce_red_first": true
    }
  },
  "token_optimization": {
    "semantic_caching": true,
    "target_reduction": 0.97
  }
}

tier0_enabled

Enable Tier 0 Governance for SKULL rule enforcement.

autonomous

Whether Planning/ADO orchestrators execute autonomously.

enforce_red_first

TDD enforcement: tests must fail before implementation.

semantic_caching

Enable semantic caching for 97% token reduction.

Troubleshooting

Python Not Found

Problem: python: command not found

Solution: Install Python 3.10+ from python.org or use python3 instead.

GitHub Copilot Not Responding

Problem: CORTEX commands not recognized

Solution: Reload VS Code window ( Ctrl+Shift+P → "Reload Window") to refresh Copilot instructions.

Dependencies Failing

Problem: pip install errors

Solution: Upgrade pip first: pip install --upgrade pip then retry installation.

Permission Denied

Problem: Permission errors during installation

Solution: Use virtual environment: python -m venv venv → source venv/bin/activate (Linux/Mac) or venv\Scripts\activate (Windows).
