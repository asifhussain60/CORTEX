What Is CORTEX Lens?

CORTEX Lens is an intelligent code analysis dashboard that performs deep AST (Abstract Syntax Tree) analysis, reverse engineering, and knowledge extraction from codebases. It transforms raw code into actionable intelligence stored in Tier 2 Knowledge Graph.

Key Capabilities

  • AST Analysis: Parse and understand code structure at token level
  • Pattern Detection: Identify design patterns, anti-patterns, code smells
  • Dependency Mapping: Build complete dependency graphs automatically
  • Intelligence Extraction: Extract architectural decisions, relationships, contracts
  • Reverse Engineering: Reconstruct architecture from code artifacts
