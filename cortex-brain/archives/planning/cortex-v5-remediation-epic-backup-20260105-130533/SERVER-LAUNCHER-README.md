# 🚀 C50 Epic Plan Viewer Server Launcher

**Version:** 5.1.1  
**Purpose:** Automated HTTP server launch for plan-viewer.html  
**Status:** ✅ Production Ready

---

## 🎯 Overview

Automatically launches a Python HTTP server in a **separate terminal** and opens the C50 Epic Plan Viewer in your browser. Non-blocking execution allows you to continue working immediately.

---

## ✨ Features

- ✅ **Auto-Detection**: Finds C50 epic root automatically
- ✅ **Port Management**: Finds available port (8000-8010)
- ✅ **Non-Blocking**: Launches in separate terminal
- ✅ **Cross-Platform**: macOS, Windows, Linux support
- ✅ **Browser Launch**: Opens plan viewer automatically
- ✅ **Server Check**: Detects if server already running

---

## 🚀 Quick Start

### Option 1: Direct Execution (Recommended)

```bash
cd /path/to/C50-cortex-v5-remediation
python3 launch_plan_viewer.py
```

### Option 2: From Any Child Plan Folder


## 📊 Execution Flow

```
1. Find C50 Epic Root
   ↓
2. Verify plan-viewer.html exists
   ↓
3. Find available port (8000-8010)
   ↓
4. Check if server already running
   ↓
5. Launch server in new terminal
   ↓
6. Open browser to plan viewer
   ↓
7. Return control (non-blocking)
```

---

## 🖥️ Platform-Specific Behavior

### macOS
- **Terminal Launch**: Uses `osascript` to open new Terminal.app window
- **Command**: `python3 -m http.server {port}`
- **Server Window**: New Terminal tab/window (stays open)

### Windows
- **Terminal Launch**: Uses `start cmd` to open new Command Prompt
- **Command**: `python -m http.server {port}`
- **Server Window**: New cmd window (stays open)

### Linux
- **Background Launch**: Uses `nohup` for background process
- **Command**: `nohup python3 -m http.server {port} &`
- **Server Process**: Runs in background (no visible window)

## 🔌 Port Configuration

**Default Range:** 8000-8010

**Port Selection Logic:**
1. Try port 8000 first
2. If occupied, try 8001, 8002, ..., 8010
3. If all occupied, fail with error

**Check Port Usage:**
```bash
# macOS/Linux
lsof -i :8000

# Windows
netstat -ano | findstr :8000
```

## 🛑 Stop Server

### macOS/Windows
Close the server terminal window or press `Ctrl+C` in the server terminal.

### Linux
```bash
# Find server process
ps aux | grep "http.server"

# Kill server
pkill -f "python3 -m http.server"

# Or kill specific port
kill $(lsof -t -i :8000)
```

## ⚙️ Configuration (c50-epic-manifest.yaml)

```yaml
epic_metadata:
  viewer: plan-viewer.html
  viewer_launcher: launch_plan_viewer.py
  
  server_config:
    auto_launch: true
    execution_mode: background
    port_range: [8000, 8010]
    auto_open_browser: true
    launcher_script: launch_plan_viewer.py
    server_command: "python3 -m http.server {port}"
    terminal_strategy:
      macos: "osascript"
      windows: "start cmd"
      linux: "nohup"
    initialization_trigger: "plan-viewer.html exists"
    stop_instructions: "Close the server terminal window or press Ctrl+C"
```

## 🐛 Troubleshooting

### Issue: "Could not find C50 epic root directory"

**Cause:** Script not run from C50 folder or child plan folder

**Solution:**
```bash
cd /path/to/C50-cortex-v5-remediation
python3 launch_plan_viewer.py
```

---

### Issue: "plan-viewer.html not found"

**Cause:** Plan viewer not yet generated

**Solution:** Generate plan viewer first (happens during epic initialization):
```bash
# Plan viewer should be generated by epic planner
# Check if file exists:
ls -la plan-viewer.html
```

---

### Issue: "Could not find available port (tried 8000-8010)"

**Cause:** All ports in range are occupied

**Solution:**
```bash
# Find and kill processes on those ports
lsof -i :8000
lsof -i :8001
# ... etc

# Or use different port manually
python3 -m http.server 8888
```

---

### Issue: Server launches but browser doesn't open

**Cause:** Browser not found or default browser issue

**Solution:** Manually navigate to:
```
http://localhost:8000/cortex-brain/documents/planning/active/C50-cortex-v5-remediation/plan-viewer.html
```

## 📚 Integration with Epic Planner

**When Epic Planner Generates plan-viewer.html:**

1. Epic planner creates `plan-viewer.html` in epic root
2. Epic planner checks `c50-epic-manifest.yaml` → `server_config.auto_launch: true`
3. Epic planner executes: `python3 launch_plan_viewer.py`
4. Server launches in background (non-blocking)
5. Browser opens to plan viewer
6. Epic planner continues to next phase

**Configuration:**
- `epic_metadata.viewer`: Path to plan viewer
- `epic_metadata.viewer_launcher`: Path to launcher script
- `epic_metadata.server_config.auto_launch`: Enable/disable auto-launch

## 🔧 Advanced Usage

### Custom Port

```bash
# Edit script to change default port
sed -i '' 's/start_port=8000/start_port=8080/' launch_plan_viewer.py
```

### Disable Browser Auto-Open

Edit `launch_plan_viewer.py`:
```python
# Comment out this line:
# webbrowser.open(url)
```

### Server Logs (Linux)

```bash
# If using nohup, view logs:
tail -f nohup.out

# Or redirect to custom log file:
nohup python3 -m http.server 8000 > server.log 2>&1 &
tail -f server.log
```
