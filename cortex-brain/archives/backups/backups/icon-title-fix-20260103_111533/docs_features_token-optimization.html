CORTEX uses an adaptive 4-tier response system that automatically selects the optimal output format based on query complexity. Instead of one-size-fits-all verbose responses, you get precisely what you need.

🛡️ Anti-Bloat Enforcement

CORTEX enforces strict anti-bloat rules to prevent response inflation:

Single Next Action: Only the highest-value next step is shown, never multiple "you could also" suggestions
No Redundant Headers: Header already conveys context—body doesn't repeat it
Pseudo-code by Default: Full code only when explicitly requested
Completion Detection: "All work complete" replaces next steps when done
Dynamic Sections: Only sections that add value appear in output
