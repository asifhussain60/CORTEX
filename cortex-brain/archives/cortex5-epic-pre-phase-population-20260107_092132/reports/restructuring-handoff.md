#### 2. `generate_plan_viewer_html(plan_path: str, mode: str)`
**Purpose:** Generate universal HTML viewer

**Inputs:**
- `plan_path`: Path to epic or feature folder
- `mode`: Auto-detected from tracker file name

**Auto-Detection Logic:**
```python
if exists(f"{plan_path}/tracking/epic-progress-tracker.json"):
    mode = "EPIC"
    data = load_json("tracking/epic-progress-tracker.json")
elif exists(f"{plan_path}/tracking/progress-tracker.json"):
    mode = "FEATURE"
    data = load_json("tracking/progress-tracker.json")
```

**Rendering:**
- **EPIC Mode:** Render features grouped by snowball tier
- **FEATURE Mode:** Render phases with deliverables

**Technology:**
- Pure HTML/CSS/JavaScript
- No external dependencies
- Works with file:// protocol
- Glassmorphism design (existing CORTEX style)
