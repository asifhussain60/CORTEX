Incremental Execution Pattern (CORE-001)

Maximum context window is ~200K tokens. CORTEX enforces incremental execution: no single operation exceeds 500 lines (≈2K tokens). This pattern prevents token overflow while maintaining reasoning continuity.

Prompt Caching for 90% Cost Reduction

Prompt Caching Mechanics

Claude's prompt caching (5-minute window) reduces input costs by 90% for cached tokens. CORTEX caches:

  • CORTEX.prompt.md (8.2K tokens) - Routing rules, governance model - Cached once, reused 97 times
  • core-rules.yaml (12.1K tokens) - SKULL rules, governance enforcement - Cached for all AC-IDs in a phase
  • AC-INDEX.yaml (18.7K tokens) - All AC-ID definitions - Cached globally
  • Test templates (4.3K tokens) - Standard test patterns - Reused across all implementations
# Caching savings per request:

cached_tokens = 39200 # CORTEX.prompt + core-rules + AC-INDEX + templates

# First request (no cache):
cost_first = cached_tokens × $3 / 1M + new_tokens × $3 / 1M
cost_first = ($0.118) + ($0.003) = $0.121

# Subsequent requests (with cache):
cost_cached = cached_tokens × $0.30 / 1M + new_tokens × $3 / 1M
cost_cached = ($0.012) + ($0.003) = $0.015

# 96 cached requests × $0.015 = $1.44 (vs $11.62 without caching!)
savings = 87.6% # on cached operations

Cost Optimization Tips

1. Use Sonnet for 70% of Workload

Sonnet is 5x cheaper than Opus for routing, planning, and simple code generation. Reserve Opus for complex reasoning only.

2. Leverage Incremental Execution

Never send 10K tokens in one request (tokens spill into expensive output). Split into 500-line increments with prompt caching at each step.

3. Cache Static Content

CORTEX.prompt.md, core-rules.yaml, AC-INDEX.yaml are cached once and reused 97 times. 90% cost reduction on input tokens.

4. Batch Processing for Phase Runs

Run entire phases (Phase 1: 33 AC-IDs) in a single session to maximize cache hits. Cost: $1.19 (vs $11.64 if done separately).

5. Monitor Token Usage

Audit log tracks token count per increment. If exceeding 2K tokens, refactor the operation smaller or switch to Opus.
