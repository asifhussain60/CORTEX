Azure DevOps Integration Capabilities

Automated work item creation, hierarchical linking, progress sync, and bi-directional updates across CORTEX orchestrators and Azure DevOps

Core Capabilities

Create Work Items (AC-ADO-001)

Automatically create Azure DevOps work items (Epic, Feature, User Story, Task) when AC-IDs are generated. CORTEX maps acceptance criteria directly to ADO fields.

📦Epic: ADO-247 CORTEX 6.0 Foundation
📋Feature: ADO-248 Phase 1 Infrastructure (33 AC)
📝User Story: ADO-249 AC-AUDIT-001 Queryable Storage
✓Task: ADO-250 Write tests (RED phase)
✓Task: ADO-251 Implement QueryBuilder (GREEN phase)
✓Task: ADO-252 Optimize & add indexes (REFACTOR phase)
Hierarchical creation Auto-assignment Tag management
Query & Retrieve (AC-ADO-002)

Query ADO work items by multiple criteria: AC-ID, correlation ID, phase, status. Retrieve full work item details including attachments, links, and history.

Example Query 1: Find all tasks for AC-AUDIT-001
ado_connector.query_by_ac_id("AC-AUDIT-001")
# Returns: [Task-250, Task-251, Task-252, ...]
# Status: All complete ✓
Example Query 2: Find work items by correlation ID
ado_connector.query_by_correlation_id(
  "CORTEX-2026-01-11-15h45m30s-ABC123"
)
# Matches all work items created in this execution
# Count: 47 items (epic + features + stories)
WIQL support Batch retrieval Attachment download
Progress Synchronization (AC-ADO-003)

Bi-directional sync between CORTEX progress-tracker.json and ADO work item status. Closing a task in ADO updates CORTEX tracking; marking AC-ID complete in CORTEX updates ADO.

CORTEX → ADO: Mark AC-AUDIT-001 complete → Update ADO Feature status to "Done" → Close all related tasks
ADO → CORTEX: Developer closes Task-250 in ADO → progress-tracker.json updates with timestamp → Audit log records change
Example Sync Timeline
10:00 AM

AC-AUDIT-001 marked "implementing" in CORTEX → ADO Feature created with 3 tasks

10:15 AM

Developer closes Task-250 (tests) in ADO → CORTEX progress-tracker syncs immediately

10:45 AM

CORTEX TDD-Master completes all tests → Marks Task-250 "Done" + Task-251 "In Progress"

11:30 AM

All 3 tasks complete → ADO Feature auto-closes → CORTEX marks AC-AUDIT-001 "complete"

11:31 AM

Evidence bundle generated → Attached to ADO Feature (test results + audit trail)

Real-time sync Conflict resolution Audit trail preservation
