9 Specialist Agents

Autonomous agents coordinating across strategic, operational, tactical, and governance domains

MasterOrchestrator
GOVERNANCE

Central orchestrator and request router

Responsibilities

  • Route requests to appropriate agents
  • Manage execution lifecycle
  • Coordinate inter-agent communication
  • Enforce governance rules (SKULL)
  • Update orchestrator registry

Integrations

  • Pattern Router (intent classification)
  • Governance Merger (rule precedence)
  • TodoManager (task coordination)
PlanningOrchestrator v5
OPERATIONAL

Autonomous feature planning with 4-tier routing

Responsibilities

  • Parse feature requests
  • Perform pre-planning discovery
  • Tier routing (INSTANT → COMPLEX)
  • Generate markdown plans
  • Track progress in database

Integrations

  • Knowledge Graph Query (context discovery)
  • TodoManager (task generation)
  • AST Scanner (code analysis)
  • Duplicate Detector (avoid redundancy)
TDDMasterOrchestrator
OPERATIONAL

Coordinates planning → TDD workflow

Responsibilities

  • Detect completed plans
  • Transform planning data to TDD context
  • Invoke TDD Orchestrator
  • Validate AC coverage
  • Update dashboard with progress

Integrations

  • PlanningOrchestrator (consume plans)
  • TDDOrchestrator (delegate work)
  • Code Smell Detector (refactor triggers)
ADOOrchestratorV2
OPERATIONAL

Azure DevOps work item generation

Responsibilities

  • Create work items (Epic/Feature/Story/Task)
  • Link work items hierarchically
  • Estimate story points (SWAGGER)
  • Validate DoR/DoD
  • Sync with planning output

Integrations

  • PlanningOrchestrator (consume AC-IDs)
  • Knowledge Graph (historical estimation)
  • Azure DevOps API
TDDOrchestrator
TACTICAL

Executes RED-GREEN-REFACTOR workflow

Responsibilities

  • RED phase: Generate failing tests
  • GREEN phase: Implement minimal code
  • REFACTOR phase: Improve and clean
  • Detect 11 code smells
  • Apply refactoring patterns

Integrations

  • TDDMasterOrchestrator (lifecycle)
  • Code Analyzer (smell detection)
  • Test Generator (RED phase)
  • Pattern Library (REFACTOR phase)
VacuumOrchestratorV2
TACTICAL

Deep filesystem cleanup and organization

Responsibilities

  • Detect orphaned files
  • Find duplicate content
  • Safe reorganization
  • Remove dead code
  • Consolidate duplicate logic

Integrations

  • File System Walker
  • Duplicate Detector
  • Knowledge Graph (pattern learning)
InvestigationOrchestrator v2
TACTICAL

Autonomous code investigation and analysis

Responsibilities

  • Analyze code structure
  • Find root causes of issues
  • Generate investigation reports
  • Suggest fixes

Integrations

  • AST Scanner
  • Call Graph Analyzer
  • Knowledge Graph (pattern matching)
HealthValidator
STRATEGIC

Epic and system health monitoring

Responsibilities

  • Check epic completion status
  • Validate governance compliance
  • Monitor test coverage
  • Generate health reports
  • Recommend optimizations

Integrations

  • Progress Tracker
  • Governance Layer
  • Test Coverage Reporter
LLMIntentClassifier
STRATEGIC

Natural language request routing

Responsibilities

  • Parse user natural language requests
  • Classify intent with confidence scores
  • Route to appropriate agent
  • Handle ambiguous requests
  • Fallback to user clarification

Integrations

  • OpenAI API (or equivalent)
  • Pattern Router (regex fallback)
  • MasterOrchestrator (final routing)

LLM Intent Classification Workflow

How natural language requests are routed with confidence thresholds

flowchart TD
    A[User Natural Language Request] --> B[LLM Classification]
    B --> C{Confidence ≥0.8?}
    C -->|Yes| D[Route to Agent]
    C -->|No| E{Confidence ≥0.5?}
    E -->|Yes| F[Route with Warning]
    E -->|No| G[Regex Pattern Matching]
    G --> H{Pattern Match?}
    H -->|Yes| I[Route via Pattern]
    H -->|No| J[Ask User for Clarification]
    J --> K[Human Approval]
    K --> D

Inter-Agent Communication

How agents collaborate to complete complex workflows

sequenceDiagram
    participant U as User
    participant M as Master Orchestrator
    participant I as LLM Intent Classifier
    participant P as Planning Orchestrator
    participant T as TDD-Master
    participant R as TDD Orchestrator
    
    U->>M: "implement user login"
    M->>I: Classify intent
    I->>M: Planning (0.75 confidence)
    M->>P: Route with context
    P->>P: Create plan
    P->>M: Plan complete (plan-id: PLAN-001)
    M->>T: Transform to TDD context
    T->>R: Execute RED-GREEN-REFACTOR
    R->>T: Phase complete
    T->>M: Report results
    M->>U: Execution summary
    
    Note over M,R: All communication logged to audit trail
