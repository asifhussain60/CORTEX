5 Context Signals

Signals that determine response template selection

operation_type
["planning", "implementation", "testing", "cleanup", "analysis"]

Impact: Determines which sections are mandatory

response_phase
["start", "progress", "completion", "error", "summary"]

Impact: START shows full context; PROGRESS shows delta only

complexity_tier
["instant", "lightweight", "documented", "complex"]

Impact: Higher complexity → more detailed explanations

orchestrator_type
["planning", "tdd", "ado", "vacuum", "investigation"]

Impact: TDD shows RED/GREEN/REFACTOR phase breakdown

orchestrator_engaged
["true", "false"]

Impact: When true, include orchestrator-specific blocks

Response Composition Pipeline

How responses are built with token monitoring

flowchart TD
    A[Orchestrator Output] --> B[Extract Context Signals]
    B --> C[Load Mandatory Blocks]
    C --> D[Count Tokens]
    D --> E{Under 40K?}
    E -->|Yes| F[Add Conditional Blocks]
    E -->|No| G[Skip to next_steps]
    F --> H{Under 40K?}
    H -->|Yes| I[Add Orchestrator Blocks]
    H -->|No| G
    I --> J{Under 50K Hard?}
    J -->|No| K[Truncate + Add Continuation Link]
    J -->|Yes| L[Finalize Response]
    G --> L
    K --> L
    L --> M[Return to User]
