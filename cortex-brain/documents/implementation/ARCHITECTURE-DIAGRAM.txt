  User Request → Orchestrator → Return "SUCCESS (simulated)"

  User Request → Orchestrator → RealImplementationEngine

    ├─ FileOps creates files
    ├─ TestExecutor runs tests
    └─ EvidenceGen creates proof
  ✅ Real code generated
  ✅ Tests created and run
  ✅ Evidence bundle with metadata
