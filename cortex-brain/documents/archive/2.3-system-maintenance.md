## Phase Return Structure

Each phase returns consistent structure:

```python
{
    "phase": "align",  # Phase identifier
    "status": "success" | "warning" | "error",
    "duration_seconds": 12.34,
    "changes": [
        {
            "type": "fix",
            "description": "Fixed import error in module X",
            "file": "src/path/to/file.py",
            "priority": "P0"
        }
    ],
    "metrics": {
        "fixes_applied": 5,
        "issues_detected": 10,
        "issues_resolved": 8
    },
    "skipped": False,  # New in v4.0
    "skip_reason": None
}
```

## Completion Detection Logic

```python
def is_maintenance_complete(phase_results: list[dict]) -> bool:
    """Detect if maintenance workflow is complete."""
    
    # All phases must have succeeded
    all_success = all(
        phase["status"] == "success" 
        for phase in phase_results
    )
    
    # Post-healthcheck must show zero errors
    post_health = phase_results[-1]
    zero_errors = post_health["metrics"]["errors"] == 0
    
    # Test pass rate must be high
    high_pass_rate = post_health["metrics"]["test_pass_rate"] >= 0.99
    
    return all_success and zero_errors and high_pass_rate
```

## Integration Points

### 1. Entry Point
- **Command:** `system maintenance`
- **Method:** `copilot_chat` (interactive workflow)
- **Router:** `unified_entry_point_utility.py`

### 2. Implementation
- **File:** `src/operations/modules/orchestration/maintenance_orchestrator.py`
- **Class:** `MaintenanceOrchestrator`
- **Methods:**
  - `run_pre_healthcheck()` → Phase 1
  - `run_align()` → Phase 2
  - `run_cleanup()` → Phase 3
  - `run_optimize()` → Phase 4
  - `run_vacuum()` → Phase 5
  - `run_refresh_prompts()` → Phase 6
  - `run_post_healthcheck()` → Phase 7

### 3. CLI Wrapper
- **File:** `scripts/cli_wrappers/maintenance_wrapper.py`
- **Purpose:** Invokes orchestrator from command line
