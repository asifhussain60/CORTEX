# User Personas - CORTEX Onboarding

**Purpose:** Define target audiences to tailor onboarding content and learning paths.

---

## 👤 Persona 1: New Developer Sarah

**Demographics:**
- Role: Junior Full-Stack Developer
- Experience: 2 years coding
- GitHub Copilot: 6 months
- CORTEX: First time

**Goals:**
- Learn CORTEX quickly to boost productivity
- Understand practical workflows
- Build confidence with AI-enhanced development

**Pain Points:**
- Overwhelmed by documentation
- Needs step-by-step guidance
- Prefers hands-on learning

**Learning Style:**
- Visual learner
- Likes examples and tutorials
- Needs quick wins to stay motivated

**Onboarding Path:** Quick Start (30 min) → Standard Path (60 min)

---

## 👤 Persona 2: Team Lead Marcus

**Demographics:**
- Role: Engineering Manager
- Experience: 10 years development, 3 years leadership
- GitHub Copilot: Team-wide adoption
- CORTEX: Evaluating for team

**Goals:**
- Assess CORTEX for team adoption
- Understand architecture and ROI
- Evaluate learning curve and productivity impact

**Pain Points:**
- Limited time for deep dives
- Needs business justification
- Concerned about team training overhead

**Learning Style:**
- Strategic thinker
- Focuses on architecture and benefits
- Needs concrete metrics and case studies

**Onboarding Path:** Core Concepts (15 min) → Architecture Deep Dive (45 min)

---

## 👤 Persona 3: AI Enthusiast Alex

**Demographics:**
- Role: Senior Software Engineer / AI Researcher
- Experience: 8 years development, 2 years AI/ML
- GitHub Copilot: Power user
- CORTEX: Curious about internals

**Goals:**
- Understand 4-tier brain architecture
- Explore multi-agent orchestration
- Contribute to CORTEX evolution

**Pain Points:**
- Standard tutorials too basic
- Wants to see advanced patterns
- Interested in extensibility

**Learning Style:**
- Self-directed learner
- Reads source code
- Experiments with boundaries

**Onboarding Path:** Architecture (30 min) → Advanced Topics (90 min) → Contribution Guide

---

## 📊 Persona Distribution

Based on early adopter data:

- **New Developers:** 60% (Sarah)
- **Team Leads:** 25% (Marcus)
- **AI Enthusiasts:** 15% (Alex)

---

## 🎯 Onboarding Recommendations by Persona

### For Sarah (New Developer)
- Start with Quick Start guide
- Focus on hands-on exercises
- Provide visual diagrams
- Celebrate small wins
- Offer troubleshooting help

### For Marcus (Team Lead)
- Emphasize architecture and benefits
- Show productivity metrics
- Highlight team features
- Provide deployment guide
- Share case studies

### For Alex (AI Enthusiast)
- Deep dive into brain architecture
- Explain agentic enhancements
- Show orchestrator internals
- Discuss extensibility
- Invite contributions
