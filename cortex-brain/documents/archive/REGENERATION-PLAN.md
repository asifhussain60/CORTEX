## 🎨 Design Principles

### Visual Style Guidelines

**AVOID (Old Style):**
- ❌ Human brain imagery
- ❌ Biological metaphors (neurons, synapses, cells)
- ❌ Anatomical cross-sections
- ❌ Medical imaging aesthetics

**USE (New Style):**
- ✅ Enterprise architecture diagrams
- ✅ Data flow visualizations
- ✅ System topology maps
- ✅ Network graphs
- ✅ Cybersecurity dashboards
- ✅ Technical schematics

### Color Palette Consistency

- **Tier 0 / Governance:** Gold (#FFD700)
- **Tier 1 / Memory:** Cyan (#06B6D4)
- **Tier 2 / Knowledge:** Purple (#A855F7)
- **Tier 3 / Context:** Blue (#3B82F6)
- **Threats / Errors:** Red (#EF4444)
- **Success / Safe:** Green (#10B981)
- **Background:** Dark (#0F172A or #0A0A0A)

## 📋 Narrative Structure Template

Each narrative file should include:

### 1. Image Overview (1-2 sentences)
Brief description of what the diagram shows

### 2. Opening Statement (30 seconds)
Hook to grab audience attention, set context

### 3. Main Content (3-5 minutes)
- Section-by-section explanation
- Key visual elements to point out
- Metrics and data to highlight

### 4. Closing Statement (30 seconds)
Summary, key takeaway, transition

### 5. Q&A Hooks
- Anticipated questions with answers
- Common misconceptions to address
- Deep-dive topics if asked

### 6. Visual Highlights
- Specific elements to point to in the image
- Color coding explanations
- Animation or flow descriptions

### 7. Timing Guide
- Quick overview: 2 min
- Standard: 5 min  
- Deep dive: 10 min

### 8. Key Takeaways
- 3-5 bullet points audience should remember

## 💡 Best Practices

### For Prompts:
1. **Be specific about perspective:** Isometric, top-down, side view
2. **Define color palette explicitly:** Use hex codes
3. **Describe data flow:** Arrows, particles, glowing streams
4. **Include annotations:** Labels, metrics, status indicators
5. **Specify visual quality:** Enterprise-grade, professional, technical

### For Narratives:
1. **Start with context:** Why this diagram matters
2. **Use analogies:** Compare to familiar concepts
3. **Highlight metrics:** Numbers make it concrete
4. **Prepare for Q&A:** Anticipate tough questions
5. **Time your delivery:** Practice 2-min, 5-min, 10-min versions
