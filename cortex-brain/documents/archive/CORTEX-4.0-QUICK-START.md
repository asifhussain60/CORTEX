## ⚡ 5-Minute Setup

### Step 1: Verify Installation (30 seconds)

```bash
# In Copilot Chat:
healthcheck
```

**Expected:** ✅ All tiers operational

**If errors:** Run `align` to auto-fix

### Step 2: Explore Help (1 minute)

```
help
```

**Shows:** All available commands organized by category

### Step 3: Your First Plan (3 minutes)

```
plan a todo list API with CRUD operations
```

**CORTEX will:**
- Analyze complexity (LOW in this case)
- Generate 5-phase plan with TDD
- Show DoR/DoD checklist
- Present execution options

### Step 4: Execute Plan (30 seconds)

```
execute all phases autonomously
```

**Sits back:** CORTEX runs end-to-end workflow

### Step 5: Validate (30 seconds)

```
what's my test coverage?
```

**Shows:** Test pass rate and coverage metrics

## 📋 Essential Commands

### System Operations

| Command | What It Does | When to Use |
|---------|-------------|-------------|
| `healthcheck` | System diagnostics | Daily startup |
| `align` | Auto-fix issues | When errors appear |
| `cleanup` | Remove waste | Weekly maintenance |
| `optimize` | Boost performance | Monthly tuning |

### Planning & Development

| Command | What It Does | When to Use |
|---------|-------------|-------------|
| `plan [feature]` | Create feature plan | Starting new work |
| `start tdd` | Begin TDD workflow | Writing new code |
| `sanitize [dir]` | Remove company data | Sharing publicly |
| `plan ado` | Generate ADO item | Creating work items |

### Advanced Operations

## 🚨 Common Issues & Fixes

### Issue 1: Command Not Found

**Problem:** CORTEX doesn't recognize command

**Fix:**

```
align
```

**Reason:** Configuration drift, fixed by alignment

### Issue 2: Tests Failing

**Problem:** Tests fail after changes

**Fix:**

```
start tdd
# Let CORTEX guide you through RED→GREEN→REFACTOR
```

**Reason:** Skipped TDD workflow

### Issue 3: Root-Level Docs Created

**Problem:** Files created at `CORTEX/my-doc.md`

**Fix:**

```
# Move to proper category:
cortex-brain/documents/{category}/my-doc.md
```

**Reason:** Document organization rule violated

### Issue 4: Slow Performance

**Problem:** CORTEX operations are slow

**Fix:**

```
optimize
```

**Reason:** Cache/index fragmentation
