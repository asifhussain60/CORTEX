## Routing Decision Tree

```
User Request
    │
    ├─ Contains code/file/test keywords? ──YES──> Code Execution Agent
    │                                      NO
    │                                       │
    └─ Contains plan/review/align keywords? ──YES──> Strategic Planning Agent
                                            NO
                                             │
                                             └─> Default: Strategic Planning Agent
```

## Integration Points

### 1. Intent Classification
- **Location:** `src/operations/utilities/unified_entry_point_utility.py`
- **Method:** `classify_intent(user_request: str) -> str`
- **Returns:** `"code_execution"` or `"strategic_planning"`

### 2. Agent Registry
- **Location:** `src/cortex_agents/`
- **Files:**
  - `code_execution_agent.py` - Tactical operations
  - `strategic_planning_agent.py` - High-level coordination

### 3. Brain Integration
- Both agents access unified 4-tier brain
- Shared memory prevents duplication
- Knowledge graph enables cross-agent learning

---

## Key Benefits

1. **Separation of Concerns:** Tactical vs strategic responsibilities
2. **Specialization:** Each agent optimized for specific task types
3. **Scalability:** Easy to add new agents without disrupting existing
4. **Maintainability:** Clear boundaries reduce complexity
