## Executive Summary

This matrix provides **completion criteria** for every AC-ID, orchestrator, and phase in CORTEX 6.0. Use this as the **validation checklist** to determine when work is truly complete.

**Key Criteria:**
- **Test Coverage:** ≥80% line coverage (all AC-IDs)
- **Clean Code Score:** ≥80 (radon + pylint + pydocstyle + mypy)
- **Audit Trail:** All operations logged with correlation IDs
- **Documentation:** Docstrings, usage examples, architecture updates
- **Validation Gates:** Pre-commit hooks, quality gates, security scans

## 1. Per AC-ID Completion Criteria

### 1.1 Universal Requirements (ALL 57 AC-IDs)

**Table: AC-ID DoD Checklist**

| Criterion | Threshold | Validation Method | Failure Action |
|-----------|-----------|-------------------|----------------|
| **Implementation** | 100% of acceptance criteria met | Manual review against AC-INDEX.yaml | Block merge until criteria met |
| **Unit Tests** | ≥80% line coverage | `pytest --cov` | Block merge if coverage <80% |
| **Integration Tests** | All integration points tested | `pytest tests/integration/` | Block merge if failures |
| **Security Tests** | Generated if user input handling | AST analysis + pytest-security | Block merge if vulnerabilities found |
| **Clean Code Score** | ≥80 | radon + pylint + pydocstyle + mypy | Block merge if score <80 |

| **Audit Trail** | All operations logged | Query: `audit query --ac-id AC-{ID}` | Block merge if audit incomplete |
| **Validation Report** | Markdown with progress bars | Auto-generated by TDD-Master | Block merge if report missing |
| **User Confirmation** | Received (if interactive) | Manual confirmation | Block merge if user rejects |

## 5. Quality Gates (Automated Enforcement)

### 5.1 Pre-Commit Hook

**Location:** `.git/hooks/pre-commit`

**Checks:**
```bash
#!/bin/bash
# Quality gates enforced before commit

CHANGED_PY=$(git diff --cached --name-only --diff-filter=ACM | grep '\.py$')

for file in $CHANGED_PY; do
    # Gate 1: Test coverage ≥80%
    pytest --cov=$file --cov-report=term-missing --cov-fail-under=80
    if [ $? -ne 0 ]; then
        echo "❌ Coverage <80% for $file"
        exit 1
    fi
    
    # Gate 2: Clean Code Score ≥80
    radon cc $file -a -nb
    pylint $file --fail-under=8.0
    pydocstyle $file
    mypy $file
    
    # Gate 3: TDD-Master validation exists
    AC_ID=$(grep -oP 'AC-[A-Z]+-\d+' "$file" | head -1)
    if [ -n "$AC_ID" ]; then
        python3 -m src.main "audit query --ac-id $AC_ID --category VALIDATION" >/dev/null 2>&1
        if [ $? -ne 0 ]; then
            echo "❌ No TDD-Master validation for $file (AC-ID: $AC_ID)"
            exit 1
        fi
    fi
done

echo "✅ All quality gates passed"
exit 0
```
