## 📋 Naming Convention Rules

### Master Plans, Phase Plans, Epic Plans

**Format:** `[A-Z0-9]{3}-{abbreviated-name}.md`

- **3-Character ID:** Letter + 2-digit number (A00-A99, B00-B99, etc.)
- **Separator:** Single hyphen (-)
- **Name Length:** 20-25 characters (abbreviated)
- **Extension:** .md (Markdown)

## 🔤 ID Assignment Strategy

### Sequential Assignment
- Plans are numbered sequentially within each letter group
- A00, A01, A02, ... A99 (100 plans)
- B00, B01, B02, ... B99 (next 100 plans)
- C00, C01, C02, ... C99 (next 100 plans)

### Automatic ID Generation
The Planning Orchestrator v5 automatically generates IDs based on:
1. Count of existing plans in database
2. Formula: `letter = chr(65 + (count // 100))`, `number = count % 100`
3. Example: Plan #0 = A00, Plan #100 = B00, Plan #250 = C50

## 📏 Name Abbreviation Rules

### Keep Full (Don't Abbreviate)
- Short words (≤4 chars): `api`, `auth`, `db`, `ui`, `ux`
- Domain terms: `oauth2`, `jwt`, `sass`, `css`
- Version indicators: `v1`, `v2`, `v3`

### Abbreviate (Shorten)
- Long words (>8 chars):
  - `authentication` → `auth`
  - `standardization` → `std`
  - `implementation` → `impl`
  - `enterprise` → `enterpise` (keep at 9 chars if space allows)
  - `integration` → `integ` or keep full if <25 chars total
  - `migration` → `migr`
  - `selenium` → `selenium` (keep full - well-known)

### Smart Truncation
- If abbreviated name still exceeds 25 chars, truncate from right
- Always end on a word boundary (not mid-word)
- Remove trailing hyphens after truncation
