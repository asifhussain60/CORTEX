### Interactive Visualization Site

**Purpose:** GitHub Pages-hosted interactive documentation with D3.js diagrams

**Technology Stack:**
- **Visualization:** D3.js v7 for interactive diagrams
- **Styling:** Reused admin dashboard CSS theme
- **Hosting:** GitHub Pages (static site)
- **Build:** Plain HTML/CSS/JS (no build step needed)

**Site Structure:**
```
docs/cortex-4.0/
├── index.html                    # Landing page
├── css/
│   ├── cortex-theme.css         # Extracted from admin dashboard
│   ├── d3-visualizations.css    # D3 diagram styles
│   └── responsive.css           # Mobile responsiveness
├── js/
│   ├── diagrams/
│   │   ├── enterprise-architecture.js
│   │   ├── team-orchestration.js
│   │   ├── federated-brain.js
│   │   ├── llm-intent-flow.js
│   │   ├── mcp-integration.js
│   │   └── implementation-roadmap.js
│   ├── components/
│   │   ├── navigation.js
│   │   ├── zoom-controls.js
│   │   └── tooltip.js
│   └── data/
│       ├── architecture-data.json
│       ├── roadmap-data.json
│       └── team-structure-data.json
├── pages/
│   ├── architecture.html
│   ├── team-orchestration.html
│   ├── federated-brain.html

    └── images/

```
