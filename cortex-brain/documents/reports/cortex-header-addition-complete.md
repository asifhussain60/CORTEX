## 📋 Header Format Standards

### Markdown Files (.md)

**Format:**
```markdown
# {Document Title}

**Generated by:** CORTEX Lens v3.0  
**Author:** Asif Hussain | **GitHub:** github.com/asifhussain60/CORTEX

---

{document content}
```

**Location:** Lines 1-5  
**Separator:** `---` after header

---

### YAML Files (.yaml)

**Format:**
```yaml
# {Document Title}
# Generated by: CORTEX Lens v3.0
# Author: Asif Hussain | GitHub: github.com/asifhussain60/CORTEX
# Source: {filename}
# Date: {timestamp}
#
# {additional info}

{yaml content}
```

**Location:** Lines 1-10 (comment block)  
**Separator:** Blank comment line

---

### JSON Files (.json)

**Format:**
No comment header (JSON doesn't support comments)  
Attribution included in `info.contact` section of OpenAPI spec

```json
{
  "info": {
    "contact": {
      "name": "CORTEX Lens",
      "url": "https://github.com/asifhussain60/CORTEX"
    },
    "x-legacy-source": {
      "generated": "timestamp"
    }
  }
}
```
