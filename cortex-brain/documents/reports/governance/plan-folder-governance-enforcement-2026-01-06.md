## 🔍 Root Cause Analysis

### Issue Discovered

**Forbidden folder found:** `plan-a8e6b760-72b9-4f1e-9806-bcbdc8367385/`  
**Location:** `cortex-brain/documents/planning/active/`  
**Violation:** PLAN_FILE_ORGANIZATION brain protection rule

**Brain Protection Rule Violated:**
```yaml
rule_id: PLAN_FILE_ORGANIZATION
category: architecture_integrity
severity: blocked
enforcement: block_if_root_level_plan_file
```

### Root Causes Identified

#### 1. UUID-Based Plan ID Generation

**File:** `src/database/planning_state_db.py:96`  
**Code:**
```python
def create_plan(...) -> str:
    plan_id = self._generate_id("plan-")  # Generates "plan-{uuid}"
```

**Problem:** Creates UUID-based IDs like `plan-a8e6b760-...` instead of meaningful names like `a01-feature-name`

#### 2. Missing Feature Name Validation

**File:** `src/orchestrators/planning/planning_orchestrator_v5.py:1524`  
**Code:**
```python
def _create_folder_structure(...):
    master_plan_filename = self._generate_master_plan_filename(feature_name)
    folder_id_prefix = master_plan_filename.split('-')[0].lower()
    abbreviated_name = self._abbreviate_feature_name(feature_name, max_length=22)
    folder_name = f"{folder_id_prefix}-{abbreviated_name}"
```

**Problem:** If `feature_name` is empty/invalid, `abbreviated_name` becomes empty, resulting in UUID fallback

#### 3. Database vs Folder Name Mismatch

- **Database plan_id:** `plan-{uuid}` (generated by `PlanningStateDB`)
- **Folder name:** Should be `a01-feature-name` (generated by `PlanningOrchestratorV5`)
- **Mismatch:** plan_id used for folder name when feature_name missing

## 🛡️ Prevention Strategy

### Immediate Fixes Required

#### Fix 1: Enforce Feature Name Validation in Planning v5

**File:** `src/orchestrators/planning/planning_orchestrator_v5.py`  
**Location:** `execute()` method (before database creation)

**Add validation:**
```python
def execute(self, user_request: str, **kwargs) -> OrchestratorResult:
    # Extract feature name
    feature_name = self._extract_feature_name(user_request)
    
    # VALIDATION: Enforce non-empty, meaningful name
    if not feature_name or len(feature_name) < 3:
        raise ValueError(
            "Feature name required and must be at least 3 characters. "
            "Cannot create plan with UUID fallback (PLAN_FILE_ORGANIZATION rule)."
        )
    
    # Validate feature name format (kebab-case, alphanumeric + hyphens only)
    if not re.match(r'^[a-z0-9]+(-[a-z0-9]+)*$', feature_name):
        raise ValueError(
            f"Invalid feature name: '{feature_name}'. "
            "Must be kebab-case (lowercase, hyphens only)."
        )
```

#### Fix 2: Use Meaningful Plan IDs in Database

**File:** `src/database/planning_state_db.py`  
**Method:** `create_plan()`

**Change from:**
```python
plan_id = self._generate_id("plan-")  # UUID-based
```

**Change to:**
```python
# Generate meaningful ID from feature_name
# Format: plan-{abbreviated-feature-name}-{short-hash}
feature_slug = feature_name.lower().replace(' ', '-')[:20]
short_hash = hashlib.sha256(feature_name.encode()).hexdigest()[:6]
plan_id = f"plan-{feature_slug}-{short_hash}"
```

**Example:** `plan-oauth2-auth-sys-3a2f1b` instead of `plan-a8e6b760-...`

#### Fix 3: Add Pre-Execution Hook in Master Orchestrator

**File:** `src/orchestrators/master_orchestrator.py`  
**Hook:** `before_orchestrator_execute()`

**Validation:**
```python
def before_orchestrator_execute(self, orchestrator_name: str, request: str):
    if orchestrator_name == "PlanningOrchestratorV5":
        # Enforce feature name extraction before execution
        feature_name = self._extract_feature_from_request(request)
        if not feature_name or len(feature_name) < 3:
            raise GovernanceViolation(
                rule="PLAN_FILE_ORGANIZATION",
                message="Feature name required for plan creation"
            )
```
