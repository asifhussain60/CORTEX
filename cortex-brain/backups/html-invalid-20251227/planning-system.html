🎯 Planning System Orchestrator

4-Tier Complexity Routing with Automated TDD Integration

Complexity: HIGH
Phases: 13+
File: planning_orchestrator.py
Manifest: planning-system-4.0-manifest.yaml
The Planning System Orchestrator is CORTEX's flagship workflow engine, providing intelligent complexity-based routing across four planning tiers: Skeleton (simple features), Conditional (medium complexity), Incremental (high complexity, multi-phase), and Granular (enterprise-level, detailed breakdown). All plans automatically integrate TDD workflows with RED→GREEN→REFACTOR cycles and enforce DoR/DoD compliance gates.

✨ Key Features

🎯
Tiered Complexity Routing
Automatically routes features to appropriate planning tier based on complexity analysis. Security, auth, and migrations auto-route to incremental planning.
🧪
TDD Auto-Inclusion
Every plan includes TDD phases with technology discovery, test generation, and quality enforcement (SOLID/DRY/KISS/YAGNI). Supports 11+ languages.
📋
DoR/DoD Compliance
Enforces Definition of Ready and Definition of Done at phase boundaries. Acceptance criteria gates prevent incomplete phase progression.
🔄
Phase 10 Modularization
Plans >20KB automatically split into index + modules structure for maintainability. Achieves 95% token reduction through YAML modularization.
📊
Manifest Compliance
All plans validated against planning-system-4.0-manifest.yaml. Ensures consistency, completeness, and architectural adherence.
🔗
Manifest Inheritance
Parent manifest for ADO Planning and other child orchestrators. Provides baseline requirements extended by specialized workflows.
