What is the 4-Tier Brain?

The 4-Tier Brain is CORTEX's hierarchical memory architecture that provides strategic planning, long-term learning, and context awareness. Unlike traditional AI assistants with no memory, CORTEX remembers patterns, learns from mistakes, and builds institutional knowledge across development sessions.

Each tier serves a specialized purpose—from immutable governance rules (Tier 0) to real-time development context (Tier 3)—creating a complete cognitive framework that evolves with your team.

The 4 Memory Tiers

🛡️

Tier 0: Governance (SKULL Rules)

Immutable protection rules

Purpose: Core governance layer with 22 immutable SKULL rules enforced by the Brain Protector.

Key Features:
  • TDD enforcement
  • Duplication prevention
  • Git isolation
  • Knowledge integrity
Storage:
  • brain-protection-rules.yaml
  • Never modified
  • 100% enforcement
View SKULL Rules →
⚡

Tier 1: Working Memory (FIFO Queue)

Fast, short-term context

Purpose: High-speed working memory storing recent 70 conversations with <100ms query time.

Key Features:
  • FIFO eviction policy
  • 70-conversation window
  • Session context
  • Real-time queries
Storage:
  • conversation-history.db
  • SQLite with FTS5
  • Auto-pruning
🕸️

Tier 2: Knowledge Graph (Long-Term Learning)

Pattern storage & retrieval

Purpose: Persistent knowledge graph with 8,429 nodes storing patterns, solutions, and learnings.

Key Features:
  • Pattern recognition
  • Solution templates
  • Best practices
  • Anti-pattern detection
Storage:
  • knowledge-graph.yaml
  • Semantic relationships
  • Confidence scoring
📊

Tier 3: Development Context (Metrics & Hotspots)

Real-time codebase intelligence

Purpose: Real-time development context tracking metrics, complexity, and code hotspots.

Key Features:
  • Complexity analysis
  • Hotspot detection
  • Test coverage tracking
  • Refactoring priorities
Storage:
  • development-context.yaml
  • AST-powered analysis
  • Git integration

How the Tiers Work Together

1️⃣

Query Arrives

User request enters CORTEX through Copilot Chat interface.

2️⃣

Tier 0 Validation

Brain Protector checks request against SKULL rules.

3️⃣

Context Retrieval

Tier 1 provides recent conversations, Tier 2 supplies learned patterns.

4️⃣

Real-Time Analysis

Tier 3 analyzes current codebase state and complexity.

5️⃣

Response Generation

CORTEX synthesizes all tiers to generate informed response.

6️⃣

Knowledge Update

Learnings stored in Tier 2 for future operations.

Why 4-Tier Architecture?

🚀 Performance

Tier separation ensures fast queries (<100ms) while maintaining deep knowledge storage. Hot data in Tier 1, patterns in Tier 2.

🧠 Intelligence

Long-term learning through Tier 2 knowledge graph builds institutional memory that improves over time.

🛡️ Safety

Tier 0 SKULL rules provide immutable guardrails preventing common development anti-patterns.

📊 Context

Tier 3 provides real-time codebase awareness—complexity, hotspots, and refactoring priorities.
