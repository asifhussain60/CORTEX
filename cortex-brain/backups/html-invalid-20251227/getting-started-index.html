🏗️ Multi-Repo Architecture (1:∞)

CORTEX operates on a 1:∞ architecture—one CORTEX repository serves unlimited user repositories. The 4-Tier Brain automatically:

  • Detects your current workspace (via cortex.config.json auto-discovery)
  • Segments Tier 3 dev context per repository (isolated SQLite databases)
  • Shares Tier 0-2 knowledge across all projects (governance, memory, knowledge graph)
  • Prevents cross-contamination (SKULL Rule #7: Git Isolation)

⚡ Essential Commands

Planning
