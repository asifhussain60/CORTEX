### 🔍 How It Works

1. **Event Capture:** CORTEX captures milestone events from orchestrators and agents
2. **Document Generation:** Events are transformed into structured markdown
3. **Categorization:** Documents organized into 15 learning categories
4. **Search & Browse:** Full-text search and sidebar navigation

### 📚 Document Structure

Each learning document includes:

- **Event Information:** Type, component, timestamp
- **Overview:** High-level summary
- **Details:** Specific information and context
- **Event Metadata:** Technical details
- **Resources:** Related documentation (when available)

### 🎓 Learning Approach

This library follows a **milestone-based learning approach**:

- Events are captured at significant milestones (not continuously)
- Focus on patterns and workflows (not implementation details)
- Organized by category for easy discovery
- Searchable for specific topics
