## Image Generation Guidelines

### Technical Specifications
- **Format:** JPEG
- **Resolution:** 1920x1080 minimum (web-optimized)
- **Style Consistency:** Match existing CORTEX story aesthetic (engineering workspace, terminal screens, technical diagrams)
- **Color Palette:** 
  - Terminal green (#00FF00)
  - Warning amber (#FFA500)
  - Error red (#FF4444)
  - Success blue (#4444FF)
  - Background dark (#1E1E1E) or light whiteboard (#F5F5F5)

### Content Guidelines
- **Readability:** All text must be legible at 50% zoom
- **Context:** Each image should tell part of the story independently
- **Humor:** Subtle tech humor where appropriate (Miss G's reactions, robot enthusiasm)
- **Authenticity:** Match real CORTEX features and output formats

### Placement Strategy
- **ESSENTIAL:** Core concepts, main workflow visualizations
- **VALUABLE:** Supporting details, enhancement illustrations
