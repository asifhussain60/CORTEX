Access Control

Comprehensive role-based access control (RBAC), authentication mechanisms, and authorization strategies for secure system access management.

Overview

Access Control is a fundamental security mechanism that regulates who can view or use resources in a computing environment. CORTEX implements multiple access control models to provide flexible, secure, and auditable access management across all system components.

Access Control Models

RBAC

Role-Based Access Control assigns permissions to roles, and users inherit permissions through role membership.

ABAC

Attribute-Based Access Control evaluates attributes (user, resource, environment) to make access decisions.

DAC

Discretionary Access Control allows resource owners to grant or restrict access to other users.

MAC

Mandatory Access Control enforces system-wide policies that cannot be overridden by users.

Configuration Example

access-control.yaml 
access_control:
  model: rbac
  
  roles:
    admin:
      permissions:
        - read:*
        - write:*
        - delete:*
        - manage:users
    
    developer:
      permissions:
        - read:*
        - write:code
        - execute:pipelines
    
    viewer:
      permissions:
        - read:dashboards
        - read:reports

  authentication:
    methods:
      - type: oauth2
        provider: azure-ad
        scopes: [openid, profile, email]
      - type: mfa
        required_for: [admin, developer]
    
    session:
      timeout: 3600
      refresh_enabled: true
      max_concurrent: 3

Best Practices

  • Implement principle of least privilege - grant only minimum permissions required for each role
  • Enable multi-factor authentication for all privileged accounts and sensitive operations
  • Regularly audit access permissions and remove unnecessary privileges
  • Implement session timeout and automatic logout for inactive sessions
  • Log all access attempts and maintain comprehensive audit trails
  • Use centralized identity management with SSO for consistent access control
