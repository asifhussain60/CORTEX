Alert Rules Configuration

Define alert rules to detect security incidents and anomalies.

Brute Force Detection

Alert when multiple failed login attempts occur from same IP

count(AUTH_FAILURE) by ip_address > 5 within 5m

Privilege Escalation

Detect unauthorized privilege elevation attempts

event_type = "PRIVILEGE_CHANGE" AND authorized = false

Unusual Access Patterns

Alert on access outside normal working hours

event_type = "LOGIN" AND hour NOT IN (8..18)

Mass Data Export

Detect potential data exfiltration

event_type = "DATA_EXPORT" AND record_count > 1000

Configuration Changes

Track changes to security configurations

event_type = "CONFIG_CHANGE" AND scope = "security"

New Admin Account

Alert when new administrator accounts are created

event_type = "USER_CREATE" AND role = "admin"

Audit Logging Best Practices

Log Integrity

Use cryptographic signatures or write-once storage to prevent log tampering. Implement centralized logging to reduce risk of local log manipulation.

Time Synchronization

Use NTP to ensure all systems have synchronized timestamps. Consistent timing is critical for event correlation and forensic analysis.

Sensitive Data Handling

Avoid logging sensitive data like passwords or PII. Use tokenization or masking for data that must be logged for compliance.

Standardization

Adopt standard log formats (CEF, LEEF, JSON). Use consistent field naming conventions across all applications and services.
