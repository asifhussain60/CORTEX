Cleanup Orchestrator

Production Ready

The Cleanup Orchestrator performs comprehensive repository analysis and cleanup through holistic scanning. It categorizes files by type and purpose, validates production-readiness naming conventions, detects redundancies, and safely executes cleanup with backup/rollback capabilities. The orchestrator never touches protected directories.

📁 File Categories

✅ production

Production-ready files with clean naming

^[a-z_]+\.py$

⚠️ non_production

Temporary or versioned naming

*_v2.*, *-20251225.*

🗑️ redundant

Backup and redundant files

*.bak, *BACKUP*, *.old

📦 deprecated

Explicitly deprecated files

*deprecated*, *legacy*

📂 dependency_cache

Caches and virtual environments

node_modules/, __pycache__/

⚙️ config_artifact

Config from deprecated tech

package.json, yarn.lock

📊 reports

Temporary reports and summaries

*REPORT*.md, *STATUS*.md

🚫 Production Readiness Violations

Pattern Type Example Severity Description
temporary_prefix temp_config.py HIGH Starts with temp, tmp, test, demo
version_suffix handler_v2.py MEDIUM Version number suffix
date_stamp report-20251227.md MEDIUM Date embedded in filename
modification_indicator auth_fixed.py HIGH Words like cleaned, fixed, updated
status_indicator database_old.py HIGH Words like backup, old, deprecated
copy_indicator config - Copy.json HIGH Windows-style copy suffix
temporary_report ANALYSIS_REPORT.md MEDIUM All-caps report files
