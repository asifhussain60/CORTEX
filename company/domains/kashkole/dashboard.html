Project Description

KASHKOLE is an Islamic knowledge management and educational platform built with ASP.NET Web Forms and VB.NET. The application provides Quran browsing, Islamic calendar (Hijri) functionality, knowledge articles management, and email notifications. Originally developed in 2011-2013, it represents a legacy codebase requiring modernization.

Prioritized Recommendations

  • P0 - Immediate
    1. Remove Hardcoded Credentials
    Move all passwords and API keys to secure storage:
    • Use Azure Key Vault or Windows Credential Manager
    • Implement IConfiguration with environment variables
    • Rotate all exposed credentials immediately
  • P0 - Immediate
    2. Regenerate Machine Keys
    Generate new random machine keys and store securely. Update validation algorithm from SHA1 to SHA256.
  • P1 - Short-term
    3. Upgrade .NET Framework
    Minimum upgrade to .NET Framework 4.8, plan migration to .NET 6/8 LTS for long-term support.
  • P1 - Short-term
    4. Remove Flash Content
    Flash is end-of-life. Inventory all SWF files and replace with HTML5/JavaScript alternatives.
  • P2 - Medium-term
    5. Modernize Web Services
    Migrate ASMX web services to ASP.NET Core Web API with OAuth 2.0 authentication.

Modernization Roadmap

Phase 1: Security Hardening Priority: P0
