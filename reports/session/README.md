# Session Reports

Auto-expired artifacts from development sessions.

**Lifetime:** 7 days
**Auto-delete:** Yes (after expiry)
**Archive:** Manually copy to documentation/ if needed for reference

Files in this folder are temporary work artifacts from development sessions.
They expire after 7 days automatically.
