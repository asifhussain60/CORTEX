# Tool Outputs

Auto-expired tool-generated reports and outputs.

**Lifetime:** 30 days
**Auto-delete:** Yes (after expiry)
**Archive:** Move to documentation/ if results are valuable long-term

Files in this folder are auto-generated outputs from various tools,
utilities, and scripts. They expire after 30 days automatically.

```yaml
---
created_at: 2026-01-26T15:30:00Z

category: tool

---
```
