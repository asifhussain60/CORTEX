High-Priority Principles

📝

RESTful Resource Naming

HIGH

Description: Use nouns for resources, pluralize collections, and maintain consistent naming conventions.

✅ /users /users/{id} /users/{id}/orders

❌ /getUsers /user /userOrder

🔒

Always Use HTTPS

HIGH

Description: All API endpoints must use HTTPS to encrypt data in transit.

📊

Implement Pagination

MEDIUM

Description: All list endpoints should support pagination to limit response size.

Use limit and offset or page and size parameters.
