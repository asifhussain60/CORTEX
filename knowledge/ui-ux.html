🎨 UI/UX Design

Design Systems, Accessibility, Usability Patterns, and WCAG Standards

📦 Design & Accessibility 🏷️ UI/UX 📅 Updated: Dec 2025

📋 Overview

UI/UX Design encompasses the creation of intuitive, accessible, and aesthetically pleasing user interfaces. This guide covers design systems, accessibility standards, usability patterns, and best practices for creating exceptional user experiences.

Core UI/UX Principles:
  • User-Centered: Design with users' needs and goals in mind
  • Accessible: Ensure usability for people of all abilities
  • Consistent: Maintain design patterns across the interface
  • Responsive: Adapt seamlessly across devices and screen sizes

🎯 Design Systems

What is a Design System?

A design system is a collection of reusable components, patterns, and guidelines that ensure consistency across digital products.

  • Components: Reusable UI elements (buttons, inputs, cards)
  • Patterns: Common UI solutions (navigation, forms, modals)
  • Guidelines: Rules for spacing, typography, colors
  • Documentation: Usage examples and best practices

Popular Design Systems

Material Design (Google)

  • Motion-based design language
  • Elevation and shadows
  • Bold colors and typography
  • Comprehensive component library

Human Interface Guidelines (Apple)

  • Clarity and depth
  • Platform-specific patterns
  • Emphasis on content
  • iOS, macOS, watchOS guidelines

Fluent Design (Microsoft)

  • Light, depth, motion, material
  • Acrylic materials and reveals
  • Cross-platform consistency
  • Windows, web, mobile support

Carbon Design (IBM)

  • Enterprise-focused
  • Accessibility-first approach
  • Data visualization components
  • Open-source component library

Building a Design System

Key Steps:
  • Audit: Review existing UI components and patterns
  • Define Tokens: Establish colors, typography, spacing scales
  • Create Components: Build reusable, flexible components
  • Document: Provide clear usage guidelines and examples
  • Version Control: Track changes and maintain consistency
  • Governance: Establish processes for updates and contributions

♿ Accessibility (A11y)

WCAG 2.1 Principles (POUR)

Perceivable

  • Text Alternatives: Alt text for images
  • Adaptable: Multiple ways to present content
  • Distinguishable: Sufficient color contrast
  • Captions: For audio and video content

Operable

  • Keyboard Accessible: All functions via keyboard
  • Enough Time: Users control time limits
  • Seizures: No flashing content
  • Navigable: Clear navigation and focus

Understandable

  • Readable: Clear language and structure
  • Predictable: Consistent behavior
  • Input Assistance: Error prevention and recovery
  • Instructions: Clear form labels and guidance

Robust

  • Compatible: Works with assistive technologies
  • Valid HTML: Proper semantic markup
  • ARIA: Accessible Rich Internet Applications
  • Future-Proof: Support for new technologies

WCAG Conformance Levels

Level Requirements Target Audience
Level A Essential accessibility features Minimum legal compliance
Level AA Addresses major accessibility barriers Standard for most organizations
Level AAA Highest level of accessibility Specialized or critical applications

Accessibility Checklist

Essential Accessibility Practices:
  • Semantic HTML: Use appropriate HTML elements (header, nav, main, article)
  • Alt Text: Descriptive alternative text for all images
  • Color Contrast: Minimum 4.5:1 for normal text, 3:1 for large text
  • Keyboard Navigation: Tab order and focus indicators
  • ARIA Labels: aria-label, aria-labelledby for complex components
  • Form Labels: Explicit labels for all form inputs
  • Headings: Proper heading hierarchy (h1 → h6)
  • Skip Links: Allow users to skip repetitive content
  • Responsive Text: Text resizes up to 200% without loss of content
  • Error Identification: Clear error messages and recovery paths

Assistive Technologies

Common Assistive Technologies:
  • Screen Readers: JAWS, NVDA, VoiceOver, TalkBack
  • Screen Magnifiers: ZoomText, Windows Magnifier
  • Voice Control: Dragon NaturallySpeaking, Voice Control
  • Switch Devices: Alternative input methods for motor impairments

🧩 Usability Patterns

Jakob Nielsen's 10 Usability Heuristics

Visibility of System Status

Keep users informed about what's happening through appropriate feedback within a reasonable time.

Match Between System and Real World

Use familiar language, concepts, and conventions that users understand from the real world.

User Control and Freedom

Provide undo/redo actions and clear exit options for users who make mistakes.

Consistency and Standards

Follow platform and industry conventions so users don't have to learn new patterns.

Error Prevention

Eliminate error-prone conditions and provide confirmation for destructive actions.

Recognition Rather Than Recall

Minimize memory load by making objects, actions, and options visible.

Common UX Patterns

Navigation Patterns:
  • Hamburger Menu: Collapsible menu for mobile navigation
  • Breadcrumbs: Show user's location in hierarchy
  • Tab Navigation: Organize related content sections
  • Mega Menu: Multi-column dropdown for complex sites
  • Sticky Navigation: Fixed nav bar during scrolling
Input Patterns:
  • Autocomplete: Suggest completions as user types
  • Input Masking: Format input (phone, credit card)
  • Inline Validation: Real-time error feedback
  • Multi-Step Forms: Break long forms into steps
  • Search Filters: Refine results with faceted search

📱 Responsive Design

Breakpoints

Device Breakpoint Layout Considerations
Mobile 320px - 480px Single column, touch-friendly targets
Tablet 481px - 768px Two columns, optimized spacing
Desktop 769px - 1024px Multi-column layouts, hover states
Large Desktop 1025px+ Wide layouts, max-width containers

Mobile-First Approach

Mobile-First Benefits:
  • Performance: Start with essential content and features
  • Progressive Enhancement: Add complexity for larger screens
  • Focus: Prioritize critical user needs
  • Flexibility: Easier to scale up than scale down

Responsive Techniques

Fluid Layouts

  • Percentage-based widths
  • CSS Grid and Flexbox
  • Viewport units (vw, vh)
  • max-width constraints

Flexible Media

  • Responsive images (srcset)
  • Picture element for art direction
  • SVG for scalable graphics
  • Aspect ratio boxes

Media Queries

  • Breakpoint-based styling
  • Orientation queries
  • Feature detection
  • Container queries (new)

Touch Optimization

  • 44x44px minimum touch targets
  • Adequate spacing between elements
  • Touch gesture support
  • Prevent accidental taps
