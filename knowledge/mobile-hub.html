📋 Prerequisites & Recommendations

✅ Recommended Background

  • JavaScript/TypeScript (React Native)
  • OR Dart basics (Flutter)
  • Understanding of UI components
  • No mobile experience required

🛠️ Tools You'll Use

  • React Native CLI / Expo
  • Flutter SDK & Dart
  • Android Studio / Xcode
  • SQLite / Realm databases

🎯 What You'll Build

  • Task manager app (React Native)
  • Weather app (Flutter)
  • Camera integration app
  • Offline-sync note-taking app
