Risk Calculation Methodology

CORTEX uses a quantitative risk scoring system that combines likelihood and impact assessments. Risk scores guide prioritization and resource allocation for mitigation efforts.

Risk Score Formula 
Risk Score = (Likelihood × Impact) × Asset Value Multiplier

Likelihood Scale (1-5):
1 = Rare (< 10% probability/year)
2 = Unlikely (10-25%)
3 = Possible (25-50%)
4 = Likely (50-75%)
5 = Almost Certain (> 75%)

Impact Scale (1-5):
1 = Negligible (minimal disruption)
2 = Minor (limited data/service impact)
3 = Moderate (significant operational impact)
4 = Major (severe data breach/outage)
5 = Catastrophic (system compromise/data loss)

Asset Value Multiplier (0.5-2.0):
0.5 = Low-criticality assets
1.0 = Standard assets
1.5 = High-criticality assets
2.0 = Mission-critical assets

Risk Treatment Strategies

✅

Accept

When: Risk score < 5, cost of mitigation exceeds risk impact
Action: Document acceptance, monitor regularly, set review date
Example: Low-traffic API endpoint with minimal sensitive data

🚫

Avoid

When: Risk score > 20, eliminating activity feasible
Action: Remove vulnerable feature, redesign architecture
Example: Disable insecure legacy authentication method

🛡️

Mitigate

When: Risk score 10-19, controls available and cost-effective
Action: Implement security controls, reduce likelihood/impact
Example: Add input validation, encryption, access controls

🔄

Transfer

When: Risk score 15-25, third-party better positioned
Action: Purchase insurance, outsource to specialized vendor
Example: Use managed security service for DDoS protection
