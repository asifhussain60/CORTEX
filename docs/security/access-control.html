RBAC Architecture

CORTEX implements a hierarchical Role-Based Access Control system with four primary roles: Administrator, Developer, Analyst, and Viewer. Each role inherits permissions from lower-privilege roles.

Access Control Principles

Least Privilege

Users granted minimum permissions necessary to perform their job functions. Privilege escalation requires approval workflow.

Separation of Duties

Critical operations require multiple authorized users. No single user can complete sensitive workflows independently.

Time-Based Access

Temporary elevated permissions expire automatically. Access reviews conducted quarterly to validate continued need.

Zero Trust Model

Verify every access request regardless of location. No implicit trust based on network position or previous authentication.

Implementation Guide

RBAC Decorator Example

# Python RBAC Decorator for CORTEX Operations
from functools import wraps
from cortex_brain.tier0.security import check_permissions

def require_role(role: str):
    """Decorator to enforce role-based access control."""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            if not check_permissions(current_user, role):
                raise PermissionDenied(
                    f"User lacks required role: {role}"
                )
            return func(*args, **kwargs)
        return wrapper
    return decorator

# Usage Examples
@require_role('Administrator')
def delete_user(user_id: str):
    """Admin-only: Delete user account."""
    pass

@require_role('Developer')
def deploy_code(branch: str):
    """Developer-only: Deploy code to production."""
    pass

@require_role('Analyst')
def generate_report(report_type: str):
    """Analyst-only: Generate security reports."""
    pass
