Applying STRIDE to CORTEX

🎭

Spoofing

Threat: Attacker impersonates CORTEX user or service
Mitigation: Multi-factor authentication, API key rotation, JWT with short expiry

🔄

Tampering

Threat: Unauthorized modification of code, configs, or data
Mitigation: Git commit signing, file integrity monitoring, immutable audit logs

🚫

Repudiation

Threat: User denies performing malicious action
Mitigation: Comprehensive audit logging, non-repudiation signatures, event correlation

📢

Information Disclosure

Threat: Sensitive data exposed through logs, errors, or leaks
Mitigation: Data sanitization, encryption at rest/transit, minimal logging

⛔

Denial of Service

Threat: Resource exhaustion preventing legitimate use
Mitigation: Rate limiting, input validation, resource quotas, graceful degradation

⬆️

Elevation of Privilege

Threat: Attacker gains higher permissions than authorized
Mitigation: Principle of least privilege, input validation, secure defaults
