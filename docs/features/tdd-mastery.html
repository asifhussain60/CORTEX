Executive Summary

TDD Mastery transforms test-driven development from a manual discipline into an automated workflow. CORTEX enforces the RED-GREEN-REFACTOR cycle through SKULL Protection rules, ensuring tests are written first and fail before implementation. The system validates coverage across 4 layers (unit, integration, system, acceptance) and maintains a 94% success rate for test-first development.

How It Works

🔴 RED Phase: Write Failing Tests

▼

What happens:

  • CORTEX generates comprehensive test cases before any implementation
  • Tests MUST fail initially (verified by RED_PHASE_VALIDATION rule)
  • Covers all 4 layers: unit, integration, system, acceptance
  • Tests are executable immediately with clear failure messages

Enforcement:

  • TDD_ENFORCEMENT: Blocks implementation without failing tests
  • RED_PHASE_VALIDATION: Validates tests fail before GREEN phase
  • Brain Protector alerts if implementation starts too early

🟢 GREEN Phase: Implement Solution

▼

What happens:

  • Write minimal code to make tests pass
  • Focus on functionality, not perfection
  • Run tests continuously to verify progress
  • All tests must pass before moving to REFACTOR

Success criteria:

  • All RED phase tests now pass
  • No new test failures introduced
  • Code coverage targets met (per-layer validation)

♻️ REFACTOR Phase: Optimize & Clean

▼

What happens:

  • Improve code quality without changing behavior
  • Remove duplication (enforced by HOLISTIC_CODE_DISCOVERY_ENFORCEMENT)
  • Optimize performance and readability
  • Clean up orphaned code (enforced by REFACTOR_CODE_CLEANUP_ENFORCEMENT)

Enforcement:

  • REFACTOR_CODE_CLEANUP_ENFORCEMENT: Mandates removal of dead code
  • Tests must continue passing throughout refactoring
  • Brain Protector prevents refactoring that breaks tests

SKULL Protection Rules

TDD Mastery is enforced by 3 core SKULL rules that protect the TDD workflow:

TDD_ENFORCEMENT

Mandates RED→GREEN→REFACTOR cycle. Implementation blocked until failing tests exist.

RED_PHASE_VALIDATION

Validates tests fail before implementation begins. Prevents false-positive passing tests.

REFACTOR_CODE_CLEANUP_ENFORCEMENT

Requires removal of orphaned and duplicate code during refactoring phase.
