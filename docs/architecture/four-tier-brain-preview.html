Real-World Examples

Creating a Plan

User: /CORTEX plan user authentication
T0 Governance: Enforce PLANNING_ISOLATION rule (plan only, don't implement)
T1 Working Memory: Create new plan entry, set status = "active", phase = 0
T2 Knowledge Graph: Query for authentication patterns, best practices, security considerations
T3 Dev Context: Scan project for existing auth code, identify integration points
Output: 17-phase plan document with knowledge-enriched steps, Phase -1 security patterns, and DoR/DoD checklists

TDD Session

User: tdd login function
T0 Governance: Enforce TDD_ENFORCEMENT (RED→GREEN→REFACTOR mandatory)
T1 Working Memory: Check for active TDD session, resume if exists
T2 Knowledge Graph: Load testing patterns for login functions from Phase -1 library
T3 Dev Context: Identify test framework (pytest/jest), locate test files, check coverage
Output: Failing test first (RED), then minimal implementation (GREEN), then refactor (REFACTOR)

Resuming Work

User: continue
T1 Working Memory: Query last 3 sessions from conversation-context.jsonl, find most recent orchestrator
T1 PlanningStateDB: Load plan state (current phase, completed tasks, progress percentage)
T2 Knowledge Graph: Recall context from previous session, relevant patterns
T3 Dev Context: Re-scan workspace for changes since last session (git diff, file modifications)
Output: "Resuming Phase 5: Implementation (3/8 tasks complete, 37% progress)"
