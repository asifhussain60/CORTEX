Architecture Overview

CORTEX is built on a 4-tier brain architecture that provides intelligent memory management, pattern learning, and context preservation across conversations. Tier 0 Governance enforces SKULL brain protection rules, ensuring safety and quality. Two specialist agents (Planning and Strategic Reasoning) coordinate complex multi-phase workflows with sub-100ms working memory access.
