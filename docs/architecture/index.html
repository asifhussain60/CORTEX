CORTEX Architecture

4-Tier Brain System + Tier 0 Governance + Agent Intelligence + Orchestrator Ecosystem

Executive Summary

CORTEX is built on a 4-tier brain architecture that provides intelligent memory management, pattern learning, and context preservation across conversations. Tier 0 Governance enforces SKULL brain protection rules, ensuring safety and quality. Two specialist agents (Planning and Strategic Reasoning) work within orchestrators to coordinate complex multi-phase workflows with sub-100ms working memory access.

Four-Tier Brain Architecture

The brain is organized into four hierarchical tiers, each serving a distinct purpose in memory management and intelligence. Tier 0 Governance validates all operations, ensuring SKULL rules are enforced. Data flows from governance through working memory to long-term pattern storage.

Tier Deep Dive

Tier 0: SKULL Governance

Brain Protection & Safety Validation

Purpose

  • Validates all operations before execution
  • Enforces SKULL brain protection rules
  • Prevents code duplication and anti-patterns
  • First line of defense for brain integrity

SKULL Rules

  • TDD_ENFORCEMENT: RED→GREEN→REFACTOR mandatory
  • HOLISTIC_DISCOVERY: Search before create
  • REFACTOR_CLEANUP: Remove orphaned code
  • GIT_ISOLATION: CORTEX/user repo separation

Storage

cortex-brain/brain-protection-rules.yaml

Tier 1: Working Memory

70-Conversation FIFO Buffer

Purpose

  • Recent conversation history with fast access
  • Sub-100ms retrieval performance
  • Context for current session
  • FIFO buffer prevents unbounded growth

Capabilities

  • Retention: Last 70 conversations
  • Format: JSON Lines (JSONL)
  • Cleanup: Automatic FIFO eviction
  • Performance: < 100ms retrieval

Storage

cortex-brain/tier1/working-memory.jsonl

Tier 2: Knowledge Graph

Pattern Learning & Relationships

Purpose

  • Long-term pattern recognition
  • Relationship mapping between concepts
  • Learning from past interactions
  • Semantic understanding of codebase

Capabilities

  • Nodes: Files, functions, concepts
  • Edges: Dependencies, relationships
  • Inference: Pattern detection
  • Evolution: Continuous learning

Storage

cortex-brain/tier2/knowledge-graph.yaml

Tier 3: Development Context

Per-Repo Metrics & Analytics

Purpose

  • Repository-specific development patterns
  • Code quality metrics and trends
  • Team velocity and productivity
  • Technology stack preferences

Capabilities

  • Metrics: Coverage, complexity, velocity
  • Patterns: Common issues, solutions
  • Tech Stack: Languages, frameworks
  • History: Evolution over time

Orchestrator Ecosystem

CORTEX provides 8 production orchestrators that coordinate complex multi-phase workflows. Each orchestrator leverages the 4-tier brain and specialist agents to deliver intelligent automation.

Planning System

Autonomous 10-phase planning with context gathering, knowledge graph reasoning, and AST analysis.

AUTONOMOUS

TDD Orchestrator

Enforces RED→GREEN→REFACTOR cycle with test generation, implementation, and cleanup.

GUIDED

ADO Operations

AUTONOMOUS

Debug Orchestrator

GUIDED

Maintenance

12-phase health pipeline with auto-repair, bloat detection, and system optimization.

GUIDED

Sanitization

5-phase anonymization workflow removing PII, credentials, and proprietary information.

GUIDED

Refinement

GUIDED
