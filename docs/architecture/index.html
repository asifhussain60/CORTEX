Executive Summary

CORTEX is built on a 4-tier brain architecture that provides intelligent memory management, pattern learning, and context preservation across conversations. Tier 0 Governance enforces SKULL brain protection rules, ensuring safety and quality. Two specialist agents (Planning and Strategic Reasoning) work within orchestrators to coordinate complex multi-phase workflows with sub-100ms working memory access.

Key Architectural Principles

Brain Protection First

Tier 0 SKULL rules enforce safety at governance layer, validating all operations before execution

Test-Driven Development

TDD mandatory for all production code with strict RED→GREEN→REFACTOR cycle enforcement

Git Isolation

CORTEX code never mixed with user repositories, ensuring clean separation of concerns

Context Preservation

4-Tier Brain maintains long-term memory across sessions with sub-100ms working memory access

Agent Specialization

Dedicated agents for planning and strategic reasoning coordinate complex multi-phase workflows
