Executive Summary

▼

CORTEX's architecture is a 4-tier distributed intelligence system where each floor has a specific purpose, and information travels between layers in under 100 milliseconds. At the top, Tier 0 provides governance through 22 immutable SKULL rules. Tier 1 maintains working memory of the last 70 conversations in a FIFO queue. Tier 2 builds long-term knowledge with 8,429 nodes and 24,817 connections using Hebbian learning. Tier 3 tracks development context in real-time with git activity, code metrics, and hotspot detection.

How It Works: Data Flow

▼

Information flows bidirectionally through the 4-tier architecture. Commands cascade down from governance to context, while feedback bubbles up from metrics to memory. Each data packet completes a round-trip in an average of 87 milliseconds—faster than a human eye blink (100-150ms).

⬇️ Downward Flow (Commands)

  1. Tier 0: SKULL rules validate command legality
  2. Tier 1: Working memory provides context
  3. Tier 2: Knowledge graph adds learned patterns
  4. Tier 3: Development context executes action

⬆️ Upward Flow (Feedback)

  1. Tier 3: Code metrics and git activity detected
  2. Tier 2: Patterns learned and connections strengthened
  3. Tier 1: Conversation stored in FIFO queue
  4. Tier 0: Rule violations logged and enforced
