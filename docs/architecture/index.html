Core Protection Rules

TDD Enforcement

RED→GREEN→REFACTOR mandatory

Holistic Discovery

Search before create, prevent duplication

Refactor Cleanup

Remove orphaned code, whole-file polish

Git Isolation

CORTEX never commits to user repos

Planning Isolation

Create plans only, never implement

Hand-Off Protocol

Autonomous orchestrators execute independently

flowchart LR
    INPUT[User Request] --> SKULL{SKULL Rules}

    TDD --> VALIDATE{Passes?}
    SEARCH --> VALIDATE

    EXECUTE --> REFACTOR[Cleanup Phase]
    REFACTOR --> COMPLETE[Task Complete]
