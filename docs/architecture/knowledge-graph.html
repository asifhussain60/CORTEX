📈 Learning Algorithm

When Concepts Co-Activate:
  • Detect simultaneous node activation (user query mentions both)
  • Increment edge weight: weight += 0.05
  • Visual update: light purple → cyan (learning indicator)
  • After multiple co-activations (>20), promote to gold
When Connections Weaken:
  • Time decay if not co-activated: weight -= 0.01/day
  • Edges below 0.15 threshold marked for pruning
  • Automatic cleanup removes weak edges (keeps graph lean)
  • Strong connections (>0.7) resist decay—persistent knowledge

🎯 Force-Directed Graph Physics

Graph physics automatically organizes concepts without manual categorization

⚛️ Physics Simulation

▼

Force-directed layout treats nodes as charged particles and edges as springs. Strongly connected nodes pull together, weakly connected nodes push apart. The result: semantic clusters emerge naturally.

Attractive Forces:
  • Edges act as springs pulling connected nodes closer
  • Strong edges (gold) = stronger spring force
  • Nodes with many connections become cluster centers
Repulsive Forces:
  • All nodes repel each other (prevent overlap)
  • Weakly connected nodes pushed to graph periphery
  • Creates natural spacing for readability
Result: Concepts that frequently co-occur gravitate together. TDD, Test Coverage, and Red-Green-Refactor form tight cluster. Planning, ADO, DoR/DoD form another. Graph structure reveals real usage patterns—no manual organization needed.
