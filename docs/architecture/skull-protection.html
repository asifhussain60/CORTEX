How Defense-in-Depth Works

SKULL's 8-layer architecture ensures threats stop at the appropriate security boundary. Watch how legitimate and malicious traffic flow differently:

✅ Legitimate Traffic Flow

  1. Request enters Layer 1 → Path validated
  2. Passes to Layer 2 → Test location clean
  3. Passes to Layer 3 → Git isolation compliant
  4. Passes through L4-L7 → All checks pass
  5. Layer 8 governance → Approved
  6. ✅ Reaches core (<1ms total)

🚫 Malicious Traffic Flow

  1. Attack enters Layer 1 → Root path detected
  2. 🛑 BLOCKED immediately
  3. Event logged with timestamp
  4. Threat categorized (document violation)
  5. Layer 1 counter incremented (+1)
  6. ❌ Never proceeds to inner layers
Key Insight:

Defense succeeds when threats stop at the appropriate layer. Layer 1 blocks 847 document violations so they never reach Layer 2. Layer 3 blocks 156 git pollution attempts so they never threaten Layer 4's database integrity. This layered approach prevents cascading failures and ensures each threat is handled by its specialized defense.

🤖 Brain Protector: The Enforcement Engine

The Brain Protector is CORTEX's Tier 0 enforcement engine—a specialized agent that monitors all operations against the 22 SKULL rules. When a violation is detected, it intervenes with evidence-based reasoning.

How Brain Protector Works

  1. Pre-Action Validation: Analyzes proposed action against all 22 SKULL rules
  2. Rule Matching: Identifies which rules apply to the current context
  3. Violation Detection: Flags conflicts with governance policies
  4. Evidence Collection: Gathers context, file paths, and rule citations
  5. Intervention: Stops action with clear explanation of why it violates governance
  6. Alternative Suggestion: Proposes correct approach that complies with rules

Example Intervention

❌ Attempted: Create /CORTEX/summary.md (root level)
🛡️ Brain Protector: Blocked by Layer 1 (Document Organization)
Rule: DOCUMENT_ORGANIZATION_ENFORCEMENT
Reason: Root-level documentation violates structured storage policy
✅ Suggested: cortex-brain/documents/summaries/system-summary.md
