Ecosystem Overview

The CORTEX Orchestrator Ecosystem consists of 10 specialized orchestrators coordinated through the Master Orchestrator Hub. Each orchestrator is an autonomous workflow coordinator that transforms natural language commands into multi-phase operations, handling everything from strategic planning to code refinement and debugging.

Ecosystem Capabilities

Autonomous Execution

Self-managing workflows with minimal human intervention. Each orchestrator coordinates multi-phase operations independently.

SKULL Protection

Built-in brain protection rules ensure safe operations: TDD enforcement, holistic discovery, git isolation, and planning isolation.

Rollback Support

Automatic git checkpoints and recovery mechanisms at every critical phase. All destructive operations are reversible.

Inter-Orchestrator Communication

Orchestrators share context via the Master Hub. Planning generates ADO work items, TDD uses Lens analysis, Debug leverages Lens insights.
