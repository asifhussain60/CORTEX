## 🎯 Learning Objective

Decision-makers understand CORTEX is a governed orchestration layer — not another AI coding tool — designed to dissolve the false choice between velocity and rigour for every role, in every commit.

## 🎬 Scene Sequence (7–10 min target)

### HERO INTRO (VBP-014 — 5s)
**Visual:** Deep space navy `#0a0e27`. Floating cyan/purple particles. `cortex-logo-512.png` hero-scale with pulsing cyan glow. Title typewriter-reveals: "What Is CORTEX?" → subtitle fades: "Governance. Orchestration. Reliability." Logo shrinks to watermark → Scene 1.

### Scene 1 — The Problem (90s) [VBP-002 hook, VBP-006 contrast]
**Visual:** Split-screen animation: LEFT shows chaotic code fragments, flashing red warnings, scattered team icons working in silos. RIGHT is black, waiting. A counter ticks up: "Technical Debt: $847K/year" in pulsing red `#ff4757`.
**Narration:** Modern codebases are vast. Engineers operate with fragments. AI makes us type faster — but speed without guardrails creates invisible debt. The result: fear. Fear of breaking production, changing legacy systems, making costly mistakes. And the knowledge to do it right? It is scattered across wikis, post-mortems, and the memories of engineers who have already moved on.
**Animation:** Chaos fragments consolidate into a single glowing brain outline → CORTEX logo materialises inside it. RIGHT panel illuminates with calm cyan grid. A knowledge library icon pulses briefly — a curated repository of best practices, ready to be consulted.

### Scene 2 — Pillar 1: Understand Everything (120s) [VBP-015 breadcrumb: ●○○]
**Visual:** LENS Intelligence Pipeline diagram animates layer by layer — Language→Examination→Navigation→Synthesis. Each layer lights up as narration reaches it. Code files stream into the pipeline from the left, structured insights emerge right. A curated knowledge repository icon (bookshelf with 80+ YAML spines) appears beneath the pipeline — connected by a pulsing feed line. A document stack (Word, Excel, PDF icons) flows into a Document Ingest Pipeline channel — converting external docs into structured knowledge.
**Narration:** Before a single line is written, CORTEX reads your entire repository. The LENS pipeline — Language, Examination, Navigation, Synthesis — analyses code structure, patterns, and dependencies. But intelligence is more than reading code. Behind LENS sits a curated knowledge repository — over 80 structured best-practice files spanning security, architecture, testing, migration playbooks, and industry-specific governance. The Document Ingest Pipeline extends this further — ingesting Word, Excel, PowerPoint, and PDF documents, extracting knowledge, and routing it to the appropriate domain. Every recommendation is versioned, traceable, and surfaced automatically at the moment a developer needs it.
**Animation:** Breadcrumb bar top-of-frame: "Understand Everything" glows full brightness; other two pillars at 30% opacity. Pipeline nodes pulse cyan on mention. Knowledge repository bookshelf animates: spines glow as domains are mentioned — security (red), architecture (purple), testing (gold). Document icons (Word blue, Excel green, PDF red) flow into the ingest pipeline and transform into knowledge cards.

### Scene 3 — Pillar 2: Empower Everyone (120s) [VBP-015 breadcrumb: ✅●○]
**Visual:** Intelligence Diamond (3-tier) spins into frame — Skull (static rules) at base, Core (pattern recognition) in middle, Cortex (strategic reasoning) at apex. Labels animate on each tier. Four role cards orbit it: Engineer, Architect, Product Owner, Business Leader. Each card flies forward when its role is narrated, showing a 3-second role-specific micro-animation. A Documentation Intelligence icon (60+ practices across 10 sub-domains) appears — glowing when documentation quality is mentioned.
**Narration:** The Intelligence Diamond operates across three tiers. The Skull layer enforces static rules — naming, structure, compliance. The Core layer recognises patterns — anti-patterns, code smells, architectural drift. The Cortex layer reasons strategically — decomposing problems, selecting approaches, weighing trade-offs. Together, over 350 specialised reasoning engines work inside your IDE. Documentation Intelligence provides 60+ best practices across 10 sub-domains — from API documentation to runbooks to architecture decision records. For Engineers: a senior pair-programmer who remembers your codebase. For Product Owners: backlog-to-delivery intelligence. For Leaders: compliance and ROI visibility on every commit.
**Animation:** Role cards: Engineer→code flying into test harness; PO→requirements morphing into delivery plan; Architect→blueprint auto-validating; Leader→dashboard metrics rising green. Intelligence Diamond tiers illuminate bottom-to-top as each is narrated. Documentation Intelligence icon (book with checkmarks) glows amber. Covey quote on glass pill: "Empowered individuals lead to collective success."

### Scene 4 — Pillar 3: Build Fearlessly (120s) [VBP-015 breadcrumb: ✅✅●]
**Visual:** Universal Convergence Gate — animated loop: detect (red scan)→fix (amber wrench)→rescan (green check). Loop cycles 3 times, each time the violation counter drops: 12→4→0. Confetti burst on zero. A source protection shield icon appears with 15 protected directories listed. A golden test validation panel shows 14-rule rendering checks passing.
**Narration:** Governance is infrastructure, not friction. The convergence gate is designed to loop — detect, fix, rescan — until critical violations resolve. The Vacuum Source Protection system guarantees that core directories — cortex/, tests/, .github/, scripts/ — are permanently protected from modification. Threat models evaluate risk before production. Golden tests validate 14 mandatory rendering rules for every response template. Root cause analysis helps ensure mistakes are captured and addressed. Collins reminds us: "Technology accelerates momentum, not creates it."
**Animation:** Each detect-fix-rescan cycle is a distinct animated ring. Violation counter pulses red→amber→green. Source protection shield glows with 15 directory names orbiting it. Golden test panel shows checkmarks appearing for each rule. RCA memory node glows: "Pattern captured. Never again."

### Scene 5 — The Transformation (60s) [VBP-011 strategic silence]
**Visual:** Split-screen morphs into unified view. Three pillar icons align vertically: eye (Understand)→hands (Empower)→shield (Build). They merge into the CORTEX logo.
**Narration:** By handling compliance, administration, and the safety net, CORTEX is designed to change the job description. Your team stops merely coding — and starts envisioning. [1.5s SILENCE] CORTEX does not make AI smarter. It makes AI-assisted development accountable.
**Animation:** Tagline typewriter-reveals: "Governance. Orchestration. Reliability." Logo holds 3s. Fade to black.
