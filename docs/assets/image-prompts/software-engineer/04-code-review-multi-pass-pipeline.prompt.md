# Image Prompt — SE-04 — Code Review Multi-Pass Pipeline

**Target Use:** Hero image for Code Review Orchestrator capability. Used in documentation, presentations, and video backgrounds.
**Style:** Dark-blue glassmorphism · Cyan #00d4ff accent · 16:9 landscape · 1920×1080
**Tool:** DALL-E 3, Midjourney, or equivalent AI image generator

---

## Prompt

Create a highly detailed technical visualization in a dark-blue glassmorphism style (background #0a0e27, panels with rgba(26,31,58,0.7) fill, 1px rgba(255,255,255,0.1) border, 12px radius, 16px blur, cyan #00d4ff accent glow). 16:9 landscape ratio, 1920×1080 resolution.

CRITICAL LAYOUT RULE: All content must be inset within a safe zone with a minimum 60px margin on all four sides (left, right, top, bottom). No element, text, icon, border, glow, or card should touch or bleed into the outer 60px edge boundary. The outer margin area must remain the plain dark navy background (#0a0e27) with no content. This ensures clean rendering with no cropped or edge-clipped elements.

The image should show:
- A horizontal pipeline flowing left-to-right with FIVE glassmorphic pass cards, each representing a review dimension:
  1. "Structural Analysis" (cyan border) — architecture conformance, complexity, coupling icons
  2. "Security Audit" (rose #f43f5e border) — shield icon, lock icon, key scanning
  3. "Governance Compliance" (amber #f59e0b border) — checkmark grid, rule validation
  4. "Test Coverage Gaps" (emerald #10b981 border) — test tube icon with gap indicators
  5. "Style Conformance" (purple #7b61ff border) — formatting icon, naming conventions
- Each pass card has a small severity badge: P0 (red), P1 (orange), P2 (yellow), P3 (grey)
- Thin connecting arrows between passes showing the multi-pass flow
- A "Changed Files" input on the left feeding into the pipeline
- A "Review Report" output on the right with inline comment icons
- Subtle code diff fragments floating in the background (decorative — green additions, red deletions)
- Professional, technical, immediately communicates multi-dimensional automated code review
- No photographic elements — pure pipeline visualization
- No logo, wordmark, title text, or branding in any corner — all four corners must remain empty dark navy background

Style: Horizontal pipeline diagram. Dark glassmorphism. Multi-pass review metaphor. Enterprise reference quality. All glow effects must terminate well within the safe zone.
