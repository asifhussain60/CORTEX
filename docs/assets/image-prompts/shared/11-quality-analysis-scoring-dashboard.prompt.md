## Prompt

Create a highly detailed technical visualization in a dark-blue glassmorphism style (background #0a0e27, panels with rgba(26,31,58,0.7) fill, 1px rgba(255,255,255,0.1) border, 12px radius, 16px blur, cyan #00d4ff accent glow). 16:9 landscape ratio, 1920×1080 resolution.

CRITICAL LAYOUT RULE: All content must be inset within a safe zone with a minimum 60px margin on all four sides (left, right, top, bottom). No element, text, icon, border, glow, or card should touch or bleed into the outer 60px edge boundary. The outer margin area must remain the plain dark navy background (#0a0e27) with no content. This ensures clean rendering with no cropped or edge-clipped elements.

The image should show:
- A prominent CENTRAL circular gauge (speedometer style) labeled "Overall Quality Score" displaying "87/100" with a cyan-to-green gradient arc
- FIVE vertical glassmorphic score columns flanking the central gauge (2 on left, 3 on right — or balanced layout), each representing a quality dimension:
  1. "Structural Complexity" — bar at 82/100 with a crystalline lattice icon, cyan #00d4ff fill
  2. "Test Coverage" — bar at 91/100 with a shield-check icon, emerald #10b981 fill
  3. "Documentation" — bar at 78/100 with a document/book icon, amber #f59e0b fill
  4. "Dependency Health" — bar at 85/100 with a chain-link/tree icon, teal #2dd4bf fill
  5. "Governance Compliance" — bar at 94/100 with a gavel/shield icon, purple #7b61ff fill
- Each column shows a small sparkline trend graph at the bottom indicating score trajectory over time (trending up or stable)
- Below the columns: a thin horizontal "Code Review Integration" strip showing icons for 5 review passes (structural → security → governance → test-coverage → style) connected by a directional flow arrow
- Faint floating code fragments in the background (Python/TypeScript snippets) as decorative texture
- Professional, data-driven dashboard aesthetic — immediately communicates multi-dimensional quality scoring
- No photographic elements — pure analytics dashboard visualization
- No logo, wordmark, title text, or branding in any corner — all four corners must remain empty dark navy background

Style: Analytics dashboard. Dark glassmorphism. Multi-gauge scoring metaphor. Enterprise quality intelligence reference quality. All glow effects must terminate well within the safe zone.
