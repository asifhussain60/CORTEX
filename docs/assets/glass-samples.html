Governance & Vocabulary

Strict structural definitions and active rule sets within the CORTEX environment.

Core Terminology

Convergence Gate
A mandatory detect→fix→rescan loop applied to code-modifying operations, ensuring zero critical violations remain before completion.
Golden Tests
The highest-priority behaviours that must never break. Serial execution ensures deterministic, blocking validation on every commit.
Thin Index Contract
Governance rule requiring master plan files to remain a reference index only (≤500 lines) to prevent token context exhaustion.
"Don't leave broken windows unfixed. Fix each one as soon as it is discovered."

MCP Gateway Tools

A selection of the 35+ capabilities available directly in your coding assistant via the Model Context Protocol.

cortex_classify

Classifies a request into one of 31 intent types and returns the routing decision in under 40 milliseconds.

cortex_validate

Checks code or a proposed operation against active governance rules before any execution begins.

cortex_refactor

Performs semantic refactoring across Python, C#, and TypeScript with full before-and-after analysis and governance validation.

cortex_learning

Emits reinforcement signals, queries the learning history, and accesses root cause analysis with structured methodologies.

cortex_generate_tests

Generates failing tests from a feature specification, ready for the implementation phase.

cortex_git

Executes git operations—branching, committing, conflict resolution—through the governance-aware git layer.
