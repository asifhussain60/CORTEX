🔍 About CORTEX LENS

CORTEX LENS provides comprehensive AST (Abstract Syntax Tree) analysis for understanding codebase architecture. Features include:

  • Dependency Graphs: Interactive D3.js visualizations of module relationships
  • Complexity Metrics: Cyclomatic complexity, maintainability index, LOC
  • Architecture Analysis: Layer detection, coupling analysis, cohesion metrics
  • Security Scanning: Vulnerability detection and security patterns
  • Documentation Coverage: Docstring analysis and coverage reporting
