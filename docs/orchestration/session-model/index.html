Session Model

CORTEX Orchestration System

Overview

Unified Session Model for CORTEX Orchestrators

Provides type-safe, consistent state management across all orchestrators.
Eliminates Dict-based state management issues.

Version: 1.0.0
Author: Asif Hussain
