# Glossary

- **Master Plan**: Phase index and execution status.
- **Phase Detail File**: Executable blueprint for one phase.
- **MCP**: Tool integration layer used by workflows.
- **Convergence Gate**: Detect-fix-rescan stability loop.
- **Sweep Completeness**: Full issue catalogue closure rule.
- **Capability Manifest**: Ownership map for LLM-native, hybrid, and platform-owned behavior.
- **Cross-cutting Intelligence**: Shared quality/governance logic applied across all modes.
