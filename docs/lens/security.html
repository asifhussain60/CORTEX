🚨 Detected Patterns

CWE-94: Code Injection

CRITICAL - AUTO BLOCKED

Risk: Arbitrary code execution from untrusted input

Detection: eval(), exec(), dynamic code compilation

❌ Vulnerable Code:

# VULNERABLE - CWE-94 Detected
user_input = request.GET['code']
eval(user_input) # ← BLOCKED BY CHALLENGE ENGINE

✅ Secure Alternative:

# SECURE - Input validation + safe execution
if is_valid_expression(user_input):
    result = safe_eval(user_input, allowed_functions)

CWE-95: Unsafe Deserialization

HIGH - WARNING + RECOMMENDATION

Risk: Remote code execution via malicious serialized objects

Detection: pickle.loads(), yaml.load() without SafeLoader

❌ Vulnerable Code:

import pickle
data = pickle.loads(untrusted_input) # ← CWE-95 DETECTED

✅ Secure Alternative:

import json
data = json.loads(untrusted_input) # Use JSON instead

CWE-78: Command Injection

CRITICAL - AUTO BLOCKED

Risk: OS command execution from untrusted input

Detection: os.system(), subprocess.call() with shell=True

❌ Vulnerable Code:

import os
os.system(f"rm {user_file}") # ← BLOCKED BY CHALLENGE ENGINE

✅ Secure Alternative:

import subprocess
subprocess.run(['rm', user_file], shell=False) # Safe execution

CWE-89: SQL Injection

CRITICAL - AUTO BLOCKED

Risk: Database manipulation via SQL injection

Detection: String concatenation in SQL queries

❌ Vulnerable Code:

query = f"SELECT * FROM users WHERE id = {user_id}" # ← CWE-89 DETECTED
cursor.execute(query)

✅ Secure Alternative:

query = "SELECT * FROM users WHERE id = %s"
cursor.execute(query, (user_id,)) # Parameterized query

CWE-327: Weak Cryptography

HIGH - WARNING + RECOMMENDATION

Risk: Data compromise via weak encryption algorithms

Detection: MD5, SHA1, DES usage

❌ Vulnerable Code:

import hashlib
password_hash = hashlib.md5(password).hexdigest() # ← CWE-327 DETECTED

✅ Secure Alternative:

import bcrypt
password_hash = bcrypt.hashpw(password, bcrypt.gensalt()) # Strong hashing

CWE-22: Path Traversal

HIGH - WARNING + RECOMMENDATION

Risk: Unauthorized file system access

Detection: ../ patterns in file paths, unvalidated user paths

❌ Vulnerable Code:

file_path = f"/uploads/{user_filename}" # ← CWE-22 if user_filename contains ../
open(file_path, 'r')

✅ Secure Alternative:

from pathlib import Path
safe_path = Path("/uploads").joinpath(user_filename).resolve()
if safe_path.is_relative_to("/uploads"):
    open(safe_path, 'r')
