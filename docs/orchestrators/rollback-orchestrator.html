Rollback Orchestrator

Production Ready

The Rollback Orchestrator provides safe state restoration to previous checkpoints. It integrates with the PhaseCheckpointManager to list, validate, and restore checkpoints created during TDD workflows. With built-in safety checks for uncommitted changes and merge conflicts, plus dry-run mode and force override, you can confidently restore your codebase to a known-good state.

🛡️ Safety Checks

⚠️ Uncommitted Changes

Detects modified files in working tree. Rollback blocked until changes are committed or stashed. Lists all affected files.

SAFETY_MSG_UNCOMMITTED

⚠️ Merge In Progress

Checks for .git/MERGE_HEAD presence. Cannot rollback during active merge. Complete or abort merge first.

SAFETY_MSG_MERGE

✅ Checkpoint Exists

Validates checkpoint ID exists in PhaseCheckpointManager registry before attempting rollback.

validate_checkpoint()

✅ User Confirmation

Shows diff preview (optional) and requires explicit user confirmation before executing rollback.

confirm_rollback()

⚙️ Command Options

Option Description Default Example
--dry-run Preview rollback without executing false rollback abc123 --dry-run
--force Skip safety checks (dangerous) false rollback abc123 --force
--show-diff Show git diff before confirming false rollback abc123 --show-diff
--session Specify session ID for checkpoint lookup current rollback abc123 --session my-session
