ADO Operations

Azure DevOps

Writing Azure DevOps work items is tedious—formatting acceptance criteria, linking stories to features, ensuring DoR/DoD compliance. ADO Operations generates perfectly formatted ADO work items from your natural language descriptions, complete with acceptance criteria, story points, and proper linking. Copy-paste directly into ADO or use the API integration for automatic creation.

## Feature: User Registration Flow

**Business Value:** Enable new users to create accounts, 
increasing user base and engagement metrics.

### Story 1: Email Registration
**As a** new user
**I want to** register with my email
**So that** I can access the platform

**Acceptance Criteria:**
- [ ] Given valid email, when submitted, then account created
- [ ] Given existing email, when submitted, then error shown
- [ ] Given weak password, when submitted, then requirements shown

**Story Points:** 5
**DoR:** ✅ Requirements clear, design approved
**DoD:** ✅ Tests pass, code reviewed, deployed to staging
