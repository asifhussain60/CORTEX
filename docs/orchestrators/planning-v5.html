📊 8-Factor Complexity Scoring

Planning v5.0 uses a sophisticated multi-dimensional complexity model to guide strategy selection and phase breakdown. Each factor contributes to the overall complexity score (0-100 scale).

1. Lines of Code (LOC): Estimated code volume (weight: 15%)
2. File Count: Number of files to create/modify (weight: 10%)
3. Dependency Depth: Transitive dependency count (weight: 20%)
4. Cognitive Complexity: Cyclomatic complexity estimate (weight: 15%)
5. Integration Points: External system connections (weight: 12%)
6. Risk Level: Breaking change potential (weight: 18%)
7. Test Coverage: Required test scenarios (weight: 5%)
8. Documentation Burden: Doc pages to create/update (weight: 5%)

Strategy Selection Thresholds

0-30: Skeleton Strategy (quick scaffolding)
31-60: Incremental Strategy (3-5 phases)
61-85: Incremental Strategy (6-8 phases)
86-100: Incremental Strategy (9-12 phases)
