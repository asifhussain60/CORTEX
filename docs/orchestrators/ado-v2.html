🗂️ Work Item Hierarchy

ADO v2.0 generates a complete 3-tier hierarchy following Azure DevOps best practices:

🎯 Features (Epic-level)

High-level business capabilities
Maps to Planning v5 "Feature" scope
Contains: Title, Description, Business Value, Acceptance Criteria
Example: "User Authentication System"

📖 User Stories (Requirement-level)

User-focused functional requirements
Maps to Planning v5 "Phases"
Contains: As-a / I-want / So-that, Acceptance Criteria, Story Points
Example: "As a user, I want OAuth2 login so that I can access with Google"

✅ Tasks (Implementation-level)

Technical implementation tasks
Maps to Planning v5 "Phase Tasks"
Contains: Description, Effort (hours), Remaining Work, Activity
Example: "Implement OAuth2 provider integration (8 hours)"

📊 CSV Output Format

Generated CSV files are ADO-compliant and ready for immediate import. All required columns are included with proper data types and formatting. 

Work Item Type,Title,Description,Acceptance Criteria,State,Priority,Effort,Tags,Area Path,Iteration Path,Parent
Feature,User Authentication System,"Implement secure user authentication...","AC-1: Users can login with OAuth2...",New,1,,auth;security,MyProject\Backend,Sprint 24,
User Story,OAuth2 Login,"As a user I want to login with Google...","Given user clicks Google login...",New,1,13,auth;oauth,MyProject\Backend,Sprint 24,User Authentication System
Task,Implement OAuth2 Provider,"Create OAuth2Provider class...","Task complete when unit tests pass",New,2,8,implementation,MyProject\Backend,Sprint 24,OAuth2 Login

Standard Columns

Work Item Type: Feature | User Story | Task
Title: Concise work item name (50-80 chars)
Description: Detailed explanation with markdown
Acceptance Criteria: GIVEN-WHEN-THEN or SC-X format
State: New | Active | Resolved | Closed
Priority: 1 (Critical) → 4 (Low)
Effort: Story Points (Stories) or Hours (Tasks)
Tags: Semicolon-separated keywords
Area Path: Project\Component hierarchy
Iteration Path: Sprint or release timeline
Parent: Parent work item title (for hierarchy)
