Pre-Flight Orchestrator

Production Ready

The Pre-Flight Orchestrator validates your development environment BEFORE executing a feature plan. It detects project patterns (FastAPI, .NET, Node.js, Docker), generates environment requirements, validates installed tools, and enforces gates with remediation scripts. Prevent costly delays—like the 2-week .NET SDK blocker—before they happen.

📜 Generated Remediation Script

PowerShell 
# CORTEX Pre-Flight Remediation Script
# Generated: 2025-12-27T15:30:00Z
# Status: BLOCK (2 critical issues)

Write-Host "🛫 CORTEX Pre-Flight Environment Setup" -ForegroundColor Cyan

# Critical: Install .NET SDK 6.0
Write-Host "Installing .NET SDK 6.0..." -ForegroundColor Yellow
winget install Microsoft.DotNet.SDK.6

# Critical: Install Docker Desktop
Write-Host "Installing Docker Desktop..." -ForegroundColor Yellow
winget install Docker.DockerDesktop

# Recommended: Install Redis CLI
Write-Host "Installing Redis CLI (optional)..." -ForegroundColor Gray
winget install Redis.RedisInsight

# Verify installations
Write-Host "`n✅ Verifying installations..." -ForegroundColor Green
dotnet --version
docker --version

Write-Host "`n🎉 Environment setup complete! Re-run pre-flight check." -ForegroundColor Green
