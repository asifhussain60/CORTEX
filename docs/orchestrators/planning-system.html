🎚️ 4 Complexity Tiers

Plans are automatically classified into one of four tiers based on operation complexity:

⚡
Tier 1: INSTANT
Direct execution, no artifacts
  • Simple queries, file reads
  • 1-3 steps, ~30 seconds
  • No planning artifacts stored
📝
Tier 2: LIGHTWEIGHT
Inline notes, minimal planning
  • Single-file edits, small refactors
  • 3-8 steps, ~2 minutes
  • Inline notes only (no folder)
📋
Tier 3: DOCUMENTED
Structured plan folder
  • Multi-file changes, feature additions
  • 8-20 steps, ~10 minutes
  • Full planning folder structure
🏗️
Tier 4: COMPLEX
Multi-phase, gates, reviews
  • Architecture changes, major features
  • 20+ steps, phases with gates
  • Full documentation + phase reviews
