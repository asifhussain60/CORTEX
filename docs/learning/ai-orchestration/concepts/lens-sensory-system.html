LENS — The Sensory System.

Before CORTEX writes a single line of code, it reads your workspace with 9 parallel analysers — understanding language, structure, history, patterns, security, complexity, and more. This is LENS: the intelligence that turns raw files into an informed AnalysisContext.

~15 min read 9 analysers 3 intelligence tiers

Real-World Analogy

Think of a Medical Diagnostic Lab

A doctor doesn't diagnose from intuition alone. They order a blood panel, an X-ray, an MRI — each test reveals a different layer of the patient's condition. The lab results are synthesised into a single patient record before the clinician acts. LENS works identically.

The 9 Analysers

Each analyser produces a structured output object merged into AnalysisContext. They run concurrently via asyncio.gather().

01

Language Analyser

Detects primary and secondary languages, frameworks (Django, React, .NET), runtime versions, and package manager files.

02

Structure Analyser

Maps directory topology, identifies module boundaries, measures depth/breadth ratios, and detects architectural violations like circular imports.

03

History Analyser

Reads git log — recent commits, authors, change frequency per file, and hotspot files changed more than 10 times in 30 days.

04

Security Analyser

Scans for hardcoded secrets, SQL injection patterns, unsafe deserialization, exposed debug endpoints, and known vulnerable dependency versions.

05

Complexity Analyser

Computes cyclomatic complexity per function, cognitive complexity, nesting depth, and identifies the top 10% most complex functions as refactor candidates.

06

Test Coverage Analyser

Reads coverage reports, identifies untested modules, calculates per-domain coverage rates, and flags functions with zero test coverage as P1 risks.

07

Pattern Analyser

Identifies design patterns in use (Factory, Strategy, Observer, Decorator), antipatterns (God classes, feature envy), and naming convention compliance.

08

Dependency Analyser

Parses all package manifests, cross-references against CVE databases, detects transitive dependencies, and flags outdated packages with available patches.

09

Metrics Analyser

Collects lines of code, function counts, class hierarchies, public API surface area, docstring coverage percentage, and type annotation coverage.

Intelligence Tiers

Tiered Analysis Depth

Not every request needs a full 10-second deep scan. LENS matches analysis depth to request complexity — fast answers stay fast, and complex operations get full intelligence.

Tier 1
Per-Turn Fast
Latency target <200ms
Triggered by Every turn
Analysers active Language + Structure

InteractionOrchestrator triggers Tier 1 at the start of every chat turn — instant workspace awareness with minimal overhead.

Tier 2
On-Demand Targeted
Latency target <2s
Triggered by IMPLEMENT / FIX / REFACTOR
Analysers active All 9 (targeted scope)

Activated when IntelligenceFacade selects the TARGETED strategy — runs all 9 analysers but scoped to files relevant to the current operation.

Tier 3
Deep Investigation
Latency target <10s
Triggered by AUDIT / RCA / /totalrecall
Analysers active All 9 (full workspace)

Full workspace scan — history going back 90 days, all 60 governance YAMLs, dependency CVE sweep. Used for certification runs.

The AnalysisContext

All 9 analyser outputs are merged into a single AnalysisContext dataclass. This is the only data structure passed from LENS to orchestrators — a clean, typed, immutable snapshot of workspace state.

How LENS is Triggered

InteractionOrchestrator is Stage 1 Comprehension — it runs on every Copilot Chat turn, triggering Tier 1 LENS before any routing decision is made.

# cortex/orchestrators/core/interaction_orchestrator.py class InteractionOrchestrator(OrchestratorProtocolMixin): async def execute(self, turn: ChatTurn) -> AnalysisContext: AC_START("AC-INTERACT-001") # Step 1: Tier 1 LENS — always, every turn (<200ms) ctx = await IntelligenceFacade.analyse(tier=1) # Step 2: Inject prior 5 turns as session context chain ctx = inject_session_chain(ctx, n=5) # Step 3: Route to IntentRouter with enriched context intent = await IntentRouter.classify(turn, ctx) # Step 4: Upgrade LENS tier if intent complexity demands it if intent in DEEP_INTENTS: # AUDIT, RCA, totalrecall ctx = await IntelligenceFacade.analyse(tier=3) return await AC_COMPLETE("AC-INTERACT-001", ctx)
