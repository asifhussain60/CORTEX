Perception → Reasoning → Action

CORTEX is a three-tier intelligence system. Each tier has a clear responsibility and a measurable latency target.

Tier 1
Perception

LENS scans 9 dimensions simultaneously. Matches your codebase against canonical patterns with confidence scores 0–1.0.

# 9 parallel analyzers lens.scan("structural") lens.scan("security") lens.scan("history") # → AnalysisContext built
Tier 2
Reasoning

IntelligenceFacade selects Quick, Targeted, or Full strategy based on complexity and historical success rates.

IntelligenceFacade .select_strategy(ctx) # → QUICK | TARGETED | FULL .check_rca_history()
Tier 3
Action

MasterOrchestrator routes to intent-specialised orchestrators with convergence loops until zero P0/P1 violations.

AC_START("AC-IMPL-001") MasterOrchestrator .route(IMPLEMENT) AC_COMPLETE("✅ 842ms")

LENS — The Sensory System

02

Three Intelligence Tiers

Quick (<200ms), Targeted (<2s), Full (<10s). Each tier matches request complexity to analysis depth.

03

IntelligenceFacade

The single canonical entry point with 12+ methods and null-object fallbacks for graceful degradation.

04

Intent Classification

31 intent types classified in under 40ms. From IMPLEMENT to AUDIT to DEBUG — every request maps to a specialised handler.

05

Session Context Chain

Prior 5 requests injected into each LENS run. SHA-256 hashed, parent-linked, status-tracked in SQLite.

06

MCP Tool Registry

36 MCP tools registered via Pylance-style stdio server. Auto-discovered by VS Code Copilot Chat. Zero manual startup.

07

KAL — Knowledge Acquisition

On-demand knowledge synthesis. Coverage scoring triggers automatic gap identification and YAML knowledge generation.
