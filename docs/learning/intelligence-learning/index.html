Intelligence & Learning.

CORTEX doesn't just execute — it perceives, reasons, and remembers. You learn LENS workspace analysis, the RCA memory engine, URS reinforcement signals, KAL knowledge acquisition, CAPE complexity planning, and the IntelligenceFacade that unifies it all.

Intelligence Pipeline

Perceive → Reason → Act → Learn

Four stages of cognitive processing. LENS perceives, the facade reasons, orchestrators act, and URS/RCA learn from outcomes.

Perceive

LENS: 9 analysers scan workspace structure, dependencies, patterns

Reason

IntelligenceFacade: classify intent, assess complexity, plan approach

Act

Orchestrators execute workflows, modify code, run tests

Learn

URS rewards/punishments, RCA root cause analysis, pattern memory

Three Intelligence Tiers

Each tier adds deeper analysis. Tier 1 for every turn, Tier 2 on demand, Tier 3 for deep investigations.

Tier 1
Per-Turn

Fast context building — file inventory, dependency scan, intent classification. Runs automatically on every interaction.

Tier 2
On-Demand

Deep code analysis — pattern detection, complexity metrics, architecture graphs. Triggered by specific intents.

Tier 3
Deep Investigation

Full workspace synthesis — cross-module impact, regression prediction, root cause analysis. Heavy but comprehensive.

8 Intelligence Concepts

01 · Deep Dive →

LENS Sensory System

9 analysers build AnalysisContext: Language → Examination → Navigation → Synthesis. The workspace perception layer.
02

IntelligenceFacade

Single canonical entry point replacing 3 legacy facades (Phase 107). Coordinates LENS, domain brain, and knowledge synthesis.

03

URS — Reinforcement Signals

Closed-loop learning: MILD_REWARD on success, MILD_PUNISHMENT on failure. Signals emit, decay, promote, or quarantine.

04

RCA Memory Engine

4 root cause methodologies: Five-Whys, Fishbone (Ishikawa), Fault-Tree, Causal-Chain. Each analysis generates prevention rules.

05

KAL — Knowledge Acquisition

6-step pipeline: coverage assessor, gap analyser, source ranker, acquisition planner, integration validator, knowledge scorer.

06

CAPE — Complexity Planning

Complexity triage → auto plan → 5 execution gates → loop. Adapts planning depth to task complexity — simple tasks skip deep analysis.

07

PLIP — Prompt-Layer Protocol

Before every code-modifying operation: query history, check prevention rules, surface prior failure patterns. After: emit reward or punishment.

08

Deep Intelligence (Phase 144)

CCL query engine, capability verifier, facade extension — making intelligence queryable and self-aware.
