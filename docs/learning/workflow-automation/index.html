The Workflow Hierarchy

Three Tiers of Composition

Workflows compose from atomic primitives into mode-specific templates into multi-mode pipelines. Each tier is a YAML file — no procedural code.

Tier 1
Primitives

Atomic, reusable steps — gates, loops, markers, checkpoints. The building blocks that every workflow shares.

# ac-marker-emit.yaml type: primitive emit: AC_START | AC_COMPLETE
Tier 2
Mode Workflows

One per execution mode — IMPLEMENT, FIX, REFACTOR. Composes primitives into intent-specific sequences.

# implement-workflow.yaml type: mode_workflow pre_gate: holistic-validation steps: [tdd, implement, validate]
Tier 3
Composite Pipelines

Multi-mode compositions — audit-fix, totalrecall. Chain multiple mode workflows into complete operations.

# audit-fix-pipeline.yaml type: composite stages: [scan, classify, fix, rescan, certify]
