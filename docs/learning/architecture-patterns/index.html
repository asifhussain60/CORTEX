The Orchestrator Lifecycle

Every orchestrator, regardless of specialisation, follows these five steps. This consistency is what makes CORTEX auditable.

Step 1
Prepare

Load config. Establish connections.

Step 2
Govern

Run governance gate. Block if P0.

Step 3
Execute

Perform the specialised work.

Step 4
Validate

Verify against acceptance criteria.

Step 5
Close

Record audit trail. Emit signals.
