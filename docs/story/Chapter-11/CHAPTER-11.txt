THE DESIGN

Tier 3: The Knowledge Library.

Not project-specific. Not conversation-specific. Universal development wisdom accumulated across ALL work.

The structure would store patterns with pattern_id, context, projects_used, approach description, lessons_learned as a list, and test_strategy. For example, jwt_redis_refresh pattern would document token refresh with Redis session management, list which projects used it, describe the approach using Redis with TTL matching token expiry and storing refresh tokens separately, capture lessons like not storing full JWTs in Redis and setting Redis TTL 10% longer for clock skew, and document the test strategy.

It would also store architectural_decisions with trade-offs comparing REST (simple but slower), gRPC (fast but steeper learning curve), and message queues (async and resilient but adds complexity), along with guidance on when to use each.

And anti_patterns documenting bad practices discovered across projects, like storing passwords in config files, why they're bad (security vulnerabilities), which project exposed the issue, and the proper fix.

Cross-project wisdom. Anonymized. Searchable. Always available.

```python
# FORBIDDEN patterns
FORBIDDEN_DOC_LOCATIONS = [
    "/CORTEX/*.md",           # Root level
    "/CORTEX/Documents/*",    # Random dumps
    "/CORTEX/docs/*.md"       # Wrong docs folder
]

def _enforce_document_organization(self):
    """Find misplaced docs and relocate"""
    violations = []
    
    for pattern in FORBIDDEN_DOC_LOCATIONS:
        for file in self.find_files(pattern):
            # Analyze content to categorize
            category = self._determine_category(file)
            
            # Move to proper location
            new_path = f"cortex-brain/documents/{category}/{file.name}"
            self.relocate_file(file, new_path)
            violations.append(f"{file} → {new_path}")
    
    return violations
```

"How does it determine the category?"

"Filename patterns. 'plan-' → planning/. 'report-' → reports/. 'summary-' → summaries/. Plus content analysis—if it sees DoR/DoD, it's planning. If it sees test results, it's a report."
