🔄 7-Phase Workflow

Each phase builds on the previous, with conditional execution logic and health delta tracking to measure system improvements.

1 Pre-Healthcheck

Establish baseline system health across 7 components

  • Tier 0/1/2/3 health checks
  • Orchestrator/agent validation
  • System integrity scan
  • Baseline metrics storage

2 Align

Auto-fix system issues with tiered routing

  • Realignment utility integration
  • 10+ auto-fix strategies
  • Planning System alignment
  • Git checkpoint creation

3 Cleanup

Organize files and update references

  • File organization (cortex-brain/)
  • AST-powered reference updates
  • Backup before changes
  • Import fixing

4 Optimize

Improve performance and reduce tokens

  • Token optimization
  • Cache cleanup (stale data)
  • Prompt compression
  • Performance engine

5 Vacuum

SQLite optimization + AST cleanup

  • SQLite VACUUM (compaction)
  • AST-based code cleanup
  • Database optimization
  • Space reclamation

6 Refresh Prompts

Regenerate prompts to reflect system changes

  • Corpus collection
  • Template rendering
  • System context update
  • Prompt generation

7 Post-Healthcheck

Validate improvements and calculate delta

  • Final health scan
  • Delta calculation (baseline vs final)
  • Report generation (JSON + Markdown)
  • Success template rendering

📊 Complete Workflow Sequence

The 7-phase workflow with conditional execution logic. Phases 3-4 are skipped if Phase 2 (Align) fails, while Phases 5-7 always run to ensure system consistency.
