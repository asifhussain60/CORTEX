Overview

The System Integrity Orchestrator is a comprehensive admin-level tool that validates and automatically fixes CORTEX system integrity issues across 8 critical domains. Unlike traditional validation tools that only report issues, this orchestrator takes corrective action automatically.

Key Capabilities

✅ Master Plan Alignment
Validates that master plan checkboxes match actual implementation status. Auto-updates progress indicators when features are complete.
🧪 Test Execution & Coverage
Runs full test suite, identifies failing tests, and validates coverage thresholds. Generates coverage reports with actionable recommendations.
📚 Documentation Completeness
Detects missing documentation, generates stubs for undocumented modules, and validates docstring completeness across codebase.
📁 File Organization
Enforces CORTEX file structure standards, relocates misplaced files to correct directories, and maintains clean workspace organization.
🔗 Broken Link Detection & Repair
Scans all markdown files for broken internal references, updates paths after file moves, and validates external links.
🧹 Legacy Artifact Removal
Identifies and removes deprecated CORTEX 3.0 code, updates imports to 4.0 equivalents, and archives obsolete documentation.
📋 Manifest Validation
Validates YAML manifest structure, checks cross-references, ensures compliance with 3-tier manifest architecture.
🔄 Root Folder Cleanup
Prevents root-level document sprawl by relocating files to appropriate subdirectories within cortex-brain/.
