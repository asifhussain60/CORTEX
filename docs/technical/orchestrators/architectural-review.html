Overview

The Architectural Review Orchestrator performs comprehensive code and architecture analysis from a senior architect perspective. It examines structure, patterns, SOLID principles, API design, security, scalability, and maintainability with quantitative scoring and actionable recommendations.

Key Features

🎯 Context-Aware Analysis
Accepts scope filters and request context to focus review on specific features or keywords (e.g., 'auth', 'api', 'payment').
📊 Quantitative Scoring
0-100 scoring across 6 dimensions with weighted composite overall score. Clear thresholds for excellent (90+), good (70-89), fair (50-69), and poor (<50).
🔍 AST-Powered Analysis
Uses Abstract Syntax Tree analysis for precise code quality metrics, complexity calculation, and pattern detection.
🛡️ Git Protection Integration
Tracks alignment state across runs, detects regressions, and optionally blocks commits when critical issues are introduced.
📋 Actionable Recommendations
Generates priority-ranked recommendations with specific locations, root cause analysis, and suggested fixes.
📈 Compliance Analysis
Validates compliance with SOLID principles, design patterns, security best practices, and CORTEX coding standards.
