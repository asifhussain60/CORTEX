Overview

CORTEX Lens v3 is a universal repository analyzer that transforms raw code data into compelling narratives with interactive visualizations. It automatically detects repository type, extracts relevant metrics, and generates adaptive dashboards tailored to the project's technology stack and architecture patterns.

Core Capabilities

📊 Repository Classification
Automatically detects repository type (web app, API, ML pipeline, CLI tool, library) and technology stack through file analysis and pattern matching.
📖 Story Weaving
Transforms technical metrics into human-readable narratives that explain what the code does, how it's structured, and why architectural decisions were made.
🎨 Adaptive Templates
8+ specialized dashboard templates (React, Django, FastAPI, ML, microservices, etc.) with auto-selection based on repository characteristics.
🔥 Hotspot Analysis
Identifies code complexity hotspots, frequently changed files, and architectural bottlenecks using git history and AST analysis.
📈 Business Value Extraction
Connects technical metrics to business outcomes: feature velocity, technical debt impact, quality trends, deployment frequency.
🧠 Learning Integration
Stores discovered patterns in Tier 2 brain for future analysis, enabling continuous improvement of narrative quality and insight detection.

Technical Features

🔍 AST-Powered Analysis
Uses Abstract Syntax Tree parsing for accurate code complexity, pattern detection, and architectural analysis across multiple languages.
📊 Git History Mining
Analyzes commit history to identify code churn hotspots, contributor patterns, and feature velocity trends over time.
🎯 Dependency Analysis
Maps internal and external dependencies to detect tight coupling, circular dependencies, and vulnerable packages.
📈 Quality Metrics
Calculates cyclomatic complexity, maintainability index, test coverage, documentation coverage, and technical debt ratio.
🎨 D3.js Visualizations
Interactive charts: complexity heatmaps, dependency graphs, timeline views, sunburst diagrams, network graphs.
📦 Multi-Format Export
Exports data in HTML (interactive dashboard), JSON (programmatic access), YAML (config), and CSV (spreadsheet analysis).
