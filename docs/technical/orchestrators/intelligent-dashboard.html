Overview

The Intelligent Dashboard Orchestrator collects, enriches, and visualizes repository analytics across three sequential phases: Phase 7 (base metrics), Phase 8 (structure + risk), and Phase 9 (intelligence features). It generates template-ready JSON for Dashboard v3 with live metrics, security vulnerabilities, migration roadmaps, and actionable recommendations.

🔄 Sequential Pipeline
Phase 7 → Phase 8 → Phase 9 execution with data enrichment between phases. Each phase depends on outputs from previous phases for contextual analysis.
🔍 Universal Repository Analysis
Analyzes ANY repository (user or CORTEX) - detects languages, frameworks, dependencies, business capabilities, security vulnerabilities, and technical debt.
🛡️ Security & Risk Scoring
CVE detection, EOL risk scoring, dependency bloat analysis. Identifies vulnerable frameworks and generates upgrade paths to maintained versions.
📈 Intelligence Features
Migration roadmaps, framework health heatmaps, dependency bloat detection. Uses statistical analysis and AST parsing for deep insights.

Key Features

📂 Output Directory Management
Defaults to cortex-brain/dashboards/data/repos/{repo_name}/ with automatic directory creation. Custom output paths supported.
🔄 Data Dependency Resolution
Automatically passes enriched data between phases. Phase 8 uses Phase 7 tech_stack, Phase 9 uses Phase 8 risk-enriched data.
🛡️ Error Handling
Per-collector error handling with fallback to empty datasets. Logs detailed errors while continuing collection pipeline.
📊 Template-Ready Output
Generates JSON matching Dashboard v3 template requirements. Direct integration with Jinja2 templates for HTML rendering.
🔍 AST-Powered Analysis
Uses Abstract Syntax Tree parsing for deep code analysis: docstring extraction, semantic analysis, business capability detection.

Alert Triggers & Thresholds

🚨 High Severity CVEs
Alert when CVE count > 5 or CVSS score ≥ 7.0. Triggers security recommendation for immediate patching.
⏰ EOL Frameworks
Alert when framework is EOL or EOL date < 6 months. Triggers migration roadmap generation.
📊 Dependency Bloat
Alert when unused dependencies > 30% or total dependencies > 100. Triggers bloat analysis with removal recommendations.
🔥 Technical Debt
Alert when complexity score > 70 or test coverage < 50%. Triggers refactoring recommendations.
