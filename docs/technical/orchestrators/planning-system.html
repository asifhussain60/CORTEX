📋 Overview

The Planning System Orchestrator is CORTEX's flagship feature planning engine, providing intelligent tiered routing based on feature complexity. It automatically includes TDD phases, enforces DoR/DoD compliance, and supports hierarchical plan modularization for large implementations.

🧪 TDD Integration Workflow

All planning system plans automatically include TDD phases. The RED→GREEN→REFACTOR cycle is enforced with validation gates at each phase transition.

🔄 TDD Cycle Integration
sequenceDiagram participant User participant Planning participant TDD participant Git participant Validation User->>Planning: Request Feature Plan Planning->>Planning: Analyze Complexity Planning->>TDD: Auto-Include TDD Phases Note over TDD: RED Phase TDD->>TDD: Write Failing Tests TDD->>Validation: Validate Tests Fail Validation-->>TDD: ✓ Tests Failing TDD->>Git: Checkpoint (RED Complete) Note over TDD: GREEN Phase TDD->>TDD: Implement Feature TDD->>Validation: Validate Tests Pass Validation-->>TDD: ✓ Tests Passing TDD->>Git: Checkpoint (GREEN Complete) Note over TDD: REFACTOR Phase TDD->>TDD: Clean Code TDD->>Validation: Quality Score 0-10 Validation-->>TDD: ✓ Score ≥8 TDD->>Git: Checkpoint (REFACTOR Complete) TDD-->>Planning: TDD Complete Planning->>User: Plan with TDD Ready Note over User,Validation: Phase 10: Auto-Modularize if >20KB Planning->>Planning: Check Plan Size alt Plan > 20KB Planning->>Planning: Generate Index + Modules Planning->>User: Modularized Plan else Plan ≤ 20KB Planning->>User: Standard Plan end
