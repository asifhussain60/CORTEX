🛡️ Security Classification Levels

The analyzer categorizes domain-specific terms into four sensitivity levels to guide transformation priority:

CRITICAL Company names, product names, legal entities
HIGH Department names, proprietary technologies, internal systems
MEDIUM Project codes, team names, internal terminology
LOW Generic business terms, low-risk references

🔄 5-Phase Workflow

Each phase builds on the previous, with validation gates and rollback safety to ensure code integrity.

1 Analyze

File scanning and sensitivity analysis

  • 11+ language support (Python, JS, Java, etc.)
  • Domain term extraction
  • Namespace analysis
  • Sensitivity classification (CRITICAL→LOW)

2 Mapping

Generate domain→generic transformations

  • Conflict detection (multiple→same)
  • User approval workflow
  • Custom mapping support (JSON)
  • Reversible transformations

3 Transform

AST-powered code transformation

  • Backup creation (timestamp)
  • AST transformation (preserves syntax)
  • File renaming (paths + imports)
  • Special file handling (configs, README)

4 Validate

Build and test validation

  • Build system detection (pytest, npm, mvn)
  • Build execution + test suite
  • Import validation
  • Auto-rollback on failure

5 Report

Audit trail and metrics

  • Markdown audit report
  • Mapping reference (JSON)
  • Transformation metrics
  • Packaged output artifacts

💡 Usage Examples

CLI Usage

# Standard sanitization
python scripts/cli_wrappers/sanitize_wrapper.py /path/to/project

# Dry-run mode (preview only)
python scripts/cli_wrappers/sanitize_wrapper.py MyProject --dry-run

# Custom output directory
python scripts/cli_wrappers/sanitize_wrapper.py MyProject --output ~/sanitized

# Custom mappings
python scripts/cli_wrappers/sanitize_wrapper.py MyProject --mapping-file mappings.json

Python API

from src.orchestrators.sanitization import SanitizationOrchestrator

# Initialize orchestrator
orchestrator = SanitizationOrchestrator(
    target_directory="/path/to/project",
    dry_run=False  # Set True for preview
)

# Execute sanitization
result = orchestrator.execute()

# Check results
if result.success:
    print(f"✅ Files analyzed: {result.files_analyzed}")
    print(f"✅ Files transformed: {result.files_transformed}")
    print(f"✅ Report: {result.report_path}")
else:
    print(f"❌ Failed at {result.phase}")
