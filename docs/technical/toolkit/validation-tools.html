📄 Documentation Validator

HTML/Markdown Link Checker

Overview

Validates HTML documentation structure, checks for broken links, verifies glassmorphism CSS class usage, ensures WCAG 2.1 Level AA accessibility compliance, and validates Mermaid diagram syntax.

Validations

  • Link Integrity: Checks all internal/external links resolve (HTTP 200)
  • CSS Compliance: Ensures 100% centralized CSS (no inline styles except story button)
  • Accessibility: Validates ARIA labels, alt text, keyboard navigation
  • Structure: Verifies breadcrumb navigation, logo headers, consistent layout
  • Diagrams: Validates Mermaid syntax, checks D3.js integrations

Usage

# Validate all HTML docs
python -m cortex_toolkit.validators.doc_validator --directory docs/

# Check specific page
python -m cortex_toolkit.validators.doc_validator --file docs/index.html

# Accessibility audit
python -m cortex_toolkit.validators.doc_validator --accessibility-only

🧹 Code Sanitization Validator

Anonymization Sensitive Data

Overview

Verifies code sanitization completeness by checking for company-specific names, API keys, proprietary identifiers, and sensitive data leaks. Ensures sanitized code compiles and tests pass.

Detection Categories

  • Company Names: Detects hardcoded company/product names
  • API Keys: Scans for exposed credentials, tokens, secrets
  • Proprietary Identifiers: Finds internal system names, DB schemas
  • PII: Identifies emails, phone numbers, addresses
  • Compilation: Ensures sanitized code still runs

Usage

# Validate sanitization
python -m cortex_toolkit.validators.sanitization_validator \
    --directory src/sanitized/ \
    --mapping sanitization-map.json

# Output:
# ✅ 147 company names anonymized
# ✅ 23 API keys removed
# ✅ Code compiles
# ⚠️  2 potential leaks: ["InternalDB", "legacy-api-v2"]

📋 Manifest Validator

YAML Schema DoR/DoD

Overview

Validates orchestrator manifest YAML files against defined schemas. Ensures DoR (Definition of Ready) and DoD (Definition of Done) compliance, checks phase dependencies, and verifies TDD integration.

Validations

  • Schema Compliance: Validates against manifest-schema.yaml
  • DoR/DoD: Ensures all phases have entry/exit criteria
  • Phase Dependencies: Checks phase_order, dependencies, prerequisites
  • TDD Integration: Verifies RED-GREEN-REFACTOR checkpoints
  • Inheritance: Validates manifest composition (e.g., ADO inherits Planning)

Usage

# Validate manifest
python -m cortex_toolkit.validators.manifest_validator \
    --manifest cortex-brain/manifests/planning-system-manifest.yaml

# Validate all manifests
python -m cortex_toolkit.validators.manifest_validator --all
