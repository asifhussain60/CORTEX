🏗️ Architecture

📋 Overview

CORTEX uses a hierarchical 4-tier brain architecture for memory management and knowledge organization:

  • Tier 0 (Governance): Core rules, templates, and system-wide policies
  • Tier 1 (Working Memory): Active conversations, current context, session state
  • Tier 2 (Knowledge Graph): Relationships, patterns, learned insights
  • Tier 3 (Development Context): Project-specific knowledge, codebase understanding

🧠 4-Tier Brain

The brain structure provides persistent memory across conversations, enabling CORTEX to remember project context, user preferences, and development patterns over time.
