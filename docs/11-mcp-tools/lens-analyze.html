🔍 cortex_lens_analyze

Unified Code Intelligence Analysis

Overview

cortex_lens_analyze combines AST analysis, Git history, comment extraction, and security scanning into a single unified analysis for any file.

Function Signature


cortex_lens_analyze(
    file_path: str,
    repo_path: str = ".",
    include_git: bool = True,
    include_ast: bool = True,
    include_comments: bool = True,
    include_security: bool = True
) -> Dict[str, Any]

Parameters

Parameter Type Description
file_path string Path to file to analyze (absolute or relative)
repo_path string Git repository root (default: current directory)
include_git boolean Include git history analysis (24h commits, blame)
include_ast boolean Include AST structure analysis (functions, classes, imports)
include_comments boolean Include comment extraction (TODOs, FIXMEs, docstrings)
include_security boolean Include security threat analysis (6 CWE patterns)

Returns

Example Usage


# Full analysis (all analyzers)
result = cortex_lens_analyze(
    file_path="cortex/orchestrators/core/master_orchestrator.py"
)

# Security-focused analysis
result = cortex_lens_analyze(
    file_path="api/payment.py",
    include_git=False,
    include_ast=False,
    include_comments=False,
    include_security=True
)

# AST + Git only (skip comments and security)
result = cortex_lens_analyze(
    file_path="utils/helpers.py",
    include_comments=False,
    include_security=False
)

Integration with Challenge Engine

If security threats are detected with CRITICAL severity, ChallengeEngine is automatically triggered:


# LENS detects SQL injection
result = cortex_lens_analyze("api/users.py")

# ChallengeEngine blocks execution
if result['security_analysis']['threats']:
    # User must acknowledge and override
    override_result = cortex_challenge(
        threat_id=result['security_analysis']['threats'][0]['id'],
        action="OVERRIDE"
    )
