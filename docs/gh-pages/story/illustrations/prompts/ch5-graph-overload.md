## Technical Link

**DALL-E Narrative:** `07-knowledge-graph.md` (8,429 nodes, 3 edge types = 80/20 rule)

**Story Context:** Mr. Codenstein's knowledge graph starts with seventeen different relationship types and complex epistemological classifications. Miss G helps him realize that three simple edge types ("references", "influences", "conflicts-with") capture 80% of the value with 20% of the complexity.

**Teaches:** The 80/20 rule in action, avoiding overengineering, and the power of simplicity in graph structures. Real-world lesson: Start simple, add complexity only when proven necessary.
