⚙️ Implementation Details

Core Classes

ArchitecturalReviewOrchestrator

class ArchitecturalReviewOrchestrator: """ Main orchestrator for architectural review. Coordinates 6 analysis phases and scoring. """ def __init__(self, config: Dict[str, Any]): self.config = config self.analyzers = self._initialize_analyzers() self.scoring_engine = ScoringEngine(config) def execute(self, target_path: str, dry_run: bool = False) -> ArchitectureReport: """ Execute complete architectural review. Args: target_path: Path to analyze dry_run: If True, skip file modifications Returns: ArchitectureReport with scores and findings """ findings = {} # Phase 1: Layer Analysis findings['layer'] = self.analyzers['layer'].analyze(target_path) # Phase 2: Pattern Detection findings['pattern'] = self.analyzers['pattern'].detect(target_path) # Phase 3: Dependency Analysis findings['dependency'] = self.analyzers['dependency'].analyze(target_path) # Phase 4: SOLID Analysis findings['solid'] = self.analyzers['solid'].validate(target_path) # Phase 5: Testability Analysis findings['testability'] = self.analyzers['testability'].analyze(target_path) # Phase 6: Scoring metrics = self.scoring_engine.calculate(findings) return ArchitectureReport(findings, metrics)

LayerAnalyzer

class LayerAnalyzer: """ Analyzes layer separation and detects violations. """ LAYER_HIERARCHY = { 'api': 0, 'business': 1, 'data': 2, 'utils': 3 } def analyze(self, target_path: str) -> LayerAnalysisResult: """ Detect layer violations based on import analysis. Returns: LayerAnalysisResult with violations and score """ violations = [] for file_path in self._discover_files(target_path): layer = self._detect_layer(file_path) imports = self._parse_imports(file_path) for imp in imports: target_layer = self._detect_layer(imp) # Check if dependency violates hierarchy if self._is_violation(layer, target_layer): violations.append(LayerViolation( source=file_path, target=imp, source_layer=layer, target_layer=target_layer, severity=self._calculate_severity(layer, target_layer) )) score = self._calculate_score(violations) return LayerAnalysisResult(violations, score)

ScoringEngine

class ScoringEngine: """ Calculates architecture scores and assigns grades. """ WEIGHTS = { 'layer_separation': 0.25, 'patterns': 0.20, 'dependencies': 0.20, 'solid': 0.20, 'testability': 0.15 } def calculate(self, findings: Dict[str, Any]) -> ArchitectureMetrics: """ Calculate weighted total score from all findings. Returns: ArchitectureMetrics with scores and grade """ scores = { 'layer_separation': self._score_layers(findings['layer']), 'patterns': self._score_patterns(findings['pattern']), 'dependencies': self._score_dependencies(findings['dependency']), 'solid': self._score_solid(findings['solid']), 'testability': self._score_testability(findings['testability']) } # Calculate weighted total total_score = sum( scores[category] * self.WEIGHTS[category] for category in scores ) # Assign letter grade grade = self._assign_grade(total_score) return ArchitectureMetrics( scores=scores, total_score=total_score, grade=grade, findings=findings ) def _assign_grade(self, score: float) -> str: """Assign A-F grade based on score.""" if score >= 90: return 'A' if score >= 80: return 'B' if score >= 70: return 'C' if score >= 60: return 'D' return 'F'
⚠️ Implementation Note: All analyzers use Python's ast module for static code analysis. This ensures accurate parsing without executing code.

📚 API Reference

Main Orchestrator API

execute(target_path: str, dry_run: bool = False) → ArchitectureReport

Execute complete architectural review on specified path.

  • target_path: Path to analyze (absolute or relative)
  • dry_run: If True, skip file modifications (default: False)

Returns: ArchitectureReport object containing findings and metrics

analyze_layer_separation(target_path: str) → LayerAnalysisResult

Perform only layer separation analysis.

detect_patterns(target_path: str) → PatternDetectionResult

Detect design patterns and anti-patterns.

analyze_dependencies(target_path: str) → DependencyAnalysisResult

Build dependency graph and detect circular dependencies.

⚡ Performance Considerations

Optimization Strategies

  • Caching: AST parsing results cached per file to avoid re-parsing
  • Parallel Analysis: Analyzers run concurrently using asyncio
  • Incremental Analysis: Only analyze changed files in incremental mode
  • Memory Management: Process large codebases in batches to avoid memory issues

🤝 Contributing

Adding New Analyzers

To add a new analysis phase:

  1. Create Analyzer Class
    # src/orchestrators/analyzers/my_analyzer.py class MyAnalyzer: def __init__(self, config: Dict[str, Any]): self.config = config def analyze(self, target_path: str) -> MyAnalysisResult: """Perform custom analysis.""" # Implementation here pass
  2. Register Analyzer
    # In ArchitecturalReviewOrchestrator.__init__ self.analyzers = { 'layer': LayerAnalyzer(config), 'pattern': PatternDetector(config), 'my_analyzer': MyAnalyzer(config), # Add here }
  3. Update Scoring
    # In ScoringEngine WEIGHTS = { 'layer_separation': 0.25, 'patterns': 0.20, 'dependencies': 0.20, 'solid': 0.15, 'testability': 0.15, 'my_analyzer': 0.05 # Add weight }
  4. Add Tests
    # tests/orchestrators/test_my_analyzer.py def test_my_analyzer(): analyzer = MyAnalyzer({}) result = analyzer.analyze('tests/fixtures/sample_code') assert result.score >= 0 assert result.score <= 100

Testing Guidelines

  • All analyzers must have unit tests with >90% coverage
  • Integration tests required for orchestrator-level functionality
  • Use fixtures in tests/fixtures/ for sample codebases
  • Performance tests for large codebase scenarios

Code Style

  • Follow PEP 8 for Python code
  • Use type hints for all public methods
  • Document all classes and methods with docstrings
  • Run black, isort, and mypy before committing

Pull Request Checklist

  • ✅ Type checking passes (mypy)
