    A design system is a collection of reusable components, guided by clear standards, that can be assembled to build applications.

    Core Components:

    • Design Tokens: Color, typography, spacing, shadows as variables
    • Typography Scale: Modular scale (1.25 or 1.333 ratio)
    • Color System: Primary, secondary, semantic colors with shades
    • Spacing System: 8px grid with consistent multipliers
    • Component Library: Buttons, cards, forms, modals, tables

    Popular Design Systems:

    • Google Material Design 3
    • Apple Human Interface Guidelines
    • IBM Carbon Design System
    • Atlassian Design System
    View Full Details →

    Accessibility ensures digital products are usable by people with disabilities, including visual, auditory, motor, and cognitive impairments.

    WCAG 2.1 Success Criteria:

    • 1.1 Text Alternatives: Alt text for images
    • 1.4 Distinguishable: Color contrast, resize text
    • 2.1 Keyboard Accessible: All functions via keyboard
    • 2.4 Navigable: Skip links, focus order, page titles
    • 3.1 Readable: Language declaration, abbreviations
    • 4.1 Compatible: Valid HTML, ARIA usage

    ARIA Landmark Roles:

    • HIGH banner, navigation, main, contentinfo
    • MED complementary, search, form
    • MED region (with aria-label)
    View Full Details →

    Jakob Nielsen's 10 usability heuristics are general principles for interaction design that help create user-friendly interfaces.

    Nielsen's 10 Heuristics:

    • 1. Visibility of System Status: Keep users informed
    • 2. Match Real World: Use familiar language
    • 3. User Control: Undo, redo, cancel
    • 4. Consistency: Follow platform conventions
    • 5. Error Prevention: Prevent errors before they occur
    • 6. Recognition > Recall: Show options, minimize memory
    • 7. Flexibility: Shortcuts for experts
    • 8. Aesthetic Design: Remove irrelevant information
    • 9. Help with Errors: Clear error messages
    • 10. Documentation: Searchable help when needed
    View Full Details →

    Interaction design focuses on how users interact with products, including microinteractions, feedback patterns, and meaningful animations.

    Key Patterns:

    • Microinteractions: Small animations that delight (button press, toggle)
    • Loading States: Skeleton screens, progress indicators
    • Feedback: Success/error states, confirmations
    • Transitions: Page transitions, modal animations
    • Affordances: Visual cues for interactivity

    Animation Principles:

    • HIGH Duration: 200-300ms for UI feedback
    • MED Easing: ease-out for entrances, ease-in for exits
    • MED Respect prefers-reduced-motion
