Overview

TypeScript adds static type checking to JavaScript, catching errors at compile time and improving code maintainability and developer experience.

TypeScript Benefits:
  • Type Safety: Catch errors before runtime
  • IntelliSense: Enhanced IDE autocomplete and documentation
  • Refactoring: Safer code changes with compiler checking
  • Self-Documentation: Types serve as inline documentation
  • Tooling: Better support for large codebases

Type System Fundamentals

Avoid `any` Type

HIGH

Using `any` defeats the purpose of TypeScript. Use `unknown` for truly unknown types and narrow with type guards.

✅ Good - Use unknown with Type Guards

// Use unknown for truly unknown data
function processApiResponse(response: unknown) {
  if (typeof response === 'object' && response !== null) {
    if ('data' in response && 'status' in response) {
      const typed = response as { data: unknown; status: number };
      if (typed.status === 200) {
        return typed.data;
      }
    }
  }
  throw new Error('Invalid response');
}

// Or use type predicate
function isUser(obj: unknown): obj is User {
  return (
    typeof obj === 'object' &&
    obj !== null &&
    'id' in obj &&
    'name' in obj
  );
}

❌ Bad - Using any

// Loses all type safety
function processData(data: any) {
  // No type checking - can cause runtime errors
  return data.value.toUpperCase();
  // What if data.value doesn't exist?
  // What if it's not a string?
}

Use Strict TypeScript Configuration

HIGH

Enable strict mode in tsconfig.json for maximum type safety.

✅ Good - Strict Configuration

  }
}

Interfaces and Type Aliases

Prefer Interfaces for Object Shapes

MEDIUM

Use interfaces for object types - they're extendable and provide better error messages. Use type aliases for unions, intersections, and primitives.

✅ Good - Interface Usage

// Interfaces for object shapes
interface User {
  id: string;
  name: string;
  email: string;
  createdAt: Date;
}

// Extendable
interface AdminUser extends User {
  permissions: Permission[];
  role: 'admin' | 'superadmin';
}

// Type aliases for unions and complex types
type Status = 'pending' | 'active' | 'suspended';
type Result = { success: true; data: T } | { success: false; error: string };

// Use intersection for composition
type AuthenticatedUser = User & {
  token: string;
  expiresAt: Date;
};

❌ Bad - Type Alias for Objects

// Type alias harder to extend
type User = {
  id: string;
  name: string;
};

// Must use intersection, not extends
type AdminUser = User & {
  role: string;
};

Use Discriminated Unions

HIGH

Use discriminated unions with a common literal property for type-safe state management and exhaustive checking.

Generics

Use Generics for Reusable Components

MEDIUM

Generics allow you to write flexible, type-safe, reusable code without sacrificing type checking.

✅ Good - Generic Components

// Generic async data hook
interface AsyncData {
  data: T | null;
  loading: boolean;
  error: Error | null;
}

function useAsync(
  asyncFunction: () => Promise
): AsyncData {
  const [state, setState] = useState>({
    data: null,
    loading: false,
    error: null
  });

  useEffect(() => {
    setState(prev => ({ ...prev, loading: true }));
    asyncFunction()
      .then(data => setState({ data, loading: false, error: null }))
      .catch(error => setState({ data: null, loading: false, error }));
  }, []);

  return state;
}

// Type-safe usage
const { data, loading, error } = useAsync(fetchUsers);
// data is typed as User[] | null

Constrain Generics with Extends

MEDIUM

Use generic constraints to ensure type parameters meet minimum requirements.

✅ Good - Generic Constraints

// Constrain to objects with 'id' property
interface Identifiable {
  id: string;
}

function findById(
  items: T[],
  id: string
): T | undefined {
  return items.find(item => item.id === id);
}

// Usage with any type that has 'id'
const user = findById(users, '123');  // T = User
const post = findById(posts, '456');  // T = Post

// Constrain to array element type
function getFirst(arr: T[]): T | undefined {
  return arr[0];
}

Type React Hooks Properly

HIGH

Explicitly type useState, useRef, and custom hooks for type safety.

✅ Good - Typed Hooks

// useState with explicit type
const [user, setUser] = useState(null);
const [count, setCount] = useState(0);

// useRef with DOM element
const inputRef = useRef(null);

// useRef with mutable value
const timerRef = useRef(null);

// Custom hook with return type
function useLocalStorage(
  key: string,
  initialValue: T
): [T, (value: T) => void] {
  const [storedValue, setStoredValue] = useState(() => {
    const item = window.localStorage.getItem(key);
    return item ? JSON.parse(item) : initialValue;
  });

  const setValue = (value: T) => {
    setStoredValue(value);
    window.localStorage.setItem(key, JSON.stringify(value));
  };

  return [storedValue, setValue];
}
