Recommended knowledge before starting this learning path:

  • Programming Fundamentals Proficiency in at least one programming language (Python, C#, JavaScript, Java)

📖 Quick Reference Glossary

TDD
Test-Driven Development - writing tests before implementation code
BDD
Behavior-Driven Development - tests written in natural language scenarios
AAA Pattern
Arrange-Act-Assert - structure for organizing test code
Mocking
Creating fake objects to isolate code under test from dependencies
Code Coverage
Percentage of code executed by automated tests
Test Double
Generic term for mocks, stubs, fakes, and spies
Integration Test
Tests verifying multiple components working together
E2E Test
End-to-End tests simulating real user workflows
Test Fixture
Fixed state used as baseline for running tests
Assertion
Statement verifying expected outcome matches actual result
Regression Test
Tests ensuring new changes don't break existing functionality
Test Runner
Tool that executes tests and reports results (pytest, Jest, xUnit)
