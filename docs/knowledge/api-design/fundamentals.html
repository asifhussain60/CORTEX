📊 HTTP Status Code Quick Reference

2xx Success

200 OK - Request succeeded
201 Created - Resource created
204 No Content - Success, no body

3xx Redirection

301 Moved Permanently - Permanent redirect
302 Found - Temporary redirect
304 Not Modified - Cached version valid

4xx Client Error

400 Bad Request - Invalid syntax
401 Unauthorized - Authentication required
403 Forbidden - No permission
404 Not Found - Resource doesn't exist

5xx Server Error

500 Internal Server Error - Server crashed
502 Bad Gateway - Invalid upstream response
503 Service Unavailable - Server overloaded

🏆 Progressive Challenge: E-Commerce API Design

Design a RESTful API for an e-commerce platform. Apply what you've learned!

📋 Requirements

Design endpoints for products, orders, and users
Use appropriate HTTP methods for each operation
Return correct status codes for success/error scenarios
Follow REST URI naming conventions
Include request/response examples
💡 Hint 1: Resource Naming

Use plural nouns: /products, /orders, /users

💡 Hint 2: HTTP Methods

GET = Read, POST = Create, PUT = Full Update, PATCH = Partial Update, DELETE = Remove

💡 Hint 3: Status Codes

201 for creation, 200 for success, 404 for not found, 400 for bad input

✨ Model Solution

// Product Endpoints
GET    /api/v1/products          → 200 OK (list all products)
GET    /api/v1/products/{id}     → 200 OK | 404 Not Found
POST   /api/v1/products          → 201 Created | 400 Bad Request
PUT    /api/v1/products/{id}     → 200 OK | 404 Not Found
PATCH  /api/v1/products/{id}     → 200 OK | 404 Not Found
DELETE /api/v1/products/{id}     → 204 No Content | 404 Not Found

// Order Endpoints
GET    /api/v1/orders            → 200 OK
GET    /api/v1/orders/{id}       → 200 OK | 404 Not Found
POST   /api/v1/orders            → 201 Created | 400 Bad Request
PATCH  /api/v1/orders/{id}/status → 200 OK | 404 Not Found

// User Endpoints
GET    /api/v1/users             → 200 OK (admin only)
GET    /api/v1/users/me          → 200 OK (current user)
POST   /api/v1/users             → 201 Created | 400 Bad Request
PUT    /api/v1/users/{id}        → 200 OK | 403 Forbidden | 404 Not Found
