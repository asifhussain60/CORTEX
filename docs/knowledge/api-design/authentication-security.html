🔑 JWT (JSON Web Token) Security

🚨 JWT Security Best Practices

Use HTTPS: Always transmit tokens over encrypted connections
Short Expiry: Access tokens should expire in 15-60 minutes
Refresh Tokens: Use secure rotation for long-lived sessions
Validate Signature: Always verify JWT signature on server
Store Securely: Use httpOnly cookies, never localStorage

🏆 Security Challenge

Design a complete authentication system with JWT + Refresh tokens that handles:

Login with JWT access token (15 min expiry)
Refresh token rotation (7 day expiry)
Logout and token revocation
Rate limiting (100 requests/hour)
# Complete JWT + Refresh Token System

POST /api/auth/login
Request: {email, password}
Response: {
  "access_token": "eyJhbGc...",
  "refresh_token": "xyz...",
  "expires_in": 900
}

POST /api/auth/refresh
Request: {refresh_token}
Response: {
  "access_token": "new_token...",
  "refresh_token": "new_refresh..."
}

POST /api/auth/logout
Request: {refresh_token}
Response: {"message": "Logged out successfully"}

Rate Limiting Headers:
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 75
X-RateLimit-Reset: 1640995200
