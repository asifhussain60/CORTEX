Core OO Principles

Two fundamental principles that underpin all Gang of Four patterns

Program to an Interface

Program to an interface, not an implementation. Clients remain unaware of specific object types as long as they adhere to the expected interface. This enables loose coupling and the Open/Closed Principle.

Favor Composition

Favor object composition over class inheritance. Composition (black-box reuse) creates more flexible designs than inheritance (white-box reuse). This supports the Single Responsibility Principle.
