📚 Interactive Learning Modules

Module 1 Beginner
🎯 Messaging Fundamentals

Understand queues, topics, exchanges, and pub/sub patterns. Learn RabbitMQ AMQP protocol and message delivery guarantees (at-least-once, exactly-once).

⏱️ 35 minutes Start →
Module 2 Intermediate
🌊 Apache Kafka & Streaming

Master Kafka producers, consumers, partitions, and consumer groups. Build real-time stream processing with Kafka Streams and ksqlDB.

⏱️ 40 minutes Start →
Module 3 Advanced
⚡ Event Sourcing

Implement event stores, projections, and temporal queries. Learn how to rebuild state from events and handle schema evolution.

⏱️ 40 minutes Start →
Module 4 Expert
🔄 CQRS (Command Query Separation)

Separate read and write models for optimal performance. Build command handlers, read models, and projections for scalable systems.

⏱️ 35 minutes Start →
