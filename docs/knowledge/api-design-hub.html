📖 Quick Reference Glossary

REST
Representational State Transfer - architectural style using HTTP and stateless operations
GraphQL
Query language for APIs allowing clients to request specific data structures
Idempotent
Operation that produces the same result regardless of how many times it's executed
HATEOAS
Hypermedia As The Engine Of Application State - REST constraint for discoverability
OAuth 2.0
Industry-standard protocol for authorization and delegated access
JWT
JSON Web Token - compact token format for transmitting claims between parties
Rate Limiting
Controlling the number of requests a client can make to prevent abuse
Pagination
Dividing large result sets into smaller chunks (pages) for efficiency
Content Negotiation
Mechanism for serving different representations (JSON, XML) based on client preferences
API Gateway
Entry point managing authentication, routing, and rate limiting for microservices
Semantic Versioning
Versioning scheme using MAJOR.MINOR.PATCH to communicate changes
OpenAPI
Specification for describing RESTful APIs (formerly Swagger)
