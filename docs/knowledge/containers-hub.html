📚 Interactive Learning Modules

Module 1 Beginner
🐳 Docker Fundamentals

Master Docker images, containers, Dockerfile best practices, multi-stage builds, and Docker Compose for local development environments.

⏱️ 40 minutes Start →
Module 2 Intermediate
☸️ Kubernetes Core Concepts

Learn Pods, Deployments, Services, ConfigMaps, and Secrets. Master kubectl commands, declarative config, and Kubernetes networking.

⏱️ 40 minutes Start →

📋 Prerequisites & Recommendations

✅ Recommended Background

  • Linux command line basics
  • Understanding of networking (TCP/IP)
  • Basic cloud platform knowledge
  • No container experience required

🛠️ Tools You'll Use

  • Docker Desktop / Podman
  • Kubernetes (kubectl, minikube)
  • Helm 3
  • Istio service mesh

🎯 What You'll Build

  • Multi-container app (Docker Compose)
  • Kubernetes deployment manifests
  • Production Helm chart
  • Service mesh traffic routing
