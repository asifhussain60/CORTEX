🔐 Application Security

Authentication, Authorization, and Secure Coding Practices

🛡️ Security 🔒 OWASP 📅 Updated: Dec 2025

📋 Overview

Application security protects software from threats throughout its lifecycle. From authentication and authorization to encryption and secure coding, understanding security principles is essential for building trustworthy systems that protect user data and resist attacks.

Security Pillars:
  • Confidentiality: Keep data private and encrypted
  • Integrity: Prevent unauthorized modification
  • Availability: Ensure system remains accessible
  • Authentication: Verify user identity
  • Authorization: Control access to resources

🔑 Authentication

Authentication Methods

🎫

JWT (JSON Web Tokens)

Characteristics

  • Self-contained tokens
  • Header + Payload + Signature
  • Stateless authentication
  • Base64 encoded

Use Cases

  • API authentication
  • Single Sign-On (SSO)
  • Microservices
🔐

OAuth 2.0

Grant Types

  • Authorization Code: Server-side apps
  • Implicit: Legacy browser apps
  • Client Credentials: Machine-to-machine
  • Password: Trusted apps only
🎭

Multi-Factor Auth (MFA)

Factors

  • Something you know: Password
  • Something you have: Token, phone
  • Something you are: Biometric

🎯 Authorization

👥

RBAC (Role-Based)

Concept

  • Assign roles to users
  • Permissions tied to roles
  • Users → Roles → Permissions

Example Roles

  • Admin: Full access
  • Editor: Read + Write
  • Viewer: Read only
🏷️

ABAC (Attribute-Based)

Concept

  • Attributes define access
  • User, resource, environment
  • Dynamic policies

Example Attributes

  • Department
  • Time of day
  • Location
📝

Policy-Based

Concept

  • Explicit access rules
  • Centralized policies
  • Fine-grained control

Example Policies

  • IAM policies (AWS)
  • Open Policy Agent
  • XACML

⚠️ OWASP Top 10 (2021)

💉

1. Injection

Types

  • SQL injection
  • NoSQL injection
  • OS command injection
  • LDAP injection

Prevention

  • Parameterized queries
  • Input validation
  • ORM frameworks
🔓

2. Broken Authentication

Issues

  • Weak passwords
  • Session hijacking
  • Credential stuffing

Prevention

  • Multi-factor auth
  • Strong password policy
  • Session timeouts
🔍

3. Sensitive Data Exposure

Issues

  • Unencrypted data
  • Weak crypto
  • Insecure storage

Prevention

  • Encrypt in transit (TLS)
  • Encrypt at rest
  • Strong algorithms
🌐

4. XML External Entities

Prevention

  • Disable XML external entities
  • Use JSON instead
  • Update XML processors
🚫

5. Broken Access Control

Prevention

  • Deny by default
  • Validate ownership
  • Disable directory listing
⚙️

6. Security Misconfiguration

Prevention

  • Remove defaults
  • Minimal installation
  • Regular updates
📜

7. Cross-Site Scripting (XSS)

Prevention

  • Escape output
  • Content Security Policy
  • Input validation
🔄

8. Insecure Deserialization

Prevention

  • Avoid native serialization
  • Integrity checks
  • Isolate deserialization
📦

9. Using Components with Vulnerabilities

Prevention

  • Regular updates
  • Dependency scanning
  • Remove unused dependencies
📊

10. Insufficient Logging

Prevention

  • Log security events
  • Monitor for anomalies
  • Incident response plan
  • Centralized logging

🔒 Encryption

🔐

Symmetric Encryption

Algorithms

  • AES-256: Standard for data at rest
  • ChaCha20: Fast, mobile-friendly

Use Cases

  • Database encryption
  • File encryption
  • Bulk data
🔑

Asymmetric Encryption

Algorithms

  • RSA-2048: Key exchange, signatures
  • ECC: Smaller keys, same security

Use Cases

  • TLS/SSL handshake
  • Digital signatures
  • Key distribution

💡 Secure Coding Practices

Security Checklist:
  • Input Validation: Whitelist validation, reject by default
  • Output Encoding: Context-aware encoding (HTML, JS, SQL)
  • Authentication: MFA, strong passwords, secure session management
  • Authorization: Principle of least privilege, deny by default
  • Cryptography: Use proven algorithms, never roll your own
  • Error Handling: Don't leak sensitive info in errors
  • Logging: Log security events, protect log files
  • Dependencies: Keep updated, scan for vulnerabilities
Common Mistakes:
  • Hardcoded Secrets: Use environment variables or vaults
  • Insecure Defaults: Change default credentials
  • Client-Side Security: Never trust client input
  • Security by Obscurity: Not a valid strategy
