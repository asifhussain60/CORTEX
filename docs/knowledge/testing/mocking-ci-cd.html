💡 Pipeline Best Practices

Fast Feedback: Run unit tests first (1-3 minutes)
Parallel Execution: Split E2E tests across multiple runners
Caching: Cache dependencies (npm_modules, .venv) for speed
Fail Fast: Stop pipeline on first critical failure
Retry Flaky Tests: Auto-retry E2E tests up to 2 times
Coverage Gates: Require 80%+ coverage to merge

🎭 Mock Strategies Comparison

Different test double patterns serve different purposes. Choose the right strategy for your testing scenario.

🎯 Mock

Verifies behavior by tracking method calls. Use for: Testing interactions.

mock.method.assert_called_once()

📝 Stub

Returns predefined data. Use for: Testing with controlled inputs.

stub.get_user() → {id: 1}

🕵️ Spy

Wraps real object, records calls. Use for: Partial mocking.

spy.on(obj, 'method')

🏗️ Fake

Working implementation (in-memory DB). Use for: Complex logic.

FakeDatabase()
