🔄 The RED-GREEN-REFACTOR Cycle

TDD follows a simple three-step cycle that ensures code correctness and design quality. 

stateDiagram-v2
    [*] --> RED: Write Failing Test
    RED --> GREEN: Write Minimum Code
    GREEN --> REFACTOR: Improve Design
    REFACTOR --> RED: Add New Feature
    REFACTOR --> [*]: Feature Complete
    
    note right of RED
        • Test fails (expected)
        • Defines behavior
        • Clarifies requirements
    end note
    
    note right of GREEN
        • Test passes
        • Minimal implementation
        • Proof of concept
    end note
    
    note right of REFACTOR
        • Clean up code
        • Remove duplication
        • Improve design
    end note

⚖️ TDD Benefits vs Common Pitfalls

✅ Key Benefits

  • Better design through test-first thinking
  • Living documentation of requirements
  • Higher confidence in changes
  • Early bug detection
  • Reduced debugging time
  • Regression safety net

⚠️ Common Pitfalls

  • Writing tests after code (not TDD!)
  • Testing implementation details
  • Over-mocking dependencies
  • Skipping refactor step
  • Writing overly complex tests
  • Not running tests frequently

🏆 TDD Challenge

Build a string reversal function using pure TDD. Requirements:

  • Write test first for empty string
  • Write test for single character
  • Write test for multiple characters
  • Handle edge cases (null, undefined)
  • Refactor after each passing test
# TDD Solution: String Reversal

# Test 1: Empty string
def test_reverse_empty_string():
    assert reverse("") == ""

# Implementation 1:
def reverse(s):
    return ""

# Test 2: Single character
def test_reverse_single_char():
    assert reverse("a") == "a"

# Implementation 2:
def reverse(s):
    if len(s) <= 1:
        return s
    return s

# Test 3: Multiple characters
def test_reverse_multiple_chars():
    assert reverse("abc") == "cba"

# Implementation 3:
def reverse(s):
    if len(s) <= 1:
        return s
    return s[::-1]

# Test 4: Edge cases
def test_reverse_none():
    assert reverse(None) == ""

# Final Implementation (Refactored):
def reverse(s):
    if not s:
        return ""
    return s[::-1]
