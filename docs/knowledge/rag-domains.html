🧠 RAG Domains

Retrieval Augmented Generation and Vector Search

🤖 AI/ML 🔍 Semantic Search 📅 Updated: Dec 2025

📋 Overview

Retrieval Augmented Generation (RAG) combines the power of large language models with external knowledge retrieval. By searching relevant documents and providing them as context, RAG systems deliver accurate, grounded responses while reducing hallucinations and enabling knowledge updates without retraining.

RAG Benefits:
  • Accuracy: Grounded responses from verified sources
  • Up-to-date: Access current information without retraining
  • Transparency: Cite sources for verification
  • Cost-effective: No need for continuous model fine-tuning
  • Domain-specific: Inject specialized knowledge

🔄 RAG Pipeline

Indexing Phase

📄

1. Document Loading

Sources

  • PDFs, Word docs
  • Markdown, HTML
  • APIs, databases
  • Web scraping

Tools

  • LangChain document loaders
  • PyPDF2, pdfplumber
  • Beautiful Soup
✂️

2. Text Chunking

Strategies

  • Fixed size: 512-1024 tokens
  • Semantic: By paragraphs/sections
  • Overlap: 20-50 token overlap
  • Recursive: Split by hierarchy

Considerations

  • Context window size
  • Semantic coherence
  • Metadata preservation
🧬

3. Embedding

Models

  • OpenAI: text-embedding-ada-002 (1536d)
  • Cohere: embed-english-v3.0
  • Open Source: sentence-transformers

Properties

  • Vector dimensions
  • Semantic similarity
  • Cosine/dot product distance

Query Phase

🔍

4. Query Processing

Steps

  • Embed user query
  • Optional query expansion
  • Metadata filtering
  • Hybrid search (keyword + semantic)
📊

5. Retrieval

Techniques

  • Top-k: Retrieve k most similar
  • MMR: Maximal Marginal Relevance (diversity)
  • Reranking: Cross-encoder scoring
  • Threshold: Minimum similarity score
💬

6. Generation

Steps

  • Build context from chunks
  • Construct prompt
  • LLM generates answer
  • Cite sources

RAG Query Flow

sequenceDiagram participant U as User participant E as Embedder participant V as Vector DB participant R as Reranker participant L as LLM U->>E: "What is CORTEX?" E->>E: Embed query → vector E->>V: Search similar vectors (top 20) V->>V: ANN search V->>R: Return 20 chunks R->>R: Rerank by relevance R->>L: Top 5 chunks + query L->>L: Generate answer with context L->>U: "CORTEX is an AI assistant with long-term memory..." Note over V: Fast approximate search Note over R: Precise reranking Note over L: Grounded generation

🗄️ Vector Databases

📌

Pinecone

Features

  • Managed cloud service
  • Fast ANN search
  • Metadata filtering
  • Automatic scaling

Best For

  • Production RAG systems
  • High-scale applications
🌊

Weaviate

Features

  • Open source
  • GraphQL API
  • Hybrid search (vector + keyword)
  • Multi-tenancy

Best For

  • Self-hosted deployments
  • Flexible schemas
🎨

Chroma

Features

  • Lightweight, embeddable
  • Python-first API
  • Easy integration
  • Local development

Best For

  • Prototyping
  • Small-scale apps

Additional Vector Stores

🔷

Qdrant

  • Rust-based, fast
  • Rich filtering
  • Cloud and self-hosted
🐘

pgvector

  • PostgreSQL extension
  • Leverage existing DB
  • SQL queries with vectors
🌲

FAISS

  • Facebook AI library
  • In-memory, ultra-fast
  • Not a full database

Models

Cohere Embeddings

Models

  • embed-english-v3.0: 1024d
  • embed-multilingual-v3.0: 100+ languages

Features

  • Compression options
  • Search/classification modes
🔓

Open Source

Models

  • sentence-transformers: all-MiniLM-L6-v2
  • BGE: BAAI embeddings
  • E5: Microsoft embeddings

Benefits

  • Self-hosted
  • No API costs
  • Privacy control
Embedding Best Practices:
  • Consistent Model: Use same model for indexing and querying
  • Domain Adaptation: Fine-tune for specialized domains
  • Dimensionality: Higher dimensions = better accuracy, more storage
  • Batch Processing: Embed documents in batches for efficiency

🚀 Advanced RAG Techniques

🔁

Hybrid Search

Approach

  • Combine vector + keyword search
  • BM25 for keyword matching
  • Weighted fusion of results

Benefits

  • Better recall
  • Handle exact matches
  • Complementary strengths
📈

Reranking

Approach

  • Retrieve larger candidate set (20-50)
  • Cross-encoder scoring
  • Return top k (3-5)

Models

  • Cohere Rerank
  • cross-encoder models
  • Custom scoring
🧩

Query Expansion

Techniques

  • Multi-query generation
  • HyDE (Hypothetical Document Embeddings)
  • Step-back prompting
🎯

Metadata Filtering

Filters

  • Document type
  • Date range
  • Author/source
  • Access permissions
🧠

Agentic RAG

Features

  • Multi-step reasoning
  • Query decomposition
  • Self-reflection
  • Tool use
📚

Contextual Compression

Approach

  • Extract relevant sentences
  • Reduce token usage
  • Improve context quality

📊 RAG Evaluation

Retrieval Metrics

Metrics

  • Precision: Relevant docs retrieved / Total retrieved
  • Recall: Relevant docs retrieved / Total relevant
  • MRR: Mean Reciprocal Rank
  • NDCG: Normalized Discounted Cumulative Gain
💬

Generation Metrics

Metrics

  • Faithfulness: Answer grounded in context
  • Relevance: Answers the question
  • Coherence: Fluent and logical
