Overview

Retrieval-Augmented Generation (RAG) combines the power of large language models with external knowledge retrieval. This architecture enables AI systems to access up-to-date, domain-specific information while maintaining the generative capabilities of LLMs, reducing hallucinations and providing citations for generated content.

    Hybrid Search

    🤖RAG HIGH

    Description: Combine vector (semantic) search with keyword (BM25) search for best results. Vector search finds conceptual matches; keyword search finds exact terms.

    Hybrid Search Benefits

    • Vector: "How do I authenticate?" finds "login implementation"
    • Keyword: "OAuth2" finds exact technical terms
    • Combined: Best of both worlds

    Implementation Example

    from rank_bm25 import BM25Okapi
import numpy as np

def hybrid_search(query: str, k: int = 10, alpha: float = 0.5):
    """
    Hybrid search combining vector and keyword search.
    alpha: weight for vector search (0=keyword only, 1=vector only)
    """
    # Vector search scores (normalized 0-1)
    vector_results = vector_db.similarity_search_with_score(
        query_embedding, k=k*2
    )
    vector_scores = {
        doc.id: score for doc, score in vector_results
    }
    
    # BM25 keyword search scores (normalized 0-1)
    tokenized_query = query.lower().split()
    bm25_scores_raw = bm25.get_scores(tokenized_query)
    bm25_scores = bm25_scores_raw / bm25_scores_raw.max()
    
    # Combine with weighted sum
    combined_scores = {}
    for doc_id in set(vector_scores.keys()) | set(range(len(bm25_scores))):
        v_score = vector_scores.get(doc_id, 0)
        k_score = bm25_scores[doc_id] if doc_id < len(bm25_scores) else 0
        combined_scores[doc_id] = alpha * v_score + (1 - alpha) * k_score
    
    # Return top-k by combined score
    top_k = sorted(combined_scores.items(), key=lambda x: -x[1])[:k]
    return [documents[doc_id] for doc_id, _ in top_k]

    Reranking for Quality

    HIGH

    Description: Use a cross-encoder reranker to improve retrieval quality. Initial retrieval is fast but approximate; reranking is slower but more accurate.

    Two-Stage Retrieval Pattern

    1. Stage 1: Fast vector search, retrieve top 50-100 candidates
    2. Stage 2: Cross-encoder rerank to select top 5-10
    from sentence_transformers import CrossEncoder

# Initialize reranker
reranker = CrossEncoder('cross-encoder/ms-marco-MiniLM-L-6-v2')

def retrieve_with_reranking(query: str, k: int = 5):
    # Stage 1: Fast vector search (top 50)
    candidates = vector_db.similarity_search(query, k=50)
    
    # Stage 2: Rerank with cross-encoder
    pairs = [(query, doc.page_content) for doc in candidates]
    scores = reranker.predict(pairs)
    
    # Sort by reranker score and return top-k
    ranked = sorted(zip(candidates, scores), key=lambda x: -x[1])
    return [doc for doc, score in ranked[:k]]

    Advanced Retrieval Patterns

    • HyDE (Hypothetical Document Embeddings): Generate hypothetical answer, embed that, search for similar real documents
    • Multi-Query: Generate multiple query variations, retrieve for each, deduplicate
    • Parent-Child Retrieval: Index small chunks, retrieve, but return parent document for context
    • Contextual Compression: Extract only relevant parts of retrieved documents

    Indexing Algorithms

    • HNSW (Hierarchical Navigable Small World): Best for most use cases, graph-based, fast queries
    • IVF (Inverted File Index): Good for very large datasets, cluster-based
    • Flat: Exact search, slow but 100% accurate, small datasets only

    Embedding Optimization

    • Batch Processing: Embed 32-128 texts per API call (5-10x faster)
    • Caching: Hash-based cache for repeated texts
    • Dimensionality Reduction: PCA or Matryoshka embeddings can reduce storage 50-75%
    • Quantization: int8 quantization reduces memory with minimal quality loss

    Batch Embedding Example

    import hashlib
from functools import lru_cache
from openai import OpenAI

client = OpenAI()

class EmbeddingService:
    def __init__(self, model="text-embedding-3-small"):
        self.model = model
        self.cache = {}
    
    def _hash_text(self, text: str) -> str:
        return hashlib.md5(text.encode()).hexdigest()
    
    def embed_batch(self, texts: list[str], batch_size: int = 100):
        """Embed texts in batches with caching."""
        results = [None] * len(texts)
        uncached = []
        uncached_indices = []
        
        # Check cache
        for i, text in enumerate(texts):
            cache_key = self._hash_text(text)
            if cache_key in self.cache:
                results[i] = self.cache[cache_key]
            else:
                uncached.append(text)
                uncached_indices.append(i)
        
        # Batch embed uncached texts
        for i in range(0, len(uncached), batch_size):
            batch = uncached[i:i + batch_size]
            response = client.embeddings.create(
                model=self.model,
                input=batch
            )
            
            for j, embedding in enumerate(response.data):
                idx = uncached_indices[i + j]
                vector = embedding.embedding
                results[idx] = vector
                
                # Cache result
                cache_key = self._hash_text(uncached[i + j])
                self.cache[cache_key] = vector
        
        return results

    Multi-Tenant Example

    def retrieve_for_tenant(
    query: str,
    tenant_id: str,
    k: int = 5,
    include_shared: bool = True
):
    """Retrieve documents respecting tenant isolation."""
    
    # Build filter for tenant-specific docs
    filters = {"tenant_id": tenant_id}
    
    if include_shared:
        # Include shared knowledge base
        filters = {
            "$or": [
                {"tenant_id": tenant_id},
                {"is_shared": True}
            ]
        }
    
    results = vector_db.similarity_search(
        query=query,
        k=k,
        filter=filters
    )
    
    return results
