High-Priority Rules

⚠️

Use Function Components with Hooks

HIGH

Description: Modern React uses function components with hooks instead of class components for better readability and reusability.

✅ Good

function Counter() {
  const [count, setCount] = useState(0);
  
  return (
    <button onClick={() => setCount(count + 1)}>
      Count: {count}
    </button>
  );
}

❌ Bad

class Counter extends React.Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
  }
  
  render() {
    return <button>...</button>;
  }
}

Single Responsibility Principle

HIGH

Description: Each component should have one clear responsibility and do it well.

Break down large components into smaller, focused ones for better maintainability and reusability.

🎯

Optimize Re-renders with React.memo

MEDIUM

Description: Use React.memo to prevent unnecessary re-renders of pure components.

This optimization should be applied to components that render frequently with the same props.

interface UserCardProps {
  userId: string;
  onUserClick?: (userId: string) => void;
}

export const UserCard = memo(function UserCard({ 
  userId, 
  onUserClick 
}: UserCardProps) {
  const [isLoading, setIsLoading] = useState(false);
  
  const handleClick = useCallback(() => {
    onUserClick?.(userId);
  }, [userId, onUserClick]);
  
  if (isLoading) return <Spinner />;
  
  return (
    <div className="user-card" onClick={handleClick}>
      {/* Component content */}
    </div>
  );
});
