📖 Quick Reference Glossary

Gang of Four (GoF)
Authors of the seminal design patterns book (Gamma, Helm, Johnson, Vlissides)
Singleton
Ensures a class has only one instance with global access point
Factory Method
Defines interface for creating objects, letting subclasses decide which class to instantiate
Observer
Defines one-to-many dependency where observers are notified of state changes
Strategy
Defines family of algorithms, encapsulates each, and makes them interchangeable
Decorator
Attaches additional responsibilities to object dynamically
Facade
Provides unified interface to set of interfaces in subsystem
Adapter
Converts interface of class into another interface clients expect
Command
Encapsulates request as object, allowing parameterization and queuing
Template Method
Defines skeleton of algorithm, letting subclasses override specific steps
Composition
Favor object composition over class inheritance for flexibility
Dependency Injection
Providing dependencies from outside rather than creating them internally
