📖 Quick Reference Glossary

XSS
Cross-Site Scripting - injecting malicious scripts into web pages
CSRF
Cross-Site Request Forgery - unauthorized actions on behalf of authenticated user
SQL Injection
Inserting malicious SQL code into database queries
STRIDE
Threat modeling framework: Spoofing, Tampering, Repudiation, Info Disclosure, DoS, Elevation
MFA
Multi-Factor Authentication - verifying identity with multiple factors
RBAC
Role-Based Access Control - permissions based on user roles
JWT
JSON Web Token - compact token for transmitting claims securely
Zero Trust
Security model assuming breach and verifying every request
SIEM
Security Information and Event Management - centralized log analysis
Penetration Testing
Authorized simulated attacks to identify vulnerabilities
Bug Bounty
Rewards for responsibly disclosing security vulnerabilities
CVE
Common Vulnerabilities and Exposures - database of known security flaws
