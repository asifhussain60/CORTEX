What are Embeddings?

Embeddings are vector representations of text that capture semantic meaning. They enable similarity search in RAG systems by converting documents and queries into comparable vectors.

💡 Key Insight: Similar concepts have similar vector representations, enabling semantic search beyond keyword matching.

Embedding Models Comparison

OpenAI text-embedding-ada-002 (Recommended)

PRODUCTION READY

Industry-standard embedding model for production RAG systems.

Specifications

  • Dimensions: 1536
  • Max Tokens: 8191 tokens per input
  • Cost: $0.10 per 1M tokens
  • Performance: Excellent for general-purpose RAG

✅ Python Implementation

from openai import OpenAI

client = OpenAI(api_key="your-api-key")

def get_embedding(text, model="text-embedding-ada-002"):
    """Generate embedding for text."""
    text = text.replace("\n", " ")  # Clean text
    
    response = client.embeddings.create(
        input=[text],
        model=model
    )
    
    return response.data[0].embedding  # List of 1536 floats

# Usage
document = "Machine learning is a subset of artificial intelligence."
embedding = get_embedding(document)
print(f"Embedding dimensions: {len(embedding)}")  # 1536

Sentence Transformers (Self-Hosted)

OPEN SOURCE

Free, self-hosted embeddings for privacy-sensitive applications.

Popular Models

  • all-MiniLM-L6-v2: 384 dimensions, fast, good for CPU
  • all-mpnet-base-v2: 768 dimensions, more accurate

✅ Python Implementation

from sentence_transformers import SentenceTransformer

# Load model (downloads automatically first time)

Optimization Strategies

Batch Processing

HIGH PRIORITY

Process multiple texts in batches for 5-10x speedup.

✅ Batch Processing

from openai import OpenAI
import numpy as np

client = OpenAI(api_key="your-api-key")

def get_embeddings_batch(texts, model="text-embedding-ada-002", batch_size=128):
    """Generate embeddings for multiple texts in batches."""
    embeddings = []
    
    for i in range(0, len(texts), batch_size):
        batch = texts[i:i + batch_size]
        
        response = client.embeddings.create(
            input=batch,
            model=model
        )
        
        batch_embeddings = [item.embedding for item in response.data]
        embeddings.extend(batch_embeddings)
    
    return np.array(embeddings)

# Usage
documents = ["doc1", "doc2", ..., "doc1000"]  # 1000 documents
embeddings = get_embeddings_batch(documents, batch_size=128)
# ~8 API calls instead of 1000!

Embedding Caching

HIGH PRIORITY

Cache embeddings to avoid recomputing identical texts.

✅ Redis Caching

import redis
import hashlib
import json
import numpy as np

redis_client = redis.Redis(host='localhost', port=6379, db=0)

def get_embedding_cached(text, model="text-embedding-ada-002"):
    """Get embedding with caching."""
    # Create cache key from text hash
    cache_key = f"embedding:{model}:{hashlib.md5(text.encode()).hexdigest()}"
    
    # Check cache
    cached = redis_client.get(cache_key)
    if cached:
        return json.loads(cached)
    
    # Generate embedding
    embedding = get_embedding(text, model)
    
    # Cache with 30-day TTL
    redis_client.setex(
        cache_key,
        60 * 60 * 24 * 30,  # 30 days
        json.dumps(embedding)
    )
    
    return embedding

# Usage
text = "Machine learning is amazing"
embedding1 = get_embedding_cached(text)  # API call
embedding2 = get_embedding_cached(text)  # Cache hit (instant!)

✅ Reduces API costs and latency for repeated queries.

Dimensionality Reduction

MEDIUM PRIORITY

Reduce storage and improve search speed with 50-75% fewer dimensions.

✅ PCA Dimensionality Reduction

from sklearn.decomposition import PCA
import numpy as np

# Original embeddings (N x 1536)
embeddings = np.array([...])  # Shape: (1000, 1536)

# Reduce to 512 dimensions (67% reduction)
pca = PCA(n_components=512)
reduced_embeddings = pca.fit_transform(embeddings)
print(f"Original shape: {embeddings.shape}")      # (1000, 1536)
print(f"Reduced shape: {reduced_embeddings.shape}")  # (1000, 512)

# Check variance retained
variance_retained = pca.explained_variance_ratio_.sum()
print(f"Variance retained: {variance_retained:.2%}")  # ~95%

✅ Benefits: 67% less storage, faster similarity search, minimal accuracy loss.

Evaluation & Testing

Retrieval Accuracy Testing

HIGH PRIORITY

Measure how well embeddings retrieve relevant documents.

✅ Recall@K Evaluation

from sklearn.metrics.pairwise import cosine_similarity
import numpy as np

def recall_at_k(query_embedding, document_embeddings, relevant_doc_ids, k=5):
    """Calculate Recall@K metric."""
    # Compute similarities
    similarities = cosine_similarity([query_embedding], document_embeddings)[0]
    
    # Get top K document indices
    top_k_indices = np.argsort(similarities)[::-1][:k]
    
    # Check how many relevant docs in top K
    retrieved_relevant = set(top_k_indices) & set(relevant_doc_ids)
    recall = len(retrieved_relevant) / len(relevant_doc_ids)
    
    return recall

# Test with query-document pairs
test_cases = [
    {
        "query": "How to train neural networks?",
        "relevant_docs": [5, 12, 23]  # IDs of relevant documents
    },
    # ... more test cases
]

recalls = []
for test in test_cases:
    query_emb = get_embedding(test["query"])
    recall = recall_at_k(query_emb, doc_embeddings, test["relevant_docs"], k=5)
    recalls.append(recall)

avg_recall = np.mean(recalls)
print(f"Average Recall@5: {avg_recall:.2%}")
