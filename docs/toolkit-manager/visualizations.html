🧩 CORTEX Visualizations

D3.js Charts & Interactive Diagrams

Overview

CORTEX Toolkit provides pre-built D3.js visualizations and glassmorphism components for generating interactive documentation, dashboards, and reports.

Available Visualizations

📊 Orchestrator Dependency Graph

Force-directed graph showing orchestrator relationships and wiring


import { createDependencyGraph } from 'visualizations/dependency-graph.js';

createDependencyGraph('#graph-container', {
    nodes: orchestrators,
    edges: dependencies
});

📈 Governance Compliance Chart

Bar chart showing CORE rule compliance across codebase


import { createComplianceChart } from 'visualizations/compliance.js';

createComplianceChart('#chart-container', {
    rules: coreRules,
    violations: violations
});

🔥 Duplication Heatmap

Heatmap showing code duplication across files and modules


import { createDuplicationHeatmap } from 'visualizations/heatmap.js';

createDuplicationHeatmap('#heatmap', {
    duplicates: duplicationData,
    threshold: 0.8
});

🎯 Phase Progress Timeline

Interactive timeline with phase milestones and completion status


import { createTimeline } from 'visualizations/timeline.js';

createTimeline('#timeline', {
    phases: epicPhases,
    current: currentPhase
});

Glassmorphism Components

Pre-styled glassmorphism components matching CORTEX design system:

  • Glass Cards: Translucent containers with backdrop blur
  • Modern Tabs: Tab navigation with smooth transitions
  • Progress Bars: Animated progress indicators
  • Tooltips: Context-aware hover tooltips
  • Modals: Dialog overlays with glassmorphism styling

Custom Visualization API


// Create custom D3.js visualization with glassmorphism styling
import { CortexVisualization } from 'toolkit/visualization-base.js';

const customViz = new CortexVisualization({
    container: '#my-viz',
    theme: 'glassmorphism',
    responsive: true,
    data: myData
});

customViz.render();
