What Is Toolkit Manager?

Toolkit Manager is CORTEX's Master Orchestrator Routing Layer that intelligently routes user requests to the appropriate specialized orchestrator. It uses a hybrid approach: fast pattern-based matching for exact intents, with LLM classification fallback for ambiguous requests.

Key Features

Hybrid Routing: Pattern matching (fast) + LLM classification (intelligent)
8 Orchestrators: Planning, TDD, ADO, Sanitization, Maintenance, Refinement, Vision, Diagnostics
Zero Ambiguity: LLM fallback resolves unclear intents
Autonomous Handoff: 🛡️ orchestrators execute independently
Manifest-Driven: Orchestrator definitions stored in YAML

Hybrid Routing Architecture

Toolkit Manager uses a 2-phase routing strategy: Pattern-Based Matching (90% of requests) and LLM Intent Classification (10% fallback for ambiguous cases).

Manifest-Driven Architecture

All orchestrator definitions are stored as YAML manifests in cortex-brain/manifests/orchestrators/. This enables version control, easy updates, and declarative orchestrator definitions.

Example: Planning Orchestrator Manifest 
name: planning-system
version: 4.0.0
type: AUTONOMOUS
trigger_patterns:
  - "plan"
  - "create a plan"
  - "make a plan"
  - "plan this"
hand_off_template: autonomous_execution_progress
phases:
  - requirements_analysis
  - architecture_design
  - implementation_plan
  - validation_strategy
output_structure:
  folders:
    - requirements/
    - architecture/
    - implementation/
    - validation/
