📋 Planning System Commands

Basic Planning

"plan: Add user authentication with JWT"

What CORTEX Does:

  • ✅ Validates Definition of Ready (DoR) - ensures requirements complete
  • ✅ Detects complexity (MEDIUM → incremental 5-phase plan)
  • ✅ Generates acceptance criteria (security, token refresh, error handling)
  • ✅ Proposes test strategy (unit, integration, E2E)
  • ✅ Creates TDD-integrated phases (RED-GREEN-REFACTOR per phase)

Alternative Phrasings:

"plan feature: JWT authentication"
"create plan for user auth"
"help me plan authentication system"

ADO-Formatted Planning

"plan ado: Implement payment gateway integration"

  • ✅ Includes DoR/DoD checklists
  • ✅ Proposes story points and acceptance criteria

Autonomous Execution

"execute all phases autonomously"

✅ TDD Mastery Commands

Start TDD Workflow

"start tdd: User registration service"

RED Phase (Tests First):

  • ✅ Generates test cases before implementation
  • ✅ Runs tests to ensure they FAIL (RED validation)
  • ✅ Validates 4-layer coverage (unit, integration, component, E2E)

GREEN Phase (Make Tests Pass):

  • ✅ Implements minimal code to pass tests
  • ✅ Validates all tests pass (GREEN validation)

REFACTOR Phase (Clean Up):

  • ✅ Removes duplication, improves structure
  • ✅ Ensures tests still pass after refactoring

Alternative Phrasings:

"begin tdd for registration"
"use tdd to build user service"
"apply red-green-refactor to registration"

Run Tests

"run tests"

What CORTEX Does:

  • ✅ Detects test framework (pytest, unittest, Jest, etc.)
  • ✅ Executes full test suite
  • ✅ Reports pass/fail counts
  • ✅ Shows coverage percentage
  • ✅ Identifies failing tests with context

Alternative Phrasings:

"run all tests"
"execute test suite"
"validate with tests"

🔒 Code Sanitization Commands

Basic Sanitization

"sanitize: src/proprietary"

5-Phase Workflow:

  1. Discover: AST analysis finds company names, API keys, business logic
  2. Map: Creates consistent replacement strategy (Acme → Company_A)
  3. Transform: Applies replacements across all files
  4. Validate: Ensures code still compiles/runs
  5. Report: Generates sanitization manifest

Alternative Phrasings:

"sanitize directory: src/proprietary"
"anonymize code in src/proprietary"
"make code generic: src/proprietary"

Full Project Sanitization

"sanitize: ."

What CORTEX Does:

  • ✅ Scans entire project recursively
  • ✅ Preserves .git history (optional)
  • ✅ Anonymizes docstrings, comments, variable names
  • ✅ Sanitizes configuration files
  • ✅ Generates reverse mapping (for internal reference)

Alternative Phrasings:

"sanitize entire project"
"anonymize all code"
"make project shareable"

💡 Tips & Tricks

Conversational Commands

CORTEX understands intent, not exact syntax:

  • "Can you help me plan a feature for..." ✅
  • "I need to sanitize some code in..." ✅
  • "Let's use TDD to build..." ✅
🔗

Context Continuity

CORTEX remembers your conversation:

  • "Plan: Add user auth" → "Execute phase 1" ✅
  • "What was the last test result?" ✅
  • "Continue with the next phase" ✅
📝

Descriptive Requests

More context = better results:

  • ❌ "plan: auth"
  • ✅ "plan: Add JWT-based authentication with refresh tokens and role-based access control"
🎯

Specific Paths

Use absolute or relative paths:

  • "sanitize: ./src/api" ✅
  • "sanitize: D:/Projects/MyApp/src" ✅
  • "start tdd: src/services/user_service.py" ✅
