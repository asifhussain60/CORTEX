🚀 Get Started with CORTEX

5-Minute Setup • MCP Configuration • Your First Request

Prerequisites

  • Python 3.11+ installed
  • VS Code with GitHub Copilot extension
  • Git repository for your project
  • Basic familiarity with command line

Step 1: Clone & Install


# Clone CORTEX repository
git clone https://github.com/asifhussain60/CORTEX.git
cd CORTEX

# Install dependencies
pip install -r requirements.txt

# Verify installation
python -m cortex.cli --version

Step 2: Configure MCP Server

Add CORTEX to your VS Code settings (.vscode/settings.json):


{
  "github.copilot.chat.mcpServers": {
    "cortex": {
      "command": "python",
      "args": ["-m", "cortex.mcp.server"],
      "env": {
        "CORTEX_ROOT": "${workspaceFolder}",
        "CORTEX_MODE": "production"
      }
    }
  }
}

Step 3: Start CORTEX


# Start MCP server
python -m cortex.mcp.server

# Server will start on http://localhost:8000
# Health check: http://localhost:8000/health

Step 4: Your First Request

In GitHub Copilot Chat, try:


@cortex analyze this file for security issues

@cortex /implement add user authentication with TDD

@cortex /refactor extract this function into a service class

Step 5: Verify MCP Tools


# List available MCP tools
curl http://localhost:8000/tools

# Expected output:
# - cortex_process_request
# - cortex_lens_analyze
# - cortex_git_history
# - cortex_challenge
# - cortex_detect_duplicates
# ... (15+ tools)

Troubleshooting

MCP Server Not Starting?


# Check Python version
python --version  # Should be 3.11+

# Check dependencies
pip list | grep cortex

# Check logs
tail -f cortex/logs/mcp-server.log

Tools Not Appearing in Copilot?

  • Restart VS Code after modifying settings.json
  • Verify MCP server is running: curl http://localhost:8000/health
  • Check VS Code Developer Console for errors
