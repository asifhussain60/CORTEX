VS Code: The Preferred CORTEX Experience

While CORTEX 4.0 now supports both Visual Studio Code and Visual Studio IDE, we strongly recommend VS Code for the best experience. Here's why:

Better Performance

Faster extension load times, GitHub Copilot Chat integration optimized for VS Code's architecture

Multi-Repo Support

Multi-folder workspace feature allows seamless CORTEX + your projects management

Rich Extension Ecosystem

Integrates with Python, Git, Docker, and thousands of other VS Code extensions

Community Support

Larger VS Code community means more resources, tutorials, and troubleshooting help

Visual Studio IDE support is available for teams with existing workflows, but feature parity and performance may differ.

Understanding CORTEX Multi-Repo Architecture

CORTEX 4.0 introduces a revolutionary 1:∞ multi-repo architecture that fundamentally changes how AI assists your development workflow. Instead of installing CORTEX in every project, you install it once and use it across unlimited projects.

How It Works

Think of CORTEX as your personal AI development consultant that sits alongside your work, not inside it. CORTEX maintains its own 4-tier brain (memory system) that learns from all your projects while respecting strict boundaries through SKULL protection rules.

SKULL Protection: What CORTEX Does vs. Never Does

CORTEX DOES

  • Create plans in cortex-brain/documents/planning/
  • Generate reports in cortex-brain/documents/reports/
  • Learn from your code patterns (in its brain)
  • Guide you through Copilot Chat commands
  • Create/modify files in YOUR projects (when you ask)

CORTEX NEVER DOES

  • Commit CORTEX code into your repositories
  • Create .cortex/ folders in your projects
  • Mix its brain data with your source code
  • Modify files without your explicit instruction
  • Allow implementation before tests fail (TDD)

VS Code Installation Path (Recommended)

Prerequisites

  • Visual Studio Code 1.85+
    Download from code.visualstudio.com
  • GitHub Copilot Chat Extension
    Requires active GitHub Copilot subscription (\-20/month)
  • Python 3.8+
    With pip package manager
  • Git 2.30+
    For cloning CORTEX repository

Step 1: Install CORTEX Extension

Install the CORTEX extension from VS Code Marketplace: 

1. Press Ctrl+Shift+X (Extensions)
2. Search for "CORTEX"
3. Click Install on "CORTEX - AI Development Intelligence" by asifhussain60
4. Reload VS Code when prompted

Step 2: Clone CORTEX Repository

Clone CORTEX to a dedicated location (NOT inside your project folders): 

# Windows
cd D:\\PROJECTS
git clone https://github.com/asifhussain60/CORTEX.git
cd CORTEX

# macOS/Linux
cd ~/projects
git clone https://github.com/asifhussain60/CORTEX.git
cd CORTEX

Step 3: Install Python Dependencies 

pip install -r requirements.txt

Step 4: Setup Multi-Folder Workspace

Add CORTEX and your projects to a VS Code workspace: 

1. File → Add Folder to Workspace
2. Select D:\\PROJECTS\\CORTEX
3. File → Add Folder to Workspace again
4. Select your project (e.g., D:\\MyProjects\\MyApp)
5. File → Save Workspace As → my-dev-workspace.code-workspace

Pro Tip: CORTEX auto-detects which folder you're working in. Just open files from your project and use Copilot Chat - CORTEX knows the context!

Visual Studio IDE Installation Path

Limited Feature Set: Visual Studio IDE extension has reduced functionality compared to VS Code. We recommend VS Code unless you have specific IDE requirements.

Prerequisites

  • Visual Studio 2019/2022
    Professional, Enterprise, or Community Edition
  • GitHub Copilot for Visual Studio
    Extension from Visual Studio Marketplace
  • Python 3.8+
    Same as VS Code requirements

Installation Steps 

1. Open Visual Studio
2. Extensions → Manage Extensions
3. Search for "CORTEX"
4. Install "CORTEX for Visual Studio" by asifhussain60
5. Restart Visual Studio
6. Clone CORTEX repository (same as VS Code)
7. Install Python dependencies (same as VS Code)

Note: Multi-folder workspace is not supported in Visual Studio IDE. CORTEX detects context from solution files (.sln) instead.
