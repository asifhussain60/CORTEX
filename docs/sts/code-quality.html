Code Quality Principles

Great code isn't just code that works—it's code that's easy to read, maintain, and extend. These principles help you write code that your future self (and teammates) will thank you for.

DRY (Don't Repeat Yourself)

Every piece of knowledge should have a single, unambiguous representation in the system.

KISS (Keep It Simple, Stupid)

Simplicity is the ultimate sophistication. Avoid unnecessary complexity.

YAGNI (You Aren't Gonna Need It)

Don't add functionality until you actually need it. Premature abstraction is the root of much evil.

Clean Code

Code should be self-documenting. If you need comments to explain what it does, refactor it.

interface DiscountContext {
    user: User;
    order: Order;
    coupon?: Coupon;
}

function calculateDiscount(ctx: DiscountContext): number {
    const discounts: number[] = [];
    
    // Apply coupon discount
    if (ctx.coupon) {
        discounts.push(calculateCouponDiscount(ctx.coupon, ctx.order));
    }
    
    // Apply premium member discount
    if (ctx.user.isPremium) {
        discounts.push(calculatePremiumDiscount(ctx.order));
    }
    
    const totalDiscount = discounts.reduce((sum, d) => sum + d, 0);
    return Math.min(totalDiscount, ctx.order.total);
}

function calculateCouponDiscount(coupon: Coupon, order: Order): number {
    const maxPercentage = 50;
    
    switch (coupon.type) {
        case 'percentage':
            const cappedPercentage = Math.min(coupon.value, maxPercentage);
            return order.total * (cappedPercentage / 100);
        
        case 'fixed':
            return Math.min(coupon.value, order.total);
        
        default:
            return 0;
    }
}

function calculatePremiumDiscount(order: Order): number {
    const thresholds = [
        { minTotal: 100, rate: 0.10 },
        { minTotal: 0, rate: 0.05 }
    ];
    
    const tier = thresholds.find(t => order.total >= t.minTotal);
    return tier ? order.total * tier.rate : 0;
}

// Even simpler with a discount engine
class DiscountEngine {
    private rules: DiscountRule[] = [];
    
    addRule(rule: DiscountRule): this {
        this.rules.push(rule);
        return this;
    }
    
    calculate(ctx: DiscountContext): number {
        return this.rules
            .filter(rule => rule.applies(ctx))
            .reduce((total, rule) => total + rule.calculate(ctx), 0);
    }
}

Code Quality Best Practices

DRY

Extract shared logic into services, utilities, or base classes. One source of truth.

@Injectable() ValidationService

KISS

Prefer simple, straightforward solutions. If it's hard to explain, it's too complex.

return items.filter(x => x.active)

YAGNI

Build for today's requirements. Refactor when you actually need more.

// TODO: Add when needed

Self-Documenting

Use meaningful names. Code should read like prose, not puzzles.

isEligibleForDiscount(user)
