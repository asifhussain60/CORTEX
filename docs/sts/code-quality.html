🎓 Code Quality Principles Explained

"Code quality" isn't just about whether code works—it's about whether code is readable, maintainable, and bug-resistant. Here are the key principles that separate good code from bad:

DRY

Don't Repeat Yourself

"Every piece of knowledge must have a single, unambiguous representation in a system."

📝 Analogy: If you update your address, you shouldn't have to change it in 10 different places.

KISS

Keep It Simple, Stupid

"Simplicity should be a key goal in design, and unnecessary complexity should be avoided."

🔧 Analogy: Don't use a Swiss Army knife when a screwdriver will do.

YAGNI

You Aren't Gonna Need It

"Don't add functionality until it's actually needed."

🏗️ Analogy: Don't build a helipad on your house "just in case" you buy a helicopter.

CC

Cyclomatic Complexity

"A measure of how many independent paths exist through code. Lower is better."

🌳 Analogy: A function with 50 if/else branches is like a maze—hard to navigate and easy to get lost.

Anti-Pattern: Copy-Paste Programming — Three payment methods share 80% identical code. When a bug is found, it must be fixed in three places. When validation rules change, three methods need updating. This is a maintenance nightmare!

def _validate_amount(self, amount: float) -> tuple[bool, str]:
    """Single source of truth for amount validation"""
    if amount <= 0:
        return False, "Invalid amount"
    if amount > 10000:
        return False, "Amount exceeds limit"
    return True, ""

def _validate_card(self, card_number: str) -> tuple[bool, str]:
    """Single source of truth for card validation"""
    if not card_number or len(card_number) != 16:
        return False, "Invalid card"
    return True, ""

def _process_card_payment(
    self, card_type: str, amount: float, data: dict
):
    """Unified card processing - no duplication!"""
    valid, error = self._validate_amount(amount)
    if not valid:
        return {"success": False, "error": error}
    
    valid, error = self._validate_card(data.get("card_number", ""))
    if not valid:
        return {"success": False, "error": error}
    
    prefix = "CC" if card_type == "credit" else "DC"
    transaction_id = f"{prefix}-{data['card_number'][:4]}-{amount}"
    return {"success": True, "transaction_id": transaction_id}

def process_data(data: list, context: ProcessContext) -> list:
    """Orchestrates processing - delegates to specialists"""
    processor = ProcessorFactory.create(context.mode)
    validator = ValidatorFactory.create(context.config)

class FastProcessor:
    """Handles fast mode processing"""
    def process_batch(self, data, context):
        return [self._process_item(item, context) for item in data]
    
    def _process_item(self, item, context):
        handler = self._get_handler(item.type)
        return handler.process(item, context)

class ItemTypeAHandler:
    """Handles Type A items only"""
    def process(self, item, context):
        if not item.is_active:
            return self._handle_inactive(item)
        return self._process_by_region(item, context.region)
    
    def _process_by_region(self, item, region: str):
        handlers = {"US": self._us_rules, "EU": self._eu_rules}

def calculate_average_discounted_price(
    products: list[Product],
    min_price: float,
    discount_rate: float
) -> float:
    """Calculate average price after discount for premium products."""
    discounted_prices = [
        product.price * discount_rate
        for product in products
        if product.price > min_price
    ]
    if not discounted_prices:
        return 0.0
    return sum(discounted_prices) / len(discounted_prices)

def filter_items_by_predicate(
    items: list[T], 
    predicate: Callable[[T], bool]
) -> list[T]:
    """Return items matching the given condition."""
    return [item for item in items if predicate(item)]

@app.route('/health')
def health():
    """Health check with graceful degradation"""
    status = {"overall": "healthy"}
    
    # Each check is isolated - one failure doesn't crash all
    try:
        db.execute("SELECT 1")
        status["database"] = "healthy"
    except DatabaseError as e:
        status["database"] = "unhealthy"
        status["overall"] = "degraded"
        logger.error(f"DB health check failed: {e}")
    
    try:
        cache.ping()
        status["cache"] = "healthy"
    except CacheError as e:
        status["cache"] = "unhealthy"
        logger.warning(f"Cache unavailable: {e}")
    
    http_status = 200 if status["overall"] == "healthy" else 503
    return jsonify(status), http_status
