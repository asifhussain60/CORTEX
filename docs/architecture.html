Intelligence Architecture

Perception → Reasoning → Action

CORTEX is not a code generator. It is a three-tier intelligence system that reads your workspace, selects a strategy, and executes with enforced quality gates.

Tier 1

Perception

Matches observed signals against 9 canonical patterns: Mediator, Strategy, Observer, Factory, Template Method, Chain of Responsibility, Adapter, Repository, Command. Each receives a confidence score (0.0–1.0).

# Pattern recognition patterns.match("repository") → 0.92 patterns.match("mediator") → 0.87
Tier 2

Reasoning

Selects the best approach from ranked strategies. Each has a historical success rate that updates after every execution. The system learns which strategies work best for your team over time.

IntelligenceFacade .select_strategy(ctx) # → QUICK | TARGETED | FULL .check_rca_history() # ⚠ Prior failure: {scope}
Tier 3

Action

Converts the chosen strategy into a step-by-step plan. Every step has a mandatory test checkpoint, a defined rollback point, and a governance validation check.

AC_START("AC-IMPL-001") MasterOrchestrator .route(IMPLEMENT) enforce() # P0/P1 gate AC_COMPLETE("✅ 842ms")

Root Cause Analysis

Four RCA Methodologies — Failures Never Repeat

Every root cause analysis generates a SQLite-backed PreventionRule that surfaces automatically the next time a similar pattern appears.

Five-Whys

Linear root cause tracing — best for technology failures with clear sequential cause chains.

Fishbone

Multi-factor analysis across People, Process, Technology, and Data failure axes.

Fault Tree

AND/OR gate analysis surfacing the minimum set of conditions for failure.

Causal Chain

Temporal event correlation — reveals triggering events that precede the visible symptom.

Prevention Escalation

Three Escalation Levels

Prevention rules escalate based on recurrence count. Chronic failures get harder to ignore.

⚠️

Advisory

Default level. Shows warning in analysis but does not block. Generated on first RCA completion.

🚫

Blocking

Promoted after 3+ recurrences. Requires explicit acknowledgment to proceed past the gate.

🔒

Hard Block

Promoted after 5+ recurrences. Cannot be bypassed — the operation is refused outright.

Continuous Learning

Unified Reinforcement Signal

CORTEX rewards successful patterns and demotes failed ones — getting measurably better at predicting which approaches succeed for your team.

Every success and failure updates confidence scores. Approaches that consistently work are recommended first. Chronic failures are quarantined.

Cross-Team Signal

Pattern Quarantine

CORE-008 Mandatory

The TDD Cycle — Red · Green · Refactor

CORTEX enforces Test-Driven Development as an immutable contract. No implementation proceeds without a failing test. There is no flag to skip it.

🔴
RED — Write Failing Test

Define expected behaviour. The test MUST fail before any production code is written.

🟢
GREEN — Minimum Passing Code

Write the simplest code that makes the test pass. Exactly what's needed — nothing more.

♻️
REFACTOR — Clean & Converge

Improve structure while keeping tests green. Convergence gate rescans until zero violations.
