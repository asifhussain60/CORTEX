## Image Prompt Design Principles

For each chapter's story prompts (a/b/c variants), the **immutable concept** should be visually represented on the whiteboard, screen, or environment — never as text overlay on the image. The concept should be discoverable through the scene composition, not stated explicitly.

### Visual Encoding Rules

1. **Whiteboard diagrams** are the primary vehicle for concept visualization
2. **Monitor screens** show live metrics/dashboards that demonstrate the concept in action
3. **Character reactions** (Asif's expression, CB's dome contents, Miss G's gesture) reflect the emotional weight of the concept
4. **The Brain Jar** grows in complexity to match the accumulated concepts
5. **Environmental details** (sticky notes, coffee state, router color) encode narrative progress

### Concepts That Should NOT Appear in Image Prompts
- Specific file counts (they change constantly)
- Specific test counts (they change constantly)  
- Version numbers
- Phase numbers
- Specific code syntax
- Any metric that will drift within 3 months
