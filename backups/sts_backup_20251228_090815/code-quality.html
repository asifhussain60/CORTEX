🎓 Code Quality Principles

These principles guide us toward writing code that's not just functional, but also maintainable, readable, and efficient. They're the wisdom of decades of software engineering.

D

DRY - Don't Repeat Yourself

"Every piece of knowledge should have a single, unambiguous representation."

📚 Analogy: A library has one copy of each book, not duplicates on every shelf.

K

KISS - Keep It Simple, Stupid

"Simplicity is the ultimate sophistication."

🔧 Analogy: A Swiss Army knife is useful, but sometimes you just need a screwdriver.

Y

YAGNI - You Aren't Gonna Need It

"Don't add functionality until it's necessary."

🏠 Analogy: Don't build a helipad on your house just in case you buy a helicopter.

CQ-02 KISS MEDIUM TypeScript

Magic Numbers: What Does 86400000 Mean?

Code Smell: Magic Numbers — Raw numeric literals scattered through code are impossible to understand. Is 86400000 a timeout? A size limit? Without context, no one knows.

❌ BEFORE session.service.ts 
export class SessionService {
  checkSession(lastActivity: Date): boolean {
    const now = Date.now();
    const diff = now - lastActivity.getTime();
    
    // What are these numbers?!
    if (diff > 86400000) {
      return false;  // Session expired
    }
    if (diff > 1800000) {
      this.refreshToken();
    }
    return true;
  }
  
  calculateDiscount(price: number, quantity: number): number {
    if (quantity > 10) return price * 0.15;  // What's 0.15?
    if (quantity > 5) return price * 0.10;   // What's 0.10?
    return 0;
  }
}
✅ AFTER Named Constants 
// constants/time.constants.ts
export const TIME = {
  MILLISECONDS_PER_DAY: 24 * 60 * 60 * 1000,  // 86400000
  MILLISECONDS_PER_30_MIN: 30 * 60 * 1000,    // 1800000
} as const;

// constants/discount.constants.ts
export const DISCOUNT = {
  BULK_THRESHOLD: 10,
  BULK_RATE: 0.15,      // 15% off
  MEDIUM_THRESHOLD: 5,
  MEDIUM_RATE: 0.10,    // 10% off
} as const;

export class SessionService {
  checkSession(lastActivity: Date): boolean {
    const elapsed = Date.now() - lastActivity.getTime();
    
    if (elapsed > TIME.MILLISECONDS_PER_DAY) {
      return false;  // Clear intent!
    }
    if (elapsed > TIME.MILLISECONDS_PER_30_MIN) {
      this.refreshToken();
    }
    return true;
  }
}

CQ-03 KISS HIGH C#

Arrow Code: Deeply Nested Conditionals

Code Smell: Arrow Code — When indentation creates an "arrow" pointing right, the code is too complex. Use early returns and guard clauses to flatten the structure.

❌ BEFORE OrderService.cs 
public async Task<Result> ProcessOrderAsync(Order order)
{
    if (order != null)
    {
        if (order.Items.Any())
        {
            if (order.Customer != null)
            {
                if (order.Customer.IsActive)
                {
                    if (await HasSufficientInventoryAsync(order))
                    {
                        if (await ValidatePaymentAsync(order))
                        {
                            // Finally! The actual logic
                            return await SubmitOrderAsync(order);
                        }
                        else { return Result.Fail("Payment failed"); }
                    }
                    else { return Result.Fail("Out of stock"); }
                }
                else { return Result.Fail("Customer inactive"); }
            }
            else { return Result.Fail("No customer"); }
        }
        else { return Result.Fail("Empty cart"); }
    }
    else { return Result.Fail("No order"); }
}
✅ AFTER Guard Clauses 
public async Task<Result> ProcessOrderAsync(Order? order)
{
    // Guard clauses - early returns flatten the code
    if (order is null)
        return Result.Fail("No order");
    
    if (!order.Items.Any())
        return Result.Fail("Empty cart");
    
    if (order.Customer is null)
        return Result.Fail("No customer");
    
    if (!order.Customer.IsActive)
        return Result.Fail("Customer inactive");
    
    if (!await HasSufficientInventoryAsync(order))
        return Result.Fail("Out of stock");
    
    if (!await ValidatePaymentAsync(order))
        return Result.Fail("Payment failed");
    
    // Happy path is now clear and unindented!
    return await SubmitOrderAsync(order);
}

Speculative Generality: Built for a Future That Never Came

YAGNI Violation — This configuration system supports XML, YAML, TOML, INI, and database sources... but the app only ever uses JSON. All that complexity serves no purpose.

class XmlConfigSource implements ConfigSource { /* 90 lines */ }
class IniConfigSource implements ConfigSource { /* 40 lines */ }

    switch (type) {
      case 'json': return new JsonConfigSource();
      case 'yaml': return new YamlConfigSource();
      // ... 5 more cases

✅ AFTER Just What You Need 
// Simple, focused, does exactly what's needed
interface AppConfig {
  apiUrl: string;
  features: FeatureFlags;
  logging: LogConfig;
}

@Injectable({ providedIn: 'root' })
export class ConfigService {
  private config: AppConfig | null = null;
  
  async load(): Promise<AppConfig> {
    if (this.config) return this.config;
    
    const response = await fetch('/config.json');
    this.config = await response.json();
    return this.config;
  }
  
  get<K extends keyof AppConfig>(key: K): AppConfig[K] {
    if (!this.config) throw new Error('Config not loaded');
    return this.config[key];
  }
}

// If you EVER need YAML, add it THEN. Not now.

Method Too Long: 200+ Lines of Spaghetti

Code Smell: Long Method — A method with 200+ lines doing validation, transformation, API calls, and database operations. Extract logical chunks into well-named methods.

✅ AFTER Extracted Methods 
public async Task<Report> GenerateReportAsync(ReportRequest request)
{
    ValidateRequest(request);
    
    var data = await FetchReportDataAsync(request);
    var summaries = TransformToSummaries(data);
    var metrics = CalculateMetrics(summaries);
    
    return AssembleReport(request, summaries, metrics);
}

private void ValidateRequest(ReportRequest request)
{
    ArgumentNullException.ThrowIfNull(request);
    if (string.IsNullOrEmpty(request.Title))
        throw new ValidationException("Title required");
}

private async Task<ReportData> FetchReportDataAsync(ReportRequest request)
{
    var users = await _userRepo.GetAllAsync();
    var orders = await _orderRepo.GetByDateRangeAsync(
        request.StartDate, request.EndDate);
    return new ReportData(users, orders);
}

private IEnumerable<Summary> TransformToSummaries(ReportData data)
{
    return data.Orders
        .GroupBy(o => o.Category)
        .Select(g => new Summary(g.Key, g.ToList()));
}
