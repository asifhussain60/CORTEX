Intelligence Architecture

Perception → Reasoning → Action

CORTEX is not a code generator. It is a three-tier intelligence system that reads your workspace, selects a strategy, and executes with enforced quality gates.

Tier 1

Perception

LENS scans 9 dimensions of your workspace. Architecture, history, coupling, and security context are all loaded before the first token is generated.

# Before every execution: lens.scan("structural") lens.scan("security") lens.scan("history") # → AnalysisContext built

Reasoning

Action

AC_START("AC-IMPL-001") MasterOrchestrator .route(IMPLEMENT) enforce() # P0/P1 gate AC_COMPLETE("✅ 842ms")
CORE-008 Mandatory

The TDD Cycle

CORTEX enforces Test-Driven Development as an immutable contract, not a suggestion. No implementation proceeds without a failing test. Every time.

🔴
RED — Write Failing Test

Define expected behaviour via a test. The test MUST fail before any production code is written. CORTEX blocks implementation if no failing test exists.

🟢
GREEN — Minimum Passing Code

Write the simplest code that makes the test pass. No over-engineering. CORTEX validates that the test suite passes before allowing the next gate.

♻️
REFACTOR — Clean & Converge

Improve structure, remove duplication, enforce CORE rules. Convergence gate rescans until zero P0/P1 violations. Then the cycle repeats.

Institutional Memory

RCA Memory — Failures Never Repeat

Every root cause analysis generates a SQLite-backed PreventionRule that surfaces automatically the next time a similar pattern is about to be introduced.

❌ Without RCA Memory
  • •Same bug fixed 4× across different sessions — no shared memory.
  • •Security gaps reintroduced by different team members.
  • •Post-mortems written, filed, and forgotten.
  • •Junior engineers repeat senior engineer mistakes.
✅ With RCA Memory
  • •Every fix converted into a named PreventionRule.
  • •PLIP-001: cortex_learning op=history consulted before every code-modifying operation.
  • •Pattern confidence scores decay over time — stale patterns don't accumulate noise.
  • •Cross-team: one fix prevents re-introduction across the entire portfolio.
