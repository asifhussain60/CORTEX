# Video Prompt 01 — What Is CORTEX?

> **Duration:** 7 minutes · **Audience:** Executives, Product Owners, Curious Learners
> **Depth:** 🟢 High-level overview — no code, no jargon
> **No overlap:** Image prompts show architecture anatomy; this video tells the story of *why CORTEX exists* and *what it does for you*

## ⚠️ VISUAL IDENTITY — MANDATORY

> **ALL visuals** must use the CORTEX dark glassmorphism palette. Background: `#0a0e27`. Panels: `rgba(26, 31, 58, 0.7)` with `rgba(255, 255, 255, 0.1)` borders and 10-20px backdrop blur. Primary accent: `#00d4ff` (cyan). Secondary accent: `#7b61ff` (purple). Success: `#00ff88`. Warning: `#ffa500`. Danger: `#ff4444`. Info: `#3b82f6`. Text: `#ffffff` (primary), `#a0a6c0` (secondary). ## PROMPT

Create a 7-minute animated explainer video titled **"What Is CORTEX?"** using the visual identity above.

### Scene 1 — The Problem (0:00 – 1:30)

**Open on:** A developer's screen — glassmorphic dark IDE panels. Show the chaos of modern AI development:

- A chat window produces an answer, but the developer manually copies it, edits a file, runs tests, checks governance rules, updates docs. Each manual step is a separate floating glass panel that blinks amber (`#ffa500`).
- **Daily-life analogy text overlay** (muted `#a0a6c0`, Inter font): *"Imagine running a restaurant where the chef, waiter, cashier, and health inspector are all the same person — doing everything manually, one step at a time."*
- Count the steps: glass panels stack up, wobble, some turn red (`#ff4444`) — missed test, broken rule, forgotten doc update.
- The stack collapses in a gentle cascade — cyan particles scatter.

**Narration tone:** Empathetic. "Building with AI assistants should feel magical. But the reality is... manual. Repetitive. Error-prone."

### Scene 2 — Enter CORTEX (1:30 – 3:00)

**Transition:** Collapsed panels reassemble — but now a glowing cyan ring (`#00d4ff`) emerges from the center, pulling them into orbit.

- The ring is CORTEX — the orchestration layer. Text materializes: **"CO**gnitive **R**eal-**T**ime **EX**ecution" in Space Grotesk, each abbreviation letter pulsing cyan.
- **Brain analogy:** The ring transforms into a translucent glass brain on the `#0a0e27` background. Three horizontal tiers light up sequentially:
  - **Top (Perception):** Cyan glow — "Understands what you're asking"
  - **Middle (Reasoning):** Purple glow (`#7b61ff`) — "Figures out the best plan"
  - **Bottom (Action):** Green glow (`#00ff88`) — "Executes with precision"
- **Daily-life analogy overlay:** *"CORTEX is the restaurant manager who coordinates the chef, waiter, and inspector — so they work in harmony."*

**Narration:** "CORTEX is a production-grade AI engineering framework. It doesn't replace your AI — it orchestrates it."

### Scene 3 — The Core Capabilities (3:00 – 5:00)

**Camera slowly orbits the glass brain.** Five capabilities appear as glassmorphic cards, each sliding in from the edges with a soft whoosh:

1. **51 Orchestrators** — Show tiny luminous dots orbiting in 4 colored rings (core=cyan, domain=purple, support=green, git=amber). Card: "51 specialized workers, each with one job."
   - *Analogy overlay:* *"Like a hospital with 51 specialist doctors — you never ask the cardiologist to do brain surgery."*

2. **28 MCP Tools** — Show a glass toolbar materialize with icon slots filling in one by one (cyan pulse per slot). Card: "Plug-in tools that extend capabilities."
   - *Analogy overlay:* *"Swiss Army knife — each tool folds out when you need it."*

3. **38 Governance Rules** — Show a translucent shield wall shimmer across the bottom. Card: "Automated quality guardrails."
   - *Analogy overlay:* *"Building codes for your code — inspected before anything ships."*

4. **TDD-First** — Show a heartbeat line (ECG) pulse across a monitor: red peak, green peak, blue peak, repeat. Card: "Test first. Always."
   - *Analogy overlay:* *"Taste the dish before serving it to customers."*

5. **LENS Analysis** — Show a scanning beam sweep across a code panel, highlighting regions. Card: "Workspace-aware intelligence."
   - *Analogy overlay:* *"An MRI scan for your entire codebase."*

Each card has `#1a1f3a` glass background, `rgba(255,255,255,0.1)` border, 12px corner radius.

### Scene 4 — What Makes It Different (5:00 – 6:15)

**Split screen.** Left: "Other Approaches" (dimmed, monochrome glass panels). Right: "CORTEX" (vibrant cyan/purple glass panels).

| Without CORTEX | With CORTEX |
|---|---|
| Manual file editing → amber panel | Autonomous execution → cyan panel |
| Hope-based testing → red blink | TDD-first guarantee → green pulse |
| No governance → static gray | 38 rules enforced → shield shimmer |
| Scattered tools → floating fragments | 28 MCP tools, wired → connected grid |
| One-shot prompts → single arrow | 51 orchestrators, routed → flowing network |

Animate each row appearing sequentially. Left side stays dim, right side glows.

**Narration:** "CORTEX doesn't just help you code. It ensures every change is tested, governed, and orchestrated — automatically."

### Scene 5 — Who Is It For? (6:15 – 7:00)

**Four glassmorphic persona cards** slide in (matching the index.html persona tiles):

1. 🏢 **Business Leader** — "See governance compliance at a glance"
2. 📋 **Product Owner** — "Track capabilities and coverage"
3. 💻 **Software Engineer** — "TDD, orchestrators, MCP tools — daily workflow"
4. 🎓 **Curious Learner** — "Understand AI engineering patterns"

Each card has the persona icon on the left, description on the right, glassmorphic panel styling.

**Closing text** (Space Grotesk, large, fade in): **"One framework. Fifty-one orchestrators. Zero manual steps."**

Logo watermark pulses once from 20% to 40% opacity and back as the final beat.

**End card:** CORTEX logo centered, URL `https://asifhussain60.github.io/CORTEX/` below in JetBrains Mono, ambient audio fades.
